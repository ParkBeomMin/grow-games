## 🎮 게임 방식

육성 게임 7종은 같은 뼈대를 공유해요 (🦄 더 유니콘은 방치형이라 아래 흐름 대신 클릭·자동 생산·프레스티지 구조를 씁니다):

1. **시작 선택** — 배경(지역/소속사/유스/시장 등, 5종)과 포지션(4종)의 트레이드오프를 골라요. 별점(성장/안정성)으로 한눈에 비교
2. **턴제 육성** — 매달 훈련 or 휴식. 컨디션을 무시하면 부상, 매달 랜덤 이벤트. 30분마다 무료 보너스 연습
3. **정기 이벤트** — 대회/무대/경기가 문자중계·연출로 흘러가고, 승부처마다 **8종 미니게임**(타이밍·홀드·순서·반응·수싸움·조준탭·낙하캐치·다른그림찾기) 중 랜덤 등장. 🤖 자동 진행도 지원
4. **최종 시험** — 드래프트/데뷔 서바이벌 등에서 3년의 성과가 갈라져요
5. **프로 커리어** — 통과하면 프로 무대로. 시즌 반복 → 수상·우승 → 원할 때 은퇴 → 🏛️ **명예의 전당** 영구 기록

### 공통 시스템

- **멀티 슬롯 저장** — 계정당 여러 캐릭터를 키우고, 이어하기에서 골라서 진행
- **🏛️ 글로벌 명예의 전당** — 은퇴 선수 기록을 Supabase에 저장해 전 세계 플레이어와 공유 (오프라인이면 로컬 기록으로 자동 폴백)
- **⚔️ 배틀 아레나** — 현역/은퇴 선수로 랜덤 매칭 대결 + 레이팅 랭킹 (공용 `match.js`, Supabase 연동)
- **📊 통계 대시보드** — 방문·선택 분포·명예의 전당·PWA 설치 수 등을 집계 ([`/stats/`](./stats/), 비밀번호 게이트)

밸런스는 전략별 수천 회 시뮬레이션으로 튜닝했어요 — **열심히 집중 육성한 캐릭터가 확실히 좋은 엔딩**을 받습니다.

## 🗒️ 업데이트 / 개선 기록

최근 작업한 개선·보완 내용이에요 (자세한 이력은 `git log` 참고).

### 신작 · 기능
- ❓ **게임 내 도움말(전 종목)** — HUD의 `❓ 도움말`을 누르면 훈련·컨디션, 재능과 각성, 진행 흐름, 은퇴, 돈 벌기를 정리한 모달이 떠요. 공용 `help.js` 하나로 7종이 같은 뼈대를 쓰고 용어만 게임별로 달라요
- 🎓 **은퇴 확인창(전 종목)** — 환생에만 확인 절차가 있어서 은퇴는 한 번 잘못 누르면 커리어가 끝났어요. 이제 남을 기록(시즌 수·성적·수상·등급)을 요약해 보여주고 확인을 받아요. 드래프트 미지명 경로는 되돌아갈 커리어가 없어 그대로 뒀어요
- 💰 **고교 경제 손질(더 드래프트)** — 대회에서 1회전 탈락하면 3년 통틀어 150만이라 장비 최하 등급(500만)도 못 사고 있었어요. 대회 수당을 2배로 올리고 장비 I~IV를 내려서, 실력에 따라 등급 I·II·III을 살 수 있게 했어요. 등급 V와 프로 수입은 그대로예요
- 🎛️ **HUD 정리(전 종목)** — 버튼이 세로로 쌓여 헤더가 170px까지 길어졌어요. 액션 버튼을 아래 한 줄로 빼고, 턴 표시와 자금을 한 줄에 우측 정렬해 60px로 줄였어요
- 💼🔁 **이적 — FA 계약 · 트레이드 요청(⚾ 더 드래프트)** — 사용자 의견으로 들어온 기능. 오프시즌(시즌 결산)에서 팀을 옮길 수 있어요. **FA는 8년차부터** — 시장 가치(최근 3시즌 WAR + 현재 기량)에 따라 제안이 1~4건 오고 원소속팀 잔류 제안은 항상 붙어요. 전력이 약한 팀일수록 계약금을 더 질러서(표본 200회 중 88%) *우승 도전이냐 목돈이냐*가 갈립니다. **트레이드는 2년차부터, 3라운드 협상** — 구단 태도 60을 넘겨야 보내주는데, 시작값이 **내 가치가 높을수록 낮고**(스타는 안 놔줌) **팀이 하위권이면 높아요**(리빌딩). 매 라운드 카드 3장 중 택1(면담·언론 흘리기·연봉 삭감·우승 명분·팬 호소·침묵)이고 구단 태도와 팬 여론이 서로 반대로 움직여요. 여론 35 미만이면 성사돼도 후유증, 거절되면 그 해 재요청 불가 + 다음 캠프 컨디션 하락. 이적이 헛돌지 않게 **팀별 전력**을 저장본에 두고 승률·순위표에 반영했어요
- 🏦 **유니콘 기업가치 체계** — 상단 숫자가 '누적 생산'이라 장비를 사도 꿈쩍하지 않던 걸 **기업가치 = 보유 코드라인 + 자산(투자액의 60%)** 으로 바꿨어요. 뭔가 사면 감가 40%만큼 즉시 내려갔다가 늘어난 생산으로 다시 채워집니다. 다만 **단계·Exit 보상·엔딩은 '이번 판 최고 기업가치'** 기준이라 사도 강등되거나 손해 보지 않아요(안 그러면 "Exit 직전엔 아무것도 사지 말기"가 최적이 돼버려요). 단계 기준선을 기존의 정확히 0.6배로 다시 잡아 진행 속도는 그대로(시뮬레이션상 오차 0.2%)이고, 기존 저장본도 강등 없이 이관돼요
- ✨ **눌린 걸 알 수 있게 — 구매·훈련 피드백(유니콘 + 육성 7종)** — 버튼을 누르면 화면이 통째로 다시 그려져서 `:active`가 남지 않는 게 원인이었어요. 유니콘은 구매 성공 시 항목이 번쩍이며 `초당 +N` 뱃지가, 코드라인이 모자라면 흔들림과 `N 부족`이 떠요(전에는 클릭이 그냥 무시됐어요). 육성 7종은 훈련 성공 `+4.2`, 실패 `-1.2`, 부상, 휴식 `컨디션 +41`이 버튼 위에 뜹니다. 공용 `Fx.tap()`으로 만들어 육성 화면·프로 화면 양쪽에 적용
- 🖥️ **유니콘 자동 생산 연출** — 조직이 코드를 뽑을 때도 터미널에 코드가 찍히고 `+N`이 떠요. 내가 친 줄은 초록, 조직이 뽑은 줄은 파랑으로 구분하고, 0.7초마다 모아서 출력해 읽을 수 있게 했어요. 탭이 가려져 있으면 쌓아두지 않아 돌아왔을 때 몰아치지 않아요
- ▾ **랭킹 더 보기 · 내 순위 고정(7종 + 유니콘)** — 글로벌 배틀 랭킹이 서버에서 200명을 받아오면서도 15명만 그리고 있었어요. 배틀 랭킹 15명씩·명예의 전당 20명씩 '더 보기'로 늘어나고, 헤더에 전체 인원이 뜨며, **내 순위가 화면 밖이면 `⋯` 아래에 내 행을 고정**해요
- 🔮 **상한에 닿으면 훈련 버튼이 각성 버튼으로(육성 7종)** — 능력치 상한(130 + 초월 단계×6)에 닿으면 훈련해도 오르지 않는데 버튼은 그대로라 턴만 소모됐어요. 이제 재능이 MAX 미만이면 `🔮 재능 각성`, MAX면 `🌠 초월 각성`으로 바뀌고 성공률까지 표시돼요. 무료 특훈도 상한에 찬 능력치는 고르지 않아요
- 🌏 **유니콘 창업 수** — 상단에 "지금까지 N개의 회사가 창업했어요". 단순 방문이 아니라 **사명을 정하고 실제로 시작한 기기 수**(통계 뷰의 `new_player`)를 세고, 5분마다 갱신하며 마지막 값을 캐시해 조회 전에도 빈자리가 없어요
- 🍂 **가을야구 · 한국시리즈(더 드래프트)** — 정규시즌 144경기가 끝나면 5위까지 가을야구에 나가요. 실제 KBO대로 와일드카드(4위가 1승 안고 시작) → 준PO → PO → 한국시리즈 순이고, 내가 안 낀 라운드는 자동으로 치러져 상대가 정해져요. 포스트시즌은 투수 단축 로테이션이고 기록은 정규시즌과 따로 집계돼요. 우승은 이제 순위로 굴리는 주사위가 아니라 7전 4선승을 실제로 이겨야 해서 훨씬 귀해졌어요. 📊 팀 순위표도 프로 화면에서 접었다 펼 수 있어요
- 📊 **통계 대시보드 게임별 탭** — 8개 게임 지표가 한 페이지에 28섹션까지 쌓이던 걸 게임별 탭으로 나눴어요. 전역 KPI와 전 게임 합산 방문 추이는 위에 고정되고, 탭을 누르면 그 게임의 방문 추이·배경/포지션 분포·이벤트 퍼널만 보여요. 게임별 방문 추이는 이번에 새로 생겼고(집계 뷰에 데이터는 있었는데 합산만 하고 있었어요), 탭은 URL에 남아서(`/stats/#rookie`) 새로고침해도 유지되고 링크로 바로 열려요
- 🦄 **방치형 신작 '더 유니콘'** — 클릭으로 코딩 → ⌨️개발력(클릭당 +N)·🏢조직(초당 +N) 반복 성장 → 🚀Exit 재창업(스톡옵션 영구 배수) → 👑데카콘 엔딩. Exit 횟수로 열리는 해금 6종, 터미널 클리커, 🏛️명예의 전당·은퇴 지원
- 🧬 **환생 — 다음 세대로(⚾ 더 드래프트)** — 은퇴와 별개의 마무리 방식. 🏛️은퇴는 명예의 전당에 기록을 남기고 끝내는 거고, 🧬환생은 기록 대신 **유산**을 남겨 다음 세대가 더 높은 재능과 시작 자금으로 출발해요. **🏆우승 3회 · 🎖️MVP 3회 · 🌠초월 각성 1단계 중 하나를 이뤄야** 열려요 — 못 채워도 은퇴는 언제나 가능해요. 유산 보너스는 재능·자금 모두 √로 완만히 오르고 **누적 70쯤에서 함께 포화**해요(재능 +0.25, 시작 자금 1.5억). 상한까지 쌓고 최상위 굴림이 겹치면 드물게 5성으로 시작할 수도 있어요. 명예의 전당에는 `3세` 배지로 세대가 표시돼요
- 🌠 **초월 각성(전 종목)** — 재능 ⭐⭐⭐⭐⭐ MAX 이후의 엔드게임. 스탯을 상한까지 채우면 도전 가능하고, 성공하면 ✨단계가 오르며 그 스탯 상한 +6, **명예의 전당 +25점**. 성공률이 45%에서 단계마다 3%p씩 떨어져(최저 15%) 자연히 느려지고 단계 상한은 없어요. 누적 단계로 칭호(🌠 각성 너머 → ✨ 초월자 → 🌌 무아지경 → 🔱 신화의 영역)
- 🐛 **유니콘 버그 잡기** — 화면을 보고 있을 때 가끔 벌레가 기어다녀요. 탭하면 핫픽스 보상(30초치 생산), 놓치면 장애로 코드가 조금 줄어요. 자리를 비운 동안엔 등장하지 않아 방치 플레이는 손해 보지 않아요
- 🦄 **유니콘 사명 직접 입력** — 창업 시 회사 이름을 정하고, 🎲 랜덤 추천(600여 조합)과 추천 칩 제공. 상단 회사명을 눌러 언제든 변경
- 🕹️ **아케이드 허브** — 메인을 게임 포털 형태로 개편 (장르 칩, 이어하기, 플레이 중 배지)
- 🆕 신작 5종 추가 — 더 인베스터(주식) · 더 윙어(축구) · 더 커밋(개발) · 더 셰프(요리) · 더 스트리머(스트리머). **시리즈 7종 완성**
- ⚽ **더 윙어 경기 시뮬레이션 뷰** — 실시간 스코어보드(우리팀 X:Y 상대) + 미니 필드에서 공이 움직이고, 골/실점 시 필드가 번쩍. 골·도움·수비 기록도 커리어에 집계
- 🎮 **미니게임 5종 → 8종** — 조준 탭 · 낙하 캐치 · 다른 그림 찾기 추가 (전 게임 공통)
- 🎚️ **선택지 확장** — 배경 3→5개, 포지션 3→4개 (전 게임)

- ⚾ **스코어보드와 승패가 어긋나던 문제(더 드래프트)** — 사용자 제보. `오륙도고 5 : 강릉고 4`인데 결과는 '패배'로 나왔어요. 미니게임이 걸린 경기는 **승패를 먼저 정하고 이닝별 점수는 따로 흩뿌리는** 구조라, 마지막 타석이 늘 동점 상황인 게 아니어서 둘이 모순될 수 있었어요. 승패는 유저가 미니게임으로 따낸 결과이니 그대로 두고 **최종 점수를 승패에 맞추도록** 고쳤고, 아예 **클러치 직전에 점수판을 '1점 차' 상황으로 맞춰둬서**(8회 칸에 반영) 이후 분기(끝내기 홈런·동점 적시타·삼진)가 저절로 점수와 맞아떨어지게 했어요 — 덕분에 `4:4 무승부인데 패배`, `이닝 합은 3인데 R은 4` 같은 사촌 문제도 함께 해결됐어요. 종료 문구도 `📢 경기 종료 — 오륙도고 5 : 4 강릉고`처럼 어느 쪽 점수인지 밝혀요. 50경기 검증에서 승패 불일치·무승부·이닝합 불일치 모두 0건. 고교 대회·프로 경기가 같은 시뮬을 쓰기 때문에 양쪽 모두 해결됐어요

'루키'는 신인을 뜻하는 보통명사라 상표로서는 약하지만, **같은 이름 + 같은 장르 + 광고 수익**이 겹치면 부정경쟁방지법상 혼동·편승으로 읽힐 수 있고, 소송보다 먼저 오는 건 광고 계정 신고예요. 게임의 클라이맥스인 드래프트를 그대로 딴 이름으로 바꿨어요. **바뀐 건 화면에 보이는 이름뿐** — URL(`/rookie/`), 저장 키(`rookie-save-v1`), 서버 기록의 `game: "rookie"`는 그대로라 기존 저장본·명예의 전당·배틀 레이팅이 전부 이어집니다. 타이틀 화면의 "지금까지 N명의 루키가 그라운드를 밟았어요"는 게임 제목이 아니라 신인 선수를 가리키는 말이라 그대로 뒀어요

## 🧪 베타 / 배포 (스테이징)

운영 중인 서비스라 새 기능은 **베타에서 검증 후 상용에 반영**해요.

- **상용**: `parkbeommin.github.io/grow-games/` (루트)
- **베타**: `parkbeommin.github.io/grow-games/beta/` (같은 main의 `beta/` 폴더 — 링크를 안 걸어 일반 유저는 오지 않아요, 좌하단 🧪 BETA 배지 표시)
- **완전 격리**: 베타는 `env.js`가 `/beta/` 경로를 감지해 localStorage를 `beta::` 네임스페이스로 분리하고, `match.js`·`stats.js`가 원격(Supabase·GA) 기록을 꺼요 → **상용 저장/명예의 전당/통계를 오염시키지 않아요.**

> ⚠️ **`sync-beta.sh`는 베타를 통째로 덮어씁니다.**
> 베타에 아직 상용화하지 않은 작업이 있으면 **그게 전부 사라져요.**
> 실제로 한 세션이 sync를 돌려 다른 세션의 베타 전용 작업(도움말 모달·은퇴 확인창 등)을
> 날린 적이 있어요. 여러 사람/세션이 함께 작업할 때는
> **`git log --oneline -- beta/` 로 베타에만 있는 커밋이 없는지 먼저 확인**하고,
> 있으면 `promote.sh`로 상용에 올린 뒤에 sync 하세요.
> 상용 수정만 베타에 반영하려면 sync 대신 그 파일만 복사하는 게 안전해요.

**작업 흐름**
```bash
# 1) (필요 시) 베타를 최신 상용 기준으로 맞추기 — 위 경고 확인 후!
bash scripts/sync-beta.sh          # 루트 → beta/

# 2) beta/ 안에서 새 기능 수정 → /beta/ 에서 확인

# 3) OK 되면 상용에 반영
bash scripts/promote.sh            # beta/ → 루트
git add -A && git commit -m "release: promote beta → prod"

# 4) 릴리스 마무리 — VERSION 갱신 + 태그 + 푸시를 한 번에
bash scripts/release.sh 1.2.0 "내용 요약"
```

### 버전 · 롤백

버전의 기준은 **두 가지**예요. 둘 다 일반 파일이라 어떤 환경에서든 확실히 남아요.

| 기준 | 역할 |
|---|---|
| `VERSION` | 지금 상용에 올라간 버전 (`cat VERSION`) |
| `CHANGELOG.md` | 버전별 **커밋 해시**와 변경 내용 — 롤백 대상 목록 |

> ⚠️ **태그는 보조 수단이에요.** 자동화 환경(Claude Code 등)의 git 프록시는
> 브랜치 ref만 허용하고 **태그 push를 403으로 거부**해요. 개인 PC에서는 정상이라,
> 태그가 필요하면 CHANGELOG의 해시로 나중에 한 번에 만들면 됩니다.

```bash
bash scripts/rollback.sh                     # 릴리스 목록 보기
bash scripts/rollback.sh 1e960bd --dry-run   # 뭐가 바뀔지 미리보기 (파일 안 건드림)
bash scripts/rollback.sh 1e960bd             # 실제 복원
git status --short                           # 확인 후
git add -A && git commit -m "revert: 상용 롤백" && git push origin main
```

- 태그·브랜치·**커밋 해시** 아무거나 받아요 — 태그가 없어도 롤백돼요.
- **루트(상용)만** 되돌려요 — `beta/`와 `scripts/`는 그대로라 작업 중인 베타가 안 날아가요.
- 그 시점 이후 추가된 파일(새로 나간 게임 폴더 등)은 상용에서 제거돼요.
- 작업 트리만 바꾸므로, 확인 후 직접 커밋/푸시해야 실제로 반영돼요.

버전별 상세 이력은 [`CHANGELOG.md`](./CHANGELOG.md)에 있어요.
