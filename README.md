## 🎮 게임 방식

모든 게임이 같은 뼈대를 공유해요:

1. **시작 선택** — 배경(지역/소속사/유스/시장 등, 5종)과 포지션(4종)의 트레이드오프를 골라요. 별점(성장/안정성)으로 한눈에 비교
2. **턴제 육성** — 매달 훈련 or 휴식. 컨디션을 무시하면 부상, 매달 랜덤 이벤트. 30분마다 무료 보너스 연습
3. **정기 이벤트** — 대회/무대/경기가 문자중계·연출로 흘러가고, 승부처마다 **8종 미니게임**(타이밍·홀드·순서·반응·수싸움·조준탭·낙하캐치·다른그림찾기) 중 랜덤 등장. 🤖 자동 진행도 지원
4. **최종 시험** — 드래프트/데뷔 서바이벌 등에서 3년의 성과가 갈라져요
5. **프로 커리어** — 통과하면 프로 무대로. 시즌 반복 → 수상·우승 → 원할 때 은퇴 → 🏛️ **명예의 전당** 영구 기록

### 공통 시스템

- **멀티 슬롯 저장** — 계정당 여러 캐릭터를 키우고, 이어하기에서 골라서 진행
- **🏛️ 글로벌 명예의 전당** — 은퇴 선수 기록을 Supabase에 저장해 전 세계 플레이어와 공유 (오프라인이면 로컬 기록으로 자동 폴백)
- **⚔️ 배틀 아레나** — 현역/은퇴 선수로 랜덤 매칭 대결 + 레이팅 랭킹 (공용 `match.js`, Supabase 연동)
- **📊 통계 대시보드** — 방문·선택 분포·명예의 전당·PWA 설치 수 등을 집계 ([`/stats/`](./stats/), 비밀번호 게이트)

밸런스는 전략별 수천 회 시뮬레이션으로 튜닝했어요 — **열심히 집중 육성한 캐릭터가 확실히 좋은 엔딩**을 받습니다.

## 🗒️ 업데이트 / 개선 기록

최근 작업한 개선·보완 내용이에요 (자세한 이력은 `git log` 참고).

### 신작 · 기능
- 🆕 신작 5종 추가 — 더 인베스터(주식) · 더 윙어(축구) · 더 커밋(개발) · 더 셰프(요리) · 더 스트리머(스트리머). **시리즈 7종 완성**
- ⚽ **더 윙어 경기 시뮬레이션 뷰** — 실시간 스코어보드(우리팀 X:Y 상대) + 미니 필드에서 공이 움직이고, 골/실점 시 필드가 번쩍. 골·도움·수비 기록도 커리어에 집계
- 🎮 **미니게임 5종 → 8종** — 조준 탭 · 낙하 캐치 · 다른 그림 찾기 추가 (전 게임 공통)
- 🎚️ **선택지 확장** — 배경 3→5개, 포지션 3→4개 (전 게임)
- 🏛️ **명예의 전당 글로벌 공유(Supabase)** + 기존 로컬 기록 자동 백필
- 💾 **멀티 슬롯 저장** — 계정당 여러 캐릭터
- 📊 **통계 대시보드** — 지역/소속사 선택 분포, 명예의 전당 실인원, **PWA 설치 수**, 최근 방문 추이 그래프(막대에 숫자·툴팁), **비밀번호 게이트**
- 📲 **PWA 설치/실행 추적** — 설치 수와 앱 사용 기기 수 집계

### 버그 · CS 대응
- ⚾ **9회말 규칙** — 홈팀이 9회초까지 앞서 있으면 불필요한 9회말을 진행하지 않도록 수정
- ⚾ **세이브 상황** — 마무리 무실점 등판이면 리드를 지켜 승리+세이브, 실점 시 블론세이브로 처리 (기존엔 랜덤 승패라 무실점인데 패배가 나옴)
- 🏆 **수상 로직(전 종목)** — MVP/대상 등을 '임계값+랜덤 동전던지기'에서 **리그 내 상대 비교**로 변경. 압도적 시즌이 상을 놓치지 않아요
- ⭐ **배경 별점** — 성장/안정성이 다 비슷하게(★★★) 보이던 문제를 상대 비교 5칸 별점으로 개선
- 🩹 각종 UI/밸런스 보정 — 타율 과다, 각성 버튼 무반응(100 표시), 하단 배너, 미니게임 연타 제거 등

## 🚀 실행 방법

정적 사이트라 아무 웹서버로나 열면 돼요.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages에 올리면 그대로 배포됩니다 (Settings → Pages → main 브랜치 선택).

## 🛠️ 새 게임 추가하기

1. `soccer/`(최신 구조) 또는 다른 게임 폴더를 복사해 새 폴더를 만들고
2. `game.js` 상단의 데이터(배경/포지션/스탯/이벤트/엔딩)를 새 테마로 교체
3. `style.css`에서 `:root` 색상 변수만 바꾸면 테마 완성 (`base.css`가 공용 스타일)
4. 루트 `index.html` 허브에 카드 추가, `stats/index.html`의 GAMES/POS 매핑에 게임 추가

> 재미로 만든 팬게임입니다. 등장하는 학교/구단/기획사/종목 명칭은 분위기를 위한 것으로 실제와 무관해요 🎈
