## 1. 🔴 왜 「빨간불을 먼저 걷어내라」였나

**빨간불인 검사는 남의 변이 신호까지 먹습니다.** 변이를 걸어도 실패 항목이 그대로면
「안 잡혔다」와 「원래 빨간불이었다」가 구분이 안 돼요.

`one-grid-test.js`가 정확히 그 상태였습니다 — 기준선 빨간불 3건이라 **변이 검증을 통째로
건너뛰고 있었고**(`⚠️ 기준선이 빨간불이라 변이 검증을 건너뜁니다`), 그래서 이미 있던
변이 10종도 **한 번도 안 돌았습니다.**

🔑 **그 셋만 고쳤더니 이미 있던 검사가 흠 넷(M1·M2·M3·M4)을 곧바로 잡았습니다.**
새로 쓸 것은 넷뿐이었어요.

### 2-2. 🔑 G-3 — **빨간불이 아니라 「아무것도 안 재는 상태」**

```js
const best = h.T.oneAt({ kc }, ms / 1000).best;   // 🔴 무대의 모양이 바뀌었습니다
```

`oneAt(b, sec)`이 받는 것이 `{ kc }` → **`{ side, off0, slide }`**로 바뀌었습니다.
`b.side`가 `undefined`라 `best`가 늘 `NaN`이고, `best > cs[i].x && best < cs[j].x`가
**한 번도 참이 안 됩니다.** 출력은 *"쓸 만한 판 0벌"* — 빨간불이 떴지만 **재고 있던 것은 없었어요.**

✅ **고친 방식** — 소스의 닫힌 식을 부르는 대신 **화면에서 읽습니다**:

```
빈 곳      = 골문 끝(0 또는 100) ↔ 🧤 몸의 가까운 끝     ← translateX · scaleX 둘 다 화면
좋은 지점  = 그 빈 곳의 한가운데
```

같은 절반의 **이웃 쌍 전부**를 보게 넓혔습니다(`[[0,1],[3,4]]`로 칸 번호를 박아 뒀는데
6칸에서는 `[1,2]`·`[4,5]`도 같은 절반이에요). **쓸 만한 판 0벌 → 24벌.**

## 4. 🔴 하네스가 ♿ 확대를 한 번도 안 걸고 있었습니다

`tests/winger2/_load.js`의 `momentDom`이 **url 없이** jsdom을 띄웠습니다.

```
url 없음 → origin이 opaque → localStorage.getItem이 던짐
        → wideOn()의 try/catch가 삼킴 → WIDE(1.30)가 늘 꺼짐
```

**「환경이 우연히 막아 줌」**입니다 — 코드가 막은 게 아니라 **창이 없었어요.**
`momentDom`에 url을 넣어 고쳤습니다. 🔒 넣기 전에 확인했습니다: 아무도 안 심으면
`getItem`이 `null`이라 **예전 검사들의 결과가 한 톨도 안 바뀝니다** (손 안 댄 16종 재실행 — 실패 0건).

🔒 **문턱 60%는 한 톨도 안 건드렸습니다** — 틀렸던 건 문턱이 아니라 **표본**이었어요.
