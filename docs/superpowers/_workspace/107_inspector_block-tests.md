## 4. 🔴 되돌려 묻습니다 — **harness의 가짜 `rAF`가 게임을 얼립니다**

**②를 넣고 나서야 보였습니다.** `.w2m-blk-go`가 **1196번 떴는데 0번 눌림**으로 찍혔어요.
12초 내내 화면에 있었다는 뜻입니다 — *"~1.7초 뒤 스스로 끝난다"*가 **거기서는 거짓**이었어요.

```js
window.requestAnimationFrame = (cb) => setTimeout(() => cb(0), 0);   // ❌
```

미니게임은 `dt = (t − last) / 1000`으로 갑니다. **`t`가 늘 0**이면 첫 프레임 `dt`가 큰 음수,
그 뒤로는 0이라 **상대가 제자리에 얼어붙어요.** 결과:

- 스스로 끝나야 할 2단계가 **안 끝납니다** (pump가 12초를 헛돎)
- 눌러도 `pos ≈ 0`이라 **판정이 늘 `s = 0`**
- 🔴 화면은 멀쩡히 그려지니 **아무 검사도 안 웁니다**

`wiring-test.js`는 **고쳤습니다** (`cb(performance.now())`). 기준선 4.3초로 돌아왔고
`.w2m-blk-go` 커버리지가 **5/5 판 전부** 잡힙니다.

> 🔴 **`tests/winger2/_load.js:270`의 `bootPage`에 같은 줄이 그대로 있습니다.**
> `town-test` · `foot-map-test` · `youth-moment-test` · `school-test` · `creation-test` …
> **bootPage를 쓰는 검사 전부가 「얼어붙은 미니게임」을 재고 있을 수 있어요.**
>
> 🚧 **제가 안 고쳤습니다.** engineer가 `town.js`·`game.js`를 잡고 있어서 **움직이는 표적**이고,
> 그 한 줄이 여러 검사의 타이밍을 한꺼번에 바꿉니다. **다음 라운드에 조용한 판에서**
