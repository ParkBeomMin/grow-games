## 2-3. 🔴 `deal()` 함정 — designer가 짚어 준 자리

```js
// 🔴 옛 것 — CARDS를 3종 → 2종으로 줄이면 n:3이 조용히 2장이 됩니다
const n = Math.max(1, Math.min(CARDS.length, stage.n));
```

**`CARDS`는 3종 그대로 뒀습니다.** 대신 `PLAYABLE`(화면을 여는 종류)에서 뽑고,
`Math.min(CARDS.length, …)`을 **일부러 뺐어요.**

종류 수(2)보다 많이 뽑아야 해서 중복이 필요한데, 칸마다 독립으로 뽑으면 **세 장이 다 ⚽**인 판이
나옵니다. 그래서 **종류를 필요한 만큼 되풀이해 깔고 섞어서** 앞 n장을 씁니다.

**실측 (20만 판)**

| 단계 | 뽑은 장수 | ⚽ | 🅰️ |
|---|---|---|---|
| 초등 `n:2` | **2.000** ✅ | 1.000 | 1.000 |
| 중·고 `n:3` | **3.000** ✅ | 1.499 | 1.501 |

✅ 장수가 안 깎입니다 · ✅ 종류마다 기대 장수가 `n ÷ 2`로 같아요(§7 `fit`의 균등성).
