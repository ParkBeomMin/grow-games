> 🔴 **조립대를 아크 앞으로 옮기면 몸에 개인차가 생기고, 잘 굴린 몸은 `d`가 양수 쪽으로 치우칩니다.**

> 🔴 그리고 §5-2의 **「층이 하나씩 쌓인다」**(학교=조작만 → 유스=조작+능력치 → 프로=+팀)도 무너집니다.

## 4. 🚨 덤으로 찾은 것 — **§5-3의 대칭이 「거의」 성립하고 있었습니다**

`tests/winger2/town-neutral-test.js:331`이 이미 지적해 둔 불일치입니다:

```
PEER_REF.town = 32.0      vs      evenStats() 평균 = 194 / 6 = 32.333…
→ 비율 1.0104
→ autoP 가 ⅓ · ½ 이 아니라  0.3368 · 0.5052
```

### 🔴 그러면 **카드의 평균이 정확히 1이 아닙니다**

§5-3의 대칭 논증은 **모든 카드가 「평균 1 · 1 축 대칭」**이라는 데 기댑니다. 다시 재면:

| kind | `p` | 평균 |
|---|---|---|
| ⚽ 🅰️ | 0.3368 | `2(0.3368) + 1(0.3316)` = **1.0052** |
| 🧱 | 0.5052 | `2(0.5052)` = **1.0104** |

**8장 합의 중립이 `8`이 아니라 `8.05`쯤입니다** → `d = 0`이 진짜 중립보다 **살짝 아래**.

🔑 **그리고 이게 engineer가 잰 값과 맞습니다:**

| | `E[spotMul]` |
|---|---|
| N=2 | 1.00019 |
| N=5 | 1.00057 |
| N=8 | **1.00094** ← 카드가 늘수록 커집니다 |

> 🔑 **누적 편향의 모양 그대로예요.** *"±0.5% 안이라 통과"*로 넘어갔던 그 0.094%가
> **어디서 오는지가 밝혀졌습니다** — 우연이 아니라 **원인이 있는 편향**입니다.

### ★ 고치는 법 — **한 줄이고, 종속값으로 적습니다**

```js
/* 🏘️🏫 학교 아크 — 🔗 **종속값입니다.** `evenStats()`의 평균과 **정확히 같아야**
 * 비율이 1.000이 되고, 그래야 카드 평균이 정확히 1이라 §5-3의 편차 밴드 대칭이
```
