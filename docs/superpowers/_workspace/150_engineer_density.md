### `beta/winger2/match-scene.js` — 🔴 `delayOf` 갈래 **하나만**

```js
const FLOW_MS = 620;
function delayOf(card) {
  if (S.fast) return 90;
  const d = Math.abs(S.h - S.a);
  const base = d <= 1 ? 900 : d === 2 ? 600 : 350;
  const flowish = !!card && (card.kind === "filler" || card.kind === "kick" || card.kind === "end");
  return flowish ? Math.min(FLOW_MS, base) : base;
}
```

- `push()`의 **비-순간 갈래** 한 자리만 `delayOf(card)`로 바꿨습니다. `openMoment()`는 `delayOf()` 그대로예요.
- 🥅 `half`는 `push`의 이 `await` **뒤**에 갈리는데 `kind === "half"`가 `flowish`가 아니라 **900ms 그대로**입니다.
- 🔒 **620이 514ms 종속값**이라는 것을 주석에 그대로 적었습니다 (설계 §11 요구). `Math.min`인 이유(3점 차에서 거꾸로 느려짐)도 함께.
- 🔴 점 움직임·`setPitch`·`fxRnd`·인라인 `transform`/`transition-delay` — **한 글자도 안 건드렸습니다.**
