## 1. 🔴 뿌리 ① — `passStage`가 「누름」을 「카드」로 셌습니다

### 무엇이 어긋났나

`tests/winger2/_load.js`의 `passStage`가 **`#btn-town-next`를 누른 횟수**를 그대로
`data-stage` 배열에 밀어 넣고 있었습니다. 🏁 [경기 시작]이 붙으면서 한 단계의 누름이

```
🏁 시작 → 카드 0 · [다음 판] → 카드 1 · … · [다음 단계] → 카드 없음
```

이 되어 **`deck.length + 1`**이 됐고, 드라이버는 그 마지막 누름까지 카드로 셌어요.
그래서 **아크 8장이 11장으로** 보였고 여섯이 한꺼번에 빨간불이 났습니다 —
`T-5` · `T-6a` · `M-R` · `S-6` · `S-6b` · `O-3`.

🟢 **덱은 그대로였습니다.** `school-test` S-7a가 `deal()`을 60,000판 굴리며 그 내내 초록불이었고,
S-6b의 *"선언 2/2/2 → 실제 3/3/3"*이 **언제나 정확히 선언 + 1**이었어요 — 이게 결정적 증거입니다.
「덱이 늘었다」면 단계마다 늘어나는 양이 달랐을 겁니다.

### 어떻게 고쳤나 — 「굴러간 카드」를 셉니다

`tests/winger2/_load.js:passStage`

```js
const DONE_DOTS = "#town-prog .town-dot.hit, #town-prog .town-dot.mid, #town-prog .town-dot.bad";
…
const before = dots();
press(b, "🏫 다음");
for (let k = dots() - before; k > 0; k--) seen.push(stage);
```

🔴 **버튼 글자로 안 가릅니다.** *"🏁 경기 시작이면 세지 마라"*로 적으면 **문구가 바뀌는 날
조용히 죽습니다** — 이 저장소의 「문자열 매칭」 그 자리예요. 대신 **판이 실제로 움직였는지**를 봅니다:
`#town-prog`의 「끝난 점」이 그 누름으로 **늘었는가**.

🔑 **`T.cards()`를 안 씁니다.** 그건 `state.cards`인데, `T-6a`가
*"`stages`가 `ee`이고 `cards2`가 2"*를 같이 단언해요 — 같은 계수기로 재면 **자기 자신과 비교**가 됩니다.
`#town-prog`은 `progHTML(deck, i)`가 그리는 **다른 계수기**라 둘이 독립으로 남습니다.

🔒 **한 누름이 두 장을 굴리면 두 칸을 넣습니다.** 이중 탭이 실제로 두 장을 태우는 날
「8장」이 그대로라 안 잡히면 안 되니까요. 누름 수는 `seen.presses`·`seen.kick`으로 같이 돌려줍니다
(배열이라 `join`·전개·`filter`는 그대로 돌고, **기존 호출부는 한 줄도 안 바뀌었습니다**).

### 그리고 그 셈을 지키는 검사를 세웠습니다 — `T-7c`

```
T-7c. 🏁 한 단계의 누름이 「굴러간 카드 + 1」이다
  🏫 초5: 누름 3회 → 굴러간 카드 2장 [ee] · 첫 누름이 킥오프였나 ✔
```

🔴 **두 방향을 다 막습니다:**
- 🏁 킥오프가 사라지면 → 누름이 카드와 **같아져** 빨간불
- `passStage`가 다시 「누름 = 카드」로 돌아가면 → 카드가 3장으로 **불어나** 빨간불

한쪽만 재면 다른 쪽이 조용히 지나갑니다.

## 2. 🔴 뿌리 ② — `T-7`의 `hasMoment`가 옛 계약이었습니다

### 무엇이 틀렸나

```js
hasMoment: !!(cardBox && cardBox.querySelector('[class*="w2m-"]')),   // 도착 직후
check(… && r.hasMoment, "T-7. 첫 순간 카드 「앞」의 결정이 8개다")
```

*"들어서자마자 카드가 떠 있다"* — **범민 님이 없애 달라신 그 동작을 검사가 지키고 있었습니다.**
제 「설계가 뒤집히면 검사가 옛 계약을 지킨다」 절의 세 번째 사례예요.

### 뒤집어서 더 세게 — `T-7b`

**지우지 않고 뒤집었습니다.** 그리고 뒤집는 김에 **한 문장 안에서 두 쪽을 같이** 봅니다:

```
T-7b. 🏁 들어서면 순간 카드가 없고, 진행 버튼을 눌러야 뜬다
  도착 screen-town: 카드 없어요 ✔ · 진행 버튼 눌릴 수 있어요 ✔
  한 번 누른 뒤 screen-town: 카드 떴어요 ✔
```

🔴 **「없다」만 재면 미니게임이 안 실려도 초록불입니다** — 「환경이 우연히 막아 줌」의 모양이에요.
그래서 **눌렀더니 떴다**를 같은 문장에 넣었습니다.
🔴 **버튼 글자를 안 봅니다.** 보는 것은 **누르기 전 0장 · 누른 뒤 1장**뿐이에요.

### 성질이 다른 것을 안 묶었습니다

`T-7`(결정이 8개다)에서 `hasMoment` 절을 **떼어냈습니다.** 탭 예산과 킥오프는 다른 문장이라,
묶여 있으면 «킥오프가 죽었다»가 «탭 예산이 깨졌다»로 읽힙니다.
변이 `M-K`가 그걸 증명합니다 — **`T-7b`만 갈리고 `T-7`·`T-7a`는 초록불로 남습니다.**

## 3. 🐛 director의 셋 — 검사가 0건이었습니다

**셋 다 되돌려도 아무도 안 울었습니다.** `tests/winger2/pitch-test.js`를 새로 세웠어요
(검사 8 · 변이 5 · 약 12초).

### 왜 jsdom으로 재나 — CSS를 **소스가 아니라 캐스케이드로** 봅니다

`②`(🧡 나가 우리 편과 같은 초록)는 **소스만 읽으면 앰버라고 적혀 있습니다.**
문자열로는 절대 못 잡아요. 그래서 `style.css`를 **진짜 스타일시트로 물리고**
`getComputedStyle`로 **누가 이겼는지**를 읽습니다.

🔑 **`var(--x)`를 이름마다 다른 색으로 갈아 넣습니다.** jsdom이 사용자 정의 속성을 못 풀어
`background: var(--good)`을 통째로 버리거든요 — 그러면 우리 편도 나도 `transparent`가 되어
**버그가 있어도 없어도 「같은 색」**이 됩니다. 색을 고르는 게 아니라
**어느 변수가 캐스케이드에서 이겼나**를 읽는 치환이라, 팔레트를 바꿔도 안 흔들려요.

|---|---|
| `P-1-0` | 🔒 전제 — 판이 `overflow: hidden`이고 밀림 규칙 **4줄**이 실제로 걸렸다 |
| `P-1` | 🧤 **판 밖으로 나가는 점이 없다** — 카드 상태 48개 · 점 576개 |
| `P-2-0` | 🔒 전제 — 점에 배경색이 **실제로** 걸렸다 (스타일시트가 안 물리면 여기서 걸립니다) |
| `P-2` | 🧡 **「나」의 색이 우리 편과 다르다** — 특이도로 실제로 이기는가 |

### ① 🧤 골키퍼 — **두 파일 사이의 계약**입니다

`match-scene.js`의 `FORM_H`(자리 %)와 `style.css`의 `push-*`(밀림 %)는 **한 쌍**이에요.
한쪽만 읽으면 안 보입니다. `P-1`은 **양쪽을 같이 열어** 최악의 밀림을 얹은 자리를 계산합니다.

🔒 **문턱을 적기 전 두 줄**(CLAUDE.md 원칙 ⑦):
- **무엇과 견주나** — 원의 **바깥 테두리**를 판 상자의 `0`/`W`에 견줍니다. 값이 아니라 **관계**예요
- **격자의 어느 칸에서 재나** — **가장 좁은 칸 하나**: 판 `280 × 76px`.
  넓은 칸은 언제나 더 헐거워요(px 여유가 폭에 비례)라 최악만 재면 충분합니다.
  · 폭 280 = 320px 화면에서 카드 여백을 넉넉히 뺀 값 · 높이 76 = CSS `clamp`의 **최솟값**

🔒 자리·크기·밀림은 **소스에서** 뜯고, 판 크기와 「안에 들어온다」는 **검사에 박습니다** — 방향이 반대입니다.

변이를 **양쪽에서** 겁니다 — 자리를 옮겨도(`M-GK`) 밀림을 키워도(`M-PUSH`) 같은 흠이 나거든요.
**한쪽만 재는 검사는 다른 쪽이 움직인 날 조용히 통과합니다.**

### ③ ⚽ `closeMoment` — 값이 아니라 **진영**을 봅니다

`P-3a`는 자리(%)가 아니라 **어느 진영인가**를 단언합니다. 표의 숫자를 정당하게 손봐도
「골은 상대 골문 쪽」이라는 문장은 그대로 살아야 하니까요.
`P-3`은 **열림 자리 ≠ 결과 자리**를 봅니다 — `setPitch`가 빠지면 18갈래가 **전부** 안 움직여요.

🔑 변이 `M-CLOSE`의 판정문에 *"몇 갈래가 여전히 움직이면 **같은 일을 하는 줄이 또 있다**"*를
