## 1. 🥈 검사 44 — **상들의 격이 뒤집히지 않는가** (§2-10 여섯 번째 냄새)

engineer 제안대로 **여섯 상수를 소스에서 각각 뜯어** 서로 비교합니다. 검사에 값을 안 박아요 —
`AXIS_OFF`나 `bar`가 움직여도 **둘 다 `× bar`라 관계는 그대로 유효**합니다.

```
🥈 뜯어온 문턱 — 🏆 MVP: 게이트 5.5 · rand(3.5, 7.8)의 최대 6개
              ·  🥈 베스트11: 게이트 5.8 · rand(5.5, 8) 한 번
```

### 44-1 · 44-2 — 관계와 구조

```
✅ 44-1. 베스트11 상한이 리그MVP 상한을 의미 있게 넘지 않는다 — 8.0 ≤ 7.8 + 0.2
✅ 44-2. **MVP만 6개 뽑기의 최대**와 겨루고 베스트11은 **한 번**만 뽑는다
```

> 🔑 **44-2를 따로 건 이유**: 문턱은 오히려 베스트11이 **더 높습니다**(5.8 > 5.5).
> 낮은 상이 더 쉬운 진짜 이유는 **MVP가 여섯 번 중 최대와 겨루기 때문**이에요.
> 그 구조가 사라지면 문턱을 어디에 놓아도 등급이 안 섭니다 — 44-1만으로는 그걸 못 봅니다.

### 44-3 🚧 — **역전 창은 이미 있습니다.** 해석적으로 찾았어요 (표본 0)

두 확률이 닫힌 형태라 시뮬레이션 없이 계산됩니다 (`bar`가 약분돼 리그와 무관):

```
P(🥈 | h) = [h ≥ 5.8] × clamp((h − 5.5)/(8.0 − 5.5), 0, 1)
P(🏆 | h) = [h ≥ 5.5] × clamp((h − 3.5)/(7.8 − 3.5), 0, 1)⁶
```

```
   hype/bar별 🥈/🏆 — 6: 20/4 · 6.5: 40/12 · 7: 60/29 · 7.5: 80/65 · 7.8: 92/100 · 8: 100/100

🚧 44-3. 좁은 역전 창이 이미 있습니다 — hype/bar **7.71 ~ 7.99** (가장 깊은 곳 **8.0%p** @ 7.80)
         🏆가 7.8에서 100%에 닿는데 🥈는 8.0까지 못 닿아서 생기는 창이에요
         (게이트 구간 5.5~5.8은 뺐습니다 — 거기 🏆 확률은 최대 2.3%로 설계 그대로)
✅ 44-3-상한. 역전 창이 더 깊어지지 않았다 — 8.0%p ≤ 15%p
```

> ### 🟠 **150의 여유 0.4%p가 바로 이 창입니다**
> engineer가 짚어 주신 자리를 검사가 **직접 찍습니다.** 유효 능력치 150의 평균 hype가
> **8.30**이라 창(7.71~7.99) 바로 위에 서 있어요 — 분포의 아래꼬리가 창을 밟습니다.
> 그래서 통합 수상률이 98.2% vs 97.8%로 **붙는** 겁니다.
>
> **지금은 역전이 아닙니다.** 다만 MVP 문턱이나 `AXIS_OFF`가 움직이면 **여기가 먼저 뒤집혀요.**
> 그래서 값을 박는 대신 **창의 깊이에 상한**을 걸었습니다 — 현상은 기록하고 회귀는 잡습니다.

### 44-변이 — 상한 8.5

```
✅ 44-변이. 상한을 8.5로 올리면 → 빨간불
   (44-1: 8.5 > 7.8 + 0.2 · 역전 창이 8.0%p → **23.3%p**, hype **7.53**부터 뒤집힘)
```

engineer 실측(130에서 80.6% vs 86.4% · 150에서 92.2% vs 97.4%)과 **같은 방향·같은 크기**입니다.

## 2. 🌱 검사 41b — **절대값을 다시 재지 않았습니다**

designer 하한(최악 조합 ≥ 7경기)을 박되, **제 자로 8.0을 재려 하지 않았습니다.**

### 왜 — balancer 분해를 제 자에서 확인했습니다

| 제 자 (fw · 전력 62 · 150시즌) | 값 |
|---|---|
| 폼 미설정 · 정점 71.9 고정 | **3.3** |
| 폼 6.65 · 정점 71.9 고정 | **3.7** |
| 폼 6.65 · 정점 **46.9 고정** | **0.0** |
| **balancer 자** (46.9 시작 → **시즌 중 성장** · 컨디션 고리) | **8.0** |

폼(②)을 고쳐도 3.7입니다. 남은 건 **①「시즌 중 훈련으로 자람」**이고,
그걸 재현하려면 **커리어 앙상블을 다시 짓는 것**이에요 — 그건 balancer의 자입니다.
제가 여기서 7을 박으면 **하네스 이유로 영영 빨간불**인 검사가 됩니다.

### 그래서 — 유효 조건을 지킵니다 (`league-test` 33-B와 같은 방식)

```
✅ 41b. 최악 조합 하한(7경기)이 유효한 조건이 그대로다 — balancer 자로 지금 8.0
        (데뷔 만 20세 · ⚔️ 자리 2개 · 데뷔 클럽 52/57/62 · 🌱 18세 +18%)
        👉 여유가 **1경기뿐**입니다 — "8.0이 6.0이 되면 「버틴다」가 아니라 「안 준다」"
```

넷 중 **하나라도 움직이면 8.0이 무효**이고, 그때 *"balancer에게 5-i 재측정을 요청하세요"*가 뜹니다.

### 제 자로는 **관계만** 봅니다 — 절대값은 달라도 순서는 같아야 합니다

```
✅ 41b-2. 클럽이 셀수록 덜 뛴다 — 전력 52 → 17.8 · 57 → 8.5 · 62 → 3.6
✅ 41b-3. ⚔️ 공격수가 네 포지션 중 가장 적게 뛴다 (fw 10.0 · wg 20.6 · mf 27.6 · df 24.6)
```

뒤집히면 **자리 수가 바뀐 것**입니다. 절대값이 갈려도 이 두 문장은 두 자에서 다 성립해요.
