`passTown`을 async로 바꾸면 **부르는 쪽이 전부 async**가 돼야 합니다:

| 파일 | 연쇄 |
|---|---|
| `worldcup-test` | `careerAt` → `scan` → 최상위 |
| `youth-card-test` | `sweep` → `mutCheck` · 최상위 |
| `youth-clamp-test` | `playthrough` → `gather` → `mutCheck` · 최상위 |
| `youth-ability-test` | `boot` → `sweep`·`roomRows`·`policyRows`·`axisRows` → 변이 다섯 · 최상위 |
| `bench-test` | `toBench` → `benchProbe` → `mutRun` · 최상위 |
| `grade-test` | `toBench` → `careers`·`drawProbe` → `mutRun` · 최상위 |
| `foot-map-test` · `youth-moment-test` | 감싸는 함수가 **이미 async**라 `await` 한 줄씩 |

🔒 **최상위 코드는 `(async () => { … })();`로 감쌌습니다** — CJS에는 top-level await이 없어요.
🔴 `.map((seed) => … await …)`는 **for 루프로 폈습니다** — 화살표는 async가 아니라서요.

### 9-2. ⏳ 실행 시간이 늘어난 자리

🔴 이 여덟은 **원래 동기라 대기가 0초**였습니다. 이제 단계마다 `stageIdle()`을 기다려요.
🔒 그래도 벽시계 문턱은 안 만들었습니다 — 기다리는 것은 **버튼이 살아나는 신호**입니다.
🔴 **`offer-test`가 10분을 넘습니다** — 전량 실행을 `timeout 600`으로 돌리면 **exit 124**가 나요.
   그건 **검사의 빨간불이 아니라 제 상한**입니다(단독 실행은 ✅ 26/26 · 종료 0).
   📌 전량 스크립트의 상한을 **20분 이상**으로 잡으세요 — 아니면 「빨간불」과 「시간 초과」가 섞입니다.
📌 그중 `youth-clamp-test`가 가장 무겁습니다(플레이스루 × 변이). 더 길어지면
**표본 수(`RUNS`·`MUT_RUNS`)를 designer와 상의해 줄이는 쪽**이지, 대기를 줄이는 쪽이 아닙니다 —
대기를 줄이면 다시 「한 번 누르고 끊김」이 되고 그건 **공짜 초록불**이에요.
