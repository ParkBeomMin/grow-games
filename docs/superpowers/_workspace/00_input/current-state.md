조사일 2026-08-28 · 대상 `beta/soccer/` (v2.53.0 기준)
근거는 전부 파일:줄번호로 확인했습니다.

## 2. 박진감이 없는 구조적 이유

### ① 결과가 확정된 뒤에 중계가 재생된다

`career.js:1685-1706`에서 **골·도움·실점·승패가 전부 확정**된 뒤 `MatchSim.run`이 호출됩니다.
`game.js:2082-2118`은 확정값을 분 순으로 정렬해 재생만 해요.

그래서:
- 스코어보드가 **뒤집히는 순간이 없습니다** (동점/역전이 이벤트가 아니라 그냥 다음 줄)
- 시계(`sb-min`)가 이벤트가 있을 때만 튑니다 (`game.js:2124`) — 흐르지 않아요
- 남은 시간·추가시간 개념이 없어 **"1점 차 후반 90분"의 압박이 구조적으로 생길 수 없습니다**

실점 하나를 승부처까지 유보하는 장치(`game.js:2114 holdConceded`)가 있지만
**수비수 포지션에서만** 작동합니다.

### ② 90분에 개입 1번, 그마저 78분 이후

`game.js:2119`가 승부처를 **항상 78~88분에 고정**합니다.
그 앞은 0.78초 간격 텍스트 4~8줄이고, **0-0 경기면 중계가 딱 2줄**(킥오프 + 필러)이라
1.5초 만에 승부처로 직행해요. `⏩ 빨리감기`(`game.js:2203`)를 누르는 게 언제나 합리적입니다.

`🤖 경기 자동 진행`(`game.js:1891`)을 켜면 **그 1번마저 확률 굴림으로 대체**됩니다.

실제 게임 루프는 `[경기 시작] → [미니게임] → [결과]` 3탭으로 축약돼요.

### ③ 골이 들어가도 아무 일도 일어나지 않는다

`fx.js`가 `confetti`/`burst`/`flash`/`celebrate`를 제공하는데
**soccer의 Fx 호출 20곳을 전수 확인한 결과 골에는 한 번도 연결이 안 됐습니다.**
(각성·초월·칭호·이적·우승에만 붙어 있어요)

골 연출의 전부 (`style.css:169-172`, `game.js:2126`):
```css
.pitch.goal-h { animation: sbGoalH 0.55s ease; }   /* 테두리가 0.55초 초록으로 깜박임 */
```

`soccer/style.css`의 `@keyframes`는 총 4개뿐이고 그중 2개는 경기와 무관합니다.
**저장소 전체에 오디오·진동 API 호출이 0건**입니다 — 휘슬조차 이모지 텍스트예요
(`game.js:2168`).

### ④ 필드에 선수가 0명

`game.js:2050-2054` — 필드 위 요소는 **중앙선 1 + 골대 이모지 2 + 공 1, 총 4개**.
높이는 92px (`style.css:155`).

```js
const moveBall = (side) => {                                    // game.js:2063-2067
  b.style.left = (side === "atk" ? 82 : side === "def" ? 18 : 50) + "%";
  b.style.top  = (26 + Math.random() * 46) + "%";               // ← 랜덤. 흐름과 무관하게 튑니다
};
```

`splitMine`(`career.js:886`)이 이미 선발 11명과 각자의 자리(CAM/LW…)를 알고 있는데
**그 정보가 화면에 전혀 안 쓰입니다.**

### ⑤ 미니게임이 축구가 아니라 8종 공용 위젯

`timing.js`는 야구 기본값을 가진 범용 모듈입니다
(`icons: ["⚾","🧢","🧤","🏏"]` — `timing.js:133`, `choices: ["몸쪽","가운데","바깥쪽"]` — `timing.js:221`).
`game.js:1926-1978`은 **라벨과 이모지만 갈아끼웁니다.**

그래서 "슛"이든 "태클"이든 화면에서 하는 동작은 **좌우로 움직이는 막대를 멈추는 것**으로 동일해요.
축구다운 조작은 승부차기(`cup.js:135`) 하나인데 **컵 무승부에서만** 열립니다.

## 3. "내 선수" 같지 않은 이유

### 플레이어가 정하는 것의 전부

유스 5개 × 포지션 4개 × 주발 2개 × 이름(자유) + **무제한 리롤** = 실질 조합 40가지

| 항목 | 어디 | 비고 |
|---|---|---|
| 유스 배경 (사실상 국적) | `game.js:17-48` | growth·spot·home 3개 숫자 |
| 포지션 4종 | `game.js:63-68` | 골키퍼 없음 (`squad.js:26`) |
| 이름 (8자) | `index.html:90` | **개명 불가** |
| 주발 | `game.js:1414-1422` | **아무 일도 안 함** (아래) |
| 초기 스탯·재능 | `game.js:439-449` | `randInt(24,38)`, 재능 `rand(0.8,1.45)` |

### 비어 있는 지점 다섯

**① 주발을 고르게 해놓고 아무 일도 안 합니다.**
`career.js:1312-1315`가 직접 인정해요 — *"주발은 지금 아무것도 안 합니다
(제보: '주발이 영향주는 건 뭐야??')"*. 세부 포지션이 이미 들어왔는데도
효과는 자리 배정 궁합 ±4%(`squad.js:82 FOOT_FIT`) 하나뿐이고 골·도움·평점 어디에도 안 닿습니다.

**② 플레이어만 나이가 없습니다.**
NPC는 `age`·`peak`·나이곡선(18세 0.68 → 27세 1.00 → 35세 0.82)을 전부 갖는데
(`squad.js:131-146`), 플레이어는 `S.proYear`(1~15)가 대신하고 노쇠는
**재능도 포지션도 안 보는 일률 감소**입니다:

```js
else if (S.proYear >= DECLINE_FROM) S.stats[d.key] -= rand(0.6, 1.8);   // career.js:2364
```

키·체격 개념 자체가 없어 헤딩·몸싸움 같은 축이 만들어질 수 없어요.

**③ 성격/플레이스타일이 없습니다.**
`traitOf(S)`(`game.js:154-157`)는 이름만 trait이고 내용은 **소속 리그 나라의 특색**입니다.
개인차를 담는 곳은 6스탯 + 6재능 + 약발뿐이고,
`clutch()`(`game.js:832-835`)는 폭이 **±6%**라 "큰 경기에 강한 선수"가 노이즈 수준이에요.

**④ 포지션 전환이 불가능합니다.**
`S.pos` 대입은 `newState`(`game.js:471`) **단 한 곳**뿐. "윙어 → 풀백 전향" 같은
축구의 대표적 서사가 구조적으로 막혀 있어요.
게다가 `FORMATION = { fw:2, wg:2, mf:4, df:3 }`(`squad.js:26`)라
**공격수·윙어를 고른 플레이어는 2자리를 놓고 경쟁하는데 탈출구가 없습니다.**

**⑤ 시작 선택에 무게가 없습니다.**
리롤 버튼(`game.js:463-466`)에 **횟수·비용 제한이 전혀 없어요.**
설계 의도(`game.js:655` *"능력치 다섯은 훈련으로 올리는 값이지만, 약발은 타고나고"*)가
스탯·재능에서 무력화돼 있고, 정작 약발만 리롤 대상이 아니라 기준이 뒤섞였습니다.

또 유스 5종은 라벨 + 숫자 3개뿐이라 **"유스에서 무엇을 배웠나"가 초기 스탯에 반영되지 않아요** —
브라질 유스로 시작해도 드리블이 안 높습니다 (브라질 보너스는 그 **리그에서 뛸 때만** 붙어요,
`game.js:148`).

## 4. 성장 — 수직만 있고 수평이 없다

성장 경로는 여덟 개나 되는데 **전부 "숫자를 올린다"입니다.**

| 경로 | 어디 |
|---|---|
| 유스 훈련 (3년 × 12턴) | `game.js:1567-1605` |
| 프로 훈련 (시즌 3턴 + 경기 사이 2턴) | `career.js:1598-1636` |
| 실전 성장 (그 경기에 한 일이 무게) | `career.js:1859-1926` |
| 벤치 주 성장 | `squad.js:697-717` |
| 시즌 결산 자동 성장/노쇠 | `career.js:2362-2365` |
| 1년 특훈 (유스 실패 시 1회) | `camp.js` |
| 각성 / 초월 | `game.js:871-954` |
| 약발 (경기에서만) | `career.js:1874-1879` |

**해금되는 것, 새로 할 수 있게 되는 것이 없습니다.**
특수능력·트레잇 같은 수평 성장 축이 전무해서 후반이 클릭만 남아요.

성장 구간 (`career.js:379-381`):
```js
const CAREER_MAX = 15; const GROW_UNTIL = 4; const DECLINE_FROM = 11;
```
→ 1~4시즌 성장기 / 5~10시즌 **정체(훈련만)** / 11~15시즌 노쇠

### 능력치 6종과 실제로 하는 일

| 스탯 | 하는 일 |
|---|---|
| ⚽ 슛 | 골 기댓값 `gLam` 주축 |
| 🎯 패스 | 도움 기댓값 `aLam` 주축 |
| 🏃 드리블 | **윙어 한정** 골·도움에 40% 혼합. 그 외엔 미니게임에만 |
| 🛡️ 수비 | 수비성공 `dLam` 주축 |
| 🫀 체력 | 평점 계수 0.10 + 컨디션 소모 감소 (최대 −30%) |
| ⚡ 스피드 | 골·수비에 20% 혼합 (`SPD_MIX`), 패스엔 안 붙음 |

> `career.js:43-47` 주석의 실토: *"⚡ 스피드를 넣었더니 종합에는 들어가는데 경기력에는

상한: `STAT_CAP = 130`(`game.js:436`), 초월 단계마다 +6 (`game.js:821`)

## 6. v2에서 가장 조심할 것

- **새 축을 얹는 것만으로 세지면 안 됩니다.** 세부 자리를 넣을 때 가중 평균을 1로 안 맞춰
  골든부츠 수상률이 **43% → 60%**로 튀었습니다
- **순위 기반 평가는 천장이 있습니다.** 능력치 90 → 150에서 결과가 76%로 평평했던 사고
- **누적되는 값은 20시즌 굴려 보세요.** 신인 peak 계산을 뒤집기 전에는 리그 평균이
  20시즌에 **+13.8**까지 부풀었습니다
- v2는 **새 슬러그·새 SAVE_KEY**입니다. 기존 `winger-save-v1`을 절대 재사용하지 마세요
