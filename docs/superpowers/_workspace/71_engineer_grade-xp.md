## 3. 🔑 어떤 값을 등급으로 옮기는가 — **정점 기준값(`S.stats`)**

```
S.stats   = 정점 기준값.  훈련·각성·장비가 올리는 건 이 값
지금 실력 = 정점 기준값 × 나이곡선   ← 경기 판정과 레이더가 보는 값
```

| | 왜 정점 기준값인가 |
|---|---|
| ① **화면의 숫자와 어긋나면 안 돼요** | 능력치 화면이 `61`을 찍는데 등급을 다른 값에서 뽑으면 `61 [E]`가 화면에 남습니다 |
| ② **훈련이 등급을 밀어야 합니다** | 지금 실력으로 매기면 **나이 한 살이 훈련 여섯 달보다 큽니다** — 승급 카드가 *"내가 한 일"*이 아니라 *"달력이 넘어간 일"*이 돼요 |
| ③ **유망주 3장이 전부 `F`로 깔립니다** | 열여덟의 곡선이 0.56~0.84라 18~54가 10~45로 눌려요 (실측 확인) |

**등급을 매기는 입력은 `Math.round(v)`** — 능력치 화면이 찍는 그 정수와 **같은 자**입니다.
소수로 재면 `40 [F]`처럼 경계에서 한 칸 어긋나요.

> ⚠️ 유망주 카드에서는 **등급(정점 기준)과 레이더(지금 실력)가 서로 다른 것을 그립니다.**
> designer가 B3 견주기 시트에 못박은 구분이에요. `📊 다 자랐을 때` 캡션이 그 말을 합니다.

## 4. XP 바 — 새 자원이 아니라 **파생값**

```
cur  = round(v) − 구간하한
need = 다음 구간하한 − 구간하한        (S는 null · 바가 꽉 참)
pct  = cur / need
```

단위는 **능력치 1점**. 세이브에 XP를 따로 안 저장해요 — 읽는 건 `S.stats`뿐입니다.
**라벨은 문턱을, 바는 진행을** 맡습니다 (designer 이유 ③).
