### 3 — 표시 %의 칸 안 폭 · 강한 선수의 천장 → 공통식

**무엇을** (A-1 · A-3 · A-4 끝 칸)
```
표시 % = round( clamp( 50 + 실력 + 컨디션 , 10, 90 ) )
실력   = clamp( k·X − Mₑ , −10, +10 )           X·k는 이벤트마다, Mₑ = 뜬 순간들의 k·X 중앙값
컨디션 = clamp( (컨디션 − C) × 0.6 , −15, +15 )  C = 뜬 순간들의 컨디션 중앙값(제안 65, 🛌만 따로)
```
- 이벤트마다 **실력 조각 하나**(재료 X · 계수 k): 리그 기준과의 차(`p_gap` · `p_marked` · `p_benchseat` · `p_momclip` · 🛌 · `p_mateslump` · 🌍 🎯 · 🕯️ · 🩹) / 선수 고유값(약발 · 재능 ★ · 명성 · 프로 시즌 수 · 이 클럽 시즌 수) / 동료와의 차(📍 📌)
- 결과: 프로 표시 %는 **25~75**. 가운데 맞춤은 이제 「기본 한 벌」이 아니라 **Mₑ 한 벌 + C 하나**
- `pre` 굴림 자리를 **준비 3턴을 마친 첫 경기 직전 화면**(`activity.cb === 1 && week === 0`)으로 — 시즌 첫 화면은 `startPrep`이 컨디션을 80으로 되돌린 직후(`career.js:352`)라 컨디션 조각이 모두 같은 값이 된다. `h2`와 같은 모양이 된다

**왜** — 가장 큰 조각 `(종합 − 리그 기준)`이 칸이 고정하는 값이라 칸 안에서 %가 한 점에 모였고(고정 격자 걸침 0/60), 리그 기준 꼭대기(PL 117.6) 위의 선수는 가운데로 돌아올 리그가 없었다(종합 150: 12/12 칸에서 도전 ≈ 읽기). 칸이 정하는 몫을 ±10에서 자르고(원칙 ⑤), 칸 안에서 **플레이어가 직접 움직이는** 컨디션이 ±15로 가르게 뒤집었다. 20번 §5에서 컨디션 항을 두 종에만 넣어도 51% → 77%였다. 이번 시즌 평점을 안 쓴 이유: 절반을 칸이 정하고 시즌 첫 블록엔 없다.

### 5 — 약속 판정 → 「그리고 승리」

## 5. 경계면 계약에 더할 것 (10번 overview는 이번 수정 범위 밖 — 여기 적어 둔다)

- 이벤트 정의의 확률 조각: 기본값 한 벌 대신 `{ x: (S) => X, k, M }` + 공통 `C`(🛌만 따로) — 화면 조각은 `[기본 50, {재료 이름}, 컨디션]`

- 이야기 결말 id: 🩹에 「서둘렀던 복귀」 하나 추가 · 📍 「벤치에서 쓴 반 시즌」 → 「벤치에서 쓴 계절」(이름만)
