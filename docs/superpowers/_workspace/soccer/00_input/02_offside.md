# 오프사이드(offside-lab.com) — 구조 정리

> 2026-09-28 공개 페이지(홈·/guide/·/faq/)와 브라우저에 내려오는 클라이언트 번들의 문구로 읽었다. 직접 끝까지 플레이한 것은 아니다.
> **여기 적은 것은 구조와 규칙이다. 문장은 일부러 옮기지 않았다 — 설계·구현에서도 그쪽 문구를 쓰지 않는다.**

## 0. 한 줄

고3 시즌부터 은퇴까지를 **글과 확률**로 굴리는 커리어 스토리 시뮬. Svelte + Cloudflare Workers + D1, 구글 로그인, PWA. 무료.
경기는 **구간(프리시즌 · 전반기 · 후반기) 단위로 한 번에 계산**되고 화면에 경기가 안 나온다(결과 줄만 흘러간다).

## 1. 선택 이벤트 — 그쪽 게임의 심장

| 규칙 | 내용 |
|---|---|
| 발생 | 구간마다 확률(프리시즌 / 전·후반기 따로, 운영 패널에서 조정). 스토리의 다음 장은 예정된 때 따로 온다 |
| 반복 억제 | 한 번 나온 이벤트는 최소 N구간 쿨다운 + 가중치 `1/(1+본 횟수)` |
| 선택지 | 보통 2개. **확률 선택지는 % 를 보여 주고 그 % 가 실제 판정값**(0~100 난수 < % 면 성공, 「숨은 보정 없음」을 도감에 명시) |
| 확률의 재료 | 소속팀 전력 · 리그 수준 · 감독 신뢰 · 사기 · 명성 · 컨디션 · 나이 · 부상 정도 · 남은 계약 · 종합 능력치 · 특성. 도감에서 요인별로 보여 준다 |
| 안전한 선택 | 판정 없이 확정. 대신 좋은 효과가 줄고, 일정 확률로 작은 대가 |
| 뜻밖의 반전 | 선택 뒤 일정 확률로 능력치 하나가 ±(성공·실패·안전에 따라 오를 확률이 다름) |
| 포지션 변형 | 같은 사건이 FW/MF/DF/GK 에 따라 선택지·결과 문장이 갈린다(예: 결과를 예고하는 인터뷰 — FW 는 골, MF 는 경기 지배, DF 는 상대 에이스 봉쇄, GK 는 무실점) |
| 도감 | 만난 이벤트에 체크, 진행률, 탭(이벤트 / 성장·부상 / 이적 / 대표팀 / 병역). **「확률을 계산하는 규칙」 한 쪽**이 따로 있다 |

**사건의 종류(범주만 — 60여 종)**
- 감독·출전: 출전 시간 요구, 새 감독의 다른 전술, 포지션 전환 제안, 특별 과제, 강한 압박 전술 적응
- 몸: 훈련 중 통증(참고 뛰기 / 쉬기), 장기 부상 진단(수술 / 보존), 재활 조기 복귀, 체지방·식단, 전담 트레이너 투자(돈)
- 돈·바깥: 광고 제의, 에이전트 계약, 행사 초대(사생활 → 기사 → 벌금), 유소년 재능기부
- 여론: 경기 전 인터뷰 예고, 부진 뒤 악성 댓글, 이적설 대응, 원정 관중 문제 대응
- 경기 순간: 결정적 PK 키커, 승부차기(GK), 1대1 마무리 방식, 프리킥 전담, 코너킥 가담(CB), 최후방 태클, 오버래핑, 득점 1위 전담 마크, 공중볼 장악(GK), VAR 판정 항의, 치명적 실수 뒤 대응
- 커리어: 해외 스카우트 관전, 겨울 이적시장 이적 요청, 포지션 경쟁자 영입, 레전드 선배 조언, 슬럼프, 전지훈련, 올스타전, 프리시즌 투어, 더비 매치, 원더골 투표

## 2. 연속 스토리 — 결말에 이름이 붙는다

여러 시즌에 걸쳐 2~4장 이어지고, **그동안의 선택·판정으로 이름 붙은 결말**이 정해진다. 흐지부지 끝나는 결말도 있다.
완결된 스토리는 선수 화면의 「스토리 앨범」에 남고 업적(「○○ 이야기의 결말」)이 된다.

| 스토리 | 흐름(요지) |
|---|---|
| 라이벌 | 같은 나이·같은 포지션 라이벌 등장 → 대응(공개 도발 / 조용히) → 정면 맞대결 → 대표팀 자리 경쟁 → 결말 넷(넘어섬 / 영원한 2인자 / 동료가 됨 / 어색한 휴전) |
| 재활 | 장기 부상 → 치료 선택 → 재활 속도 선택 → 복귀전 → 결말 셋 |
| 사생활 논란 | 행사 → 기사 → 사과 / 침묵 → 명예 회복 기회 → 결말 넷 |
| 해외 도전 | 에이전트 → 해외 이적 → 적응(언어 / 실력) → 결말 넷(완벽한 적응 / 느린 적응 / 실력으로 증명 / 향수병) |
| 은사 | 감독의 특별 과제 → 은사의 이적 → 따라감 / 남음 → 결말 둘 |

## 3. 커리어 뼈대

- 생성: 이름 · 등번호(주사위) · 포지션 4군(세부 역할 7종) · 주발 · **플레이 유형 12종**(「슈팅 ▲▲ · 수비 ▼」처럼 강점 둘 약점 하나) · **성장 특성 4종**(조기 성장 / 대기만성 / 강철 체력 / 스타성) · 주력 능력치 2개 → **능력치 총합이 같고 분포만 다른 후보 3명의 스카우트 리포트**에서 고른다
- **잠재력은 숨긴다.** 스카우트 등급으로만 보이고 21·24세 재평가에서 좁혀진다. 은퇴 때 공개
- 상태: 컨디션 · 사기 · 인기 · 감독 신뢰 · 자금 · 부상(큰 부상 8~18경기) · 계약(연봉·기간)·시장가치
- 구간 훈련 방향: 능력치 집중 / 휴식 / 개인 코치(돈) / 미디어 활동(인기·돈). 주력 능력치는 빨리, 너무 앞선 능력치는 느리게
- 진로: 고교 → **대학(4년 내 언제든 프로 도전)** 또는 프로 직행 → K3·K2·K1 → J1·MLS·유럽 5대 리그. 재계약·이적·FA·하부 리그 재기·팀을 못 찾으면 은퇴
- 대회: 리그 + 국내 컵 + 슈퍼컵 + 대륙 클럽대회 + 클럽 월드컵. 리그별 개인상, **발롱도르 순위(30인)**, 야신 트로피 등

## 5. 은퇴 — 회고 필름

레전드 점수(포지션별 기여 — 공격은 골·도움, 수비·GK 는 무실점 — + 출전 · 우승 · 개인상 · A매치 · 최고 능력치 · 발롱도르/월드컵 보너스)와 등급 5단.
은퇴 화면이 **스크롤로 넘기는 한 편의 필름**이다:

1. 이름 · 나이 · 마지막 클럽 · 레전드 점수
2. **The Journey** — 클럽 하나가 한 장(기간 · 리그 · 경기 · 골 · 도움 · 무실점)
3. **For the Country** — A매치 · 대회
4. **Honours** — 우승 연혁
5. **Scout Report** — 끝까지 숨겨져 있던 잠재력 공개, 「스카우트 평가보다 컸다 / 못 미쳤다 / 정확했다」
6. **How You Played — 플레이 성향 11유형**: 확률 선택의 습관과 운으로 정한다(원클럽 / 운이 좋았다(기대보다 성공이 많다) / 낮은 확률에 걸었다 / 떠돌았다 / 운이 나빴다 / 사다리를 올랐다 / 돈을 봤다 / 의리 / 안전 제일 / 계산된 모험 / 균형). 「기대보다 N번 더 성공」, 「커리어 최고의 한 수: 성공 확률 N%였던 ○○」
7. 시즌별 기록 · 레전드 점수 구성(접힘)

## 6. 업적(칭호)

50여 개. 분류 6(기록 · 여정 · 개인 수상 · 국가대표 · 이야기 · 은퇴), **희귀도 4(일반 · 희귀 · 영웅 · 전설)**. 칭호 도감(얻은 것 / 못 얻은 것 수), **대표 칭호**를 골라 선수 카드·명예의 전당에 표시.

## 7. 서버 기능

| 기능 | 규칙 |
|---|---|
| 홈 라이브 현황 | 지금 뛰는 중 · 오늘 치른 시즌 · 오늘 새 선수 · 오늘 은퇴 + 최근 기록 줄(「○○에서 첫 시즌을 마쳤어요」「은퇴 · 레전드 점수 N」, N분 전) |
| 서버 최초 기록 | 업적마다 **전 서버에서 처음 달성한 선수**. 이름은 공개한 선수만, 아니면 익명 |
| 영구결번 | **구단마다 번호 하나에 한 명.** 이름을 공개한 순서대로 준다 — 이미 누가 가졌으면 「명예의 벽」으로. 「서버 N번째 결번」. 홈에 결번 목록(구단별·최신순) |
| 공유 | 은퇴 커리어 **보기 전용 링크**(받은 사람 화면에 「이제 당신의 차례」 + 시작 버튼) · **1080×1350 공유 이미지**(이름·레전드 점수·여정·수상·성향·최고의 한 수) |
| 이름 공개 | 설정 「선수 이름 공개」(기본 켬). 링크·욕설이 든 이름은 익명으로만 올라간다. 만 30세 전 은퇴한 짧은 커리어는 전체 전당·공유에 안 오른다 |
| 운영 | 관리 패널에서 이벤트 발생률·반전 확률·성장 배율·부상률·대표팀 전력·예선 통과 확률·상무 합격률 조정. 「밸런스 패치 vN 이 이번 시즌부터 적용」 알림. 옛 세이브 자동 변환 |
