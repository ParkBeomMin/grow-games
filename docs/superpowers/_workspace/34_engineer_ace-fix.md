## 1. 🔴 구조 — `aceOf`에서 나를 뺐습니다

### 무엇이 문제였나

```js
// 전 — 나도 에이스 후보였어요
const pool = xi.filter((x) => want.indexOf(x.pos) >= 0);
  * (row === ace ? (row.me ? SPOT : NPC_SPOT) : 1)
  * (row.me ? ME_P : 1);
```

**클럽마다 에이스가 한 명인 승자독식**이라, 내가 팀 최강을 넘는 순간 나는
`SPOT 4.0 × ME_P 1.8 = 7.2`를 얻고 **경쟁자의 `NPC_SPOT 7.0`이 통째로 사라졌습니다.**
그 아래에서는 내가 `ME_P 1.8`뿐이고 동료가 7.0을 가졌어요.

**designer가 §2-10에서 "폐기했다"고 적은 `ACE_W` 계단이 이름만 바뀐 채 살아 있었습니다.**
제가 §2-4의 `(isAce(i) ? spotOf(i) : 1)`를 글자 그대로 옮기면서 만든 구조예요 —
21번 §①-A-5의 *"`NPC_SPOT`은 **내 클럽 에이스에게도** 걸려서 나와 같은 8칸을 놓고 겨룹니다"*가
"둘은 배타적이지 않다"는 뜻이었는데, 제가 그걸 못 읽었습니다.

### 고친 것

```js
// engine.js aceOf() — 후보에서 나를 뺍니다
const pool = xi.filter((x) => want.indexOf(x.pos) >= 0 && !x.me);
const list = pool.length ? pool : xi.filter((x) => !x.me);

// engine.js weightOf() — 둘이 더 이상 배타적이지 않아요
  * (row === ace ? NPC_SPOT : 1)
  * (row.me ? ME_P * SPOT : 1);
```

`ME_P`는 지시대로 **평평한 배수**로 뒀습니다(`(blend/70) × 1.8`).
지시하신 대로 `aceOf` 위 주석("클럽마다 한 명이에요")도 새 규칙으로 다시 썼고,
`SPOT`·`NPC_SPOT` 상수 줄 주석도 같이 고쳤어요 — 옛 설명이 남아 있으면
다음 사람이 정확히 같은 실수를 반복합니다.

### ⏱️ `CLUTCH` 1.35 → 1.25 — 밴드를 안 넓히는 쪽

designer 확정입니다. 1.35는 시즌 골 **+3.6%**로 ±3%를 아슬하게 넘었어요.

**소스를 실제로 갈아치워 재측정** (`CLUTCH = 1.25` vs `1.00` · 각 2,500경기 × 4능력치):

|---|---|---|---|
| fw | **+2.6%** | −1.5% | +0.7% |
| wg | **+2.2%** | −1.0% | +0.8% |
| mf | **+1.9%** | −1.6% | +0.4% |

**골 최대 변화 2.6% — 네 포지션 전부 ±3% 안**입니다 ✅
`N ≤ 8` 불변 유지(플레이 카드 최대 **8**) · 추가시간 카드가 열린 경기 **70%**.

근거를 코드 주석에 그대로 남겼습니다 — *±3%는 임의값이 아니라 (라′) 중립 기준을
이어받은 것이고 그 밴드가 원칙 ④의 운영 정의라는 것*, *`clutch`의 값어치는 세기가 아니라
존재(화면에서 느끼는 건 배수가 아니라 `90+3분` 표시와 타이핑 연출)라는 것*,
*이 저장소가 데인 자리(골든부츠 43% → 60%)가 정확히 "조금인데 뭐 어때"였다는 것*.
다음 사람이 "1.35로 올려도 되지 않나"를 다시 묻지 않게요.

## 5. 배운 것 하나

**`(isAce(i) ? spotOf(i) : 1)`를 글자 그대로 옮긴 게 사고였습니다.**

설계 §2-4의 그 한 줄은 "에이스 한 명"으로도, "나 + 경쟁자 에이스 둘"로도 읽힙니다.
저는 **§2-10의 `ACE_W` 폐기 근거(계단)를 읽고도** 승자독식 계단을 그대로 만들었어요 —
폐기 이유가 "상수 이름"이 아니라 **"계단이라는 형태"**였는데 이름만 바꿨습니다.

21번 §①-A-5에 답이 있었습니다: *"`NPC_SPOT`은 **내 클럽 에이스에게도** 걸려서
**나와 같은 8칸을 놓고 겨룹니다**"* — 겨루려면 둘 다 있어야 하죠.
**계수를 잡은 문서의 모델 설명이 구현의 규범입니다.** 다음엔 계수표만 보지 않고
그 계수를 잰 모델 코드까지 확인하겠습니다.
