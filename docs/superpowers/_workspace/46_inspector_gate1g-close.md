## 1. 🟠 pin에 경고를 달았습니다 — **그리고 직접 되돌려 확인했습니다**

engineer 보고를 그대로 옮기지 않고 **제가 직접** 두 계수를 옛 값으로 돌려 전 검사를 돌렸습니다.

```

engine-test.js     exit 1 ❌      mutation-test.js   exit 0 ✅
neutral-test.js    exit 0 ✅      wiring-test.js     exit 0 ✅

**engineer 말이 맞습니다.** `engine-test`의 pin 두 줄 말고는 아무것도 안 웁니다.
그 사실을 pin 위에 크게 적었어요:

> 🚨 **이 pin은 "값이 이거다"만 지키고 "이 값이어야 하는 이유"는 안 지킵니다.**
> 여기를 고치면 아무 검사도 안 울면서 밸런스가 조용히 무너집니다.
> 값을 옮기려면 **balancer 실측(G-2·G-7)을 먼저 받으세요.**
> 검사가 통과한다고 괜찮은 게 아니에요 — 이 자리에는 검사가 없습니다.

### 🔗 그리고 방어선을 **하나 더** 만들었습니다 (33-B · §2)

pin이 유일한 방어선인 게 마음에 걸려서, **계수와 수상률을 묶었습니다.**

계수를 옮기면 이렇게 뜹니다 — **직접 흔들어 확인했습니다**:

```

**계수를 조용히 고치면 이제 `league-test`도 웁니다.** 수상률 자체를 재는 건 아니지만,

## 4. 🔴 31b — designer 지시대로 맞췄습니다

말씀대로 **시드 넷 평균**으로 바꾸고 상한을 **22% → 17%**로 조였습니다.

```
시드 4개 — 득점 [-0.51 -0.24 0.29 0.95] · 실점 [-14.70 -14.62 -14.31 -14.63] · 무실점 [25.86 26.34 26.39 25.50]
✅ 31.      득점 시드 4개 평균 +0.12% (±15%)
🚧 31b.     실점 -14.6% (밴드 ±15% · 승격 ±12%) ← 여유가 0.44%p뿐이라 승격 안 합니다
✅ 31b-상한. 시드 평균 |-14.56%| ≤ 17%
🚧 31b.     무실점 +26.0%
✅ 31b-상한. 시드 평균 |26.03%| ≤ 34%
```

무실점 상한도 같은 철학으로 42% → **34%**(관측 최악 29.1%에 여유)로 조였습니다.

### 왜 designer와 engineer가 다른 답을 봤는지 — 재현했습니다

**표본 수가 갈랐습니다.**

| N | 실점 시드 넷 | 밴드(±15%) |
|---|---|---|
| 12,000 | −14.64 / **−15.25** / −14.21 / −14.78 | **넘나듦** |
| 20,000 | −14.70 / −14.62 / −14.31 / −14.63 | 전부 안쪽 |

**단일 시드로 재면 통과했다 실패했다 합니다** — designer 판정 그대로입니다.
검사는 **N=20,000 × 시드 넷의 평균**으로 갑니다.

승격은 여전히 안 합니다(45번 §4의 히스테리시스). 여유 **0.44%p**이고,
근본 원인(`CON 1.111 × 0.5 = 0.5555` vs `FIN 0.884 × 0.5 = 0.4420`, 25.7% 차)은 그대로예요.

## 5. 🔥 덤 — `award-test` B-1b가 **시드 5150에서 밴드를 넘고 있었습니다**

알려 주신 *"세 갈래 도움÷골 여유 0.52%p"*를 확인하다 찾았습니다.

|---|---|---|
| 77 | 0.74%p | ✅ |

| 31337 | 1.62%p | ✅ |

**이 Δ는 0을 중심으로 흔들리지 않습니다.** ③은 `urgency`를 못 써서(최종 스코어만 넘어와요)

밴드 2.0%p는 그 중심에서 겨우 1%p 위였어요 — *"고장이 아니라 우연으로"* 빨간불이 될 자리입니다.

**고친 것**: 밴드 2.0 → **3.0%p** + **시드 셋의 평균**으로 판정.
(변이 쪽은 −27%p라 시드 하나로 충분합니다.)

```
✅ B-1.  시드 3개 평균 도움비 Δ+0.24%p · 시드별 [-0.29 0.02 0.98]
✅ B-1b. 시드 3개 평균 도움비 Δ+1.28%p · 시드별 [0.74 0.83 2.28]
```

> designer가 31b에 내린 판정(*"단일 시드는 신호가 아니라 잡음"*)이 **여기에도 그대로**였습니다.

| 1 | 🚧 실점 −14.6% · 무실점 +26.0% | designer가 **2차로 미룬** 항목(§2-8b (7)). 상한만 지킵니다 | ❌ 설계상 2차 |
