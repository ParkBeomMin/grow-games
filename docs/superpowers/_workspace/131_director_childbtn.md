### 1-1. 뼈대

| | 값 | 왜 |
|---|---|---|
| 배치 | `flex-direction: column` 한 줄씩 · `gap: 10px` | 🔴 **2열은 3장이면 한 장이 홀로 남아** 「덜 중요한 것」으로 읽힙니다. 세 선택지는 **대등**해야 해요. 해마다 2개나 4개가 와도 세로는 안 깨집니다 |
| 박스 안 | `flex-direction: **row**` · `flex-wrap: wrap` | 🔴 **`row`를 반드시 적습니다** — base.css `.card`가 `column`이에요 (§3-1) |
| 칸 셋 | 이모지 `flex: 0 0 34px` · 제목 `flex: 1 1 **0**` · 설명 `flex: 1 1 100%` | 🔴 제목이 `1 1 auto`면 긴 낱말에서 **이모지가 혼자 한 줄**을 먹습니다 (§3-2) |
| 여백 | `padding: 12px **34px** 12px 10px` | 오른쪽 34px은 **✓ 배지 자리**예요 — 글자가 배지 밑으로 못 들어갑니다(구조적 보장) |
| 바닥 | `min-height: 68px` | 설명 줄이 없는 해에도 손가락 기준(44px)을 **1.55배**로 넘깁니다 |
| 줄바꿈 | `word-break: keep-all` + `overflow-wrap: anywhere` | `keep-all`이 없으면 *"먼/저 뛰었어요"*로 쪼개집니다. `anywhere`는 띄어쓰기 없는 낱말의 마지막 수단 |

### 1-2. 고른 표시 — **넷을 겹칩니다** (🦶 주발 화면과 같은 문법)

🔒 ④는 **고르기 전에는 안 걸립니다** — 셋 다 멀쩡해야 「아직 안 골랐다」가 읽혀요.

## 3. 🐛 렌더가 아니었으면 못 봤을 것 둘

> 이게 이 라운드에서 헤드리스 렌더가 값을 한 자리입니다. 둘 다 **소스만 보면 맞아 보이고,
> 검사는 초록불이고, 화면만 틀립니다.**

### 3-1. `flex-direction`을 안 적어서 **가로 박스가 아니었습니다**

`.arc-list .card`에 `display: flex; flex-wrap: wrap; align-items: center`를 적고
「가로 긴 박스가 됐다」고 생각했어요. **아닙니다.**

```
base.css:  .card { display: flex; flex-direction: column; ... }   ← 8종 공유
```

`flex-direction`을 안 덮으면 셋이 **세로로 쌓입니다** — 가운데 정렬 카드 그대로예요.
렌더 실측: **이모지 y14 · 제목 y51 · 설명 y75.6 · 박스 107px**.
📸 스크린샷으로는 *"카드가 좀 큰가?"* 정도로 보였고, **좌표를 찍고서야** 알았습니다.

### 3-2. 긴 제목에서 **이모지가 혼자 한 줄**을 차지했습니다

`.card-title`을 `flex: 1 1 auto`로 뒀더니, 제목이 길면 **기준 크기가 「한 줄로 폈을 때의 폭」**이라
이모지 옆에 안 들어가고 **통째로 다음 줄로** 밀렸어요. 이모지만 남은 첫 줄이 생기고
제목이 왼쪽 끝에서 시작해 **이모지 칸이 무너집니다.**

- 지금 초1 문구로는 **안 나옵니다** (셋 다 짧아요) — 초2~초4의 긴 문구에서 터졌을 결함이에요.
- `flex: 1 1 **0**`으로 고쳤습니다. 기준이 0이라 **항상 이모지 옆에 앉고**, 남는 폭을 채운 뒤
  안에서 줄을 접습니다. 긴 제목 박스가 143.7 → **109.4px**로 줄었어요(빈 줄 하나가 사라짐).

🔑 **둘 다 「스트레스 판을 따로 만들어서」 나왔습니다.** 지금 문구만 렌더했으면 ②는 못 봤어요.

## 4. 렌더 — 정상 · 색약 · 흑백

`/workspace/.tools`의 playwright-core + chromium으로 **실제 버튼을 눌러 도달**했습니다

고른 판은 **7탭**). 🔒 **셀렉터마다 탭 횟수를 세어** 돌려받습니다 — 「도달만 재면
아무것도 안 눌러도 통과」를 막으려고요. 도달 못 하면 그 자리에서 던집니다.

### 4-1. 흑백에서 무엇이 남나

- 🟢 **고른 줄** — 밝은 테두리 · **✓ 배지** · 밝은 제목 · 나머지 둘의 흐림. **넷 중 둘이 무채색 신호**라 그대로 읽힙니다.
- 🟢 **진행 띠** — 지금 해가 **5px**, 나머지가 **3px**. 굵기 차이가 색 없이 남습니다.
  (색만 썼으면 흑백에서 네 칸이 같아졌을 거예요 — 그래서 굵기를 넣었습니다.)
- 🔴 **시간대 톤은 거의 사라집니다.** 알파 .07~.30이라요. **그래도 되게 만들었습니다** —
  몇 학년인지는 **띠와 `.child-place` 글자**가 말합니다. 톤은 정보가 아니라 **공기**예요.

### 4-2. 적록 색약

- deuteranopia에서 앰버 → **노랑**으로 갑니다. 테두리(파랑 `--line`)와 **여전히 확실히 갈립니다.**
- 🔒 **이 화면에 초록/빨강 축이 없습니다** — 「좋다/나쁘다」를 안 말해요. 고른 것과 안 고른 것뿐입니다.
- 🔒 새 색을 안 만들었어요. 톤 4단도 `--sky`/`--accent`/`--bg2` 계열의 옅은 겹입니다(절대색 0).

### 4-3. 🚨 렌더를 하면서 **찍는 방법 자체가 거짓말할 뻔한 자리**

처음에 색약 판을 「탭한 뒤 필터를 씌워」 찍었는데, **`ECHO_MS` 620ms가 지나

초1이 아니었어요 — **이름만 보고 넘어갔으면 「검증했다」가 통째로 거짓**이 됩니다.
👉 색약 판은 **`.on`/`disabled`를 손으로 켠 판**으로 다시 찍었습니다(intro.js가 켜는 것과 같은 둘).

## 5. 🟡 engineer에게 넘길 것

### 5-1. 🎖️ 「🦶 약발로!」 — **정확히 이 한 줄**

`beta/winger-moment.js` **709줄**, `runShotGrid`의 `end(...)` 안:

```js
// ─ 지금
      end(s, TIER(s, boardCeil) === "perfect" ? W.great + (ctx.weak ? " 🦶 약발로!" : "")
// ─ 이렇게
      end(s, TIER(s, boardCeil) === "perfect" ? W.great + (ctx.weak ? ' <b class="w2m-win-weak">🦶 약발로!</b>' : "")
```

- ✅ **CSS는 이미 넣었습니다** (`style.css`의 `.w2m-win-weak`). 위 한 줄이 들어오면 그날 바로 뜹니다.
  🔒 **CSS를 먼저 넣은 순서가 맞습니다** — 반대로 하면 클래스는 붙는데 화면엔 아무 일도 안 일어나요.
- ✅ 안전합니다 — `ender`가 `p.innerHTML = line + ...`으로 넣으니 `<b>`가 그대로 삽니다.
- ✅ **G-6·G-6b·G-6c에 안 걸립니다** — 그 셋이 세는 것은 `.w2m-cell*`이고,
  `classList.add/toggle`로 켜는 이름만 봅니다. `.w2m-win-weak`는 둘 다 아니에요.
  (넣고 `one-grid-test.js` 돌려서 31/31 초록불 확인했습니다.)
- 🎨 **새 색을 안 만들었습니다.** 이 화면의 색은 🦶 한 축(앰버 주발 ↔ 회색 약발)이고
  성패는 `--good`/`--accent2` 축이에요. 세 번째 색을 넣으면 셋 다 안 읽힙니다.
  그래서 **색은 그대로 두고 「모양」만** — 테두리를 두른 알약이 훈장이 됩니다.
  적록 색약·흑백에서도 테두리는 남아요.
- 🔴 **왜 고치나** — 같은 화면에 「약발 －25%」 벌점표가 떠 있어서, 붙어 있는 한 문장이
  ***"약발로밖에"***로 읽힙니다. 성취를 그린 화면이 **조건을 단 변명**처럼 읽히는 자리예요.

3. **`.card-desc`는 없어도 됩니다.** 그 해에 설명 줄이 없으면 빼세요 — 68px로 섭니다.
4. **`.arc-tally`는 비어 있으면 자리를 안 차지합니다**(`:empty`). 초1에서는 그대로 두세요.

## 6. 네 번 반복돼도 되는 근거

> 🔴 designer가 위험 3으로 적었습니다 — *"같은 컴포넌트를 네 번 쓰면 사람은
> **같은 질문 네 번**으로 읽습니다."* 이건 CSS가 답해야 하는 질문입니다.

### 6-1. 🔢 진행 띠 — **「또 그 화면」이 아니라 「이어지는 화면」**

```
초1  초2  초3  초4        ← 지금 해만 앰버 5px + Jua 굵은 글씨
━━━  ───  ───  ───          지난 해는 흰 3px · 올 해는 흐린 3px
```

- 🔑 **같은 화면이 네 번 오는 것에 대한 정면 답**입니다. 띠가 한 칸씩 차오르면
  「같은 화면」이 아니라 「**세 번째 해**」로 읽혀요. 남은 횟수도 같이 보입니다.
- ✅ **글자 넷은 늘 고정**(초1·초2·초3·초4)이라 마크업에 그대로 적고, JS는 칸을 다시 안 그립니다.
- ♿ `aria-hidden`입니다 — 같은 말을 `.child-place`가 이미 글로 해요
  (*"📍 서울특별시 · 초등학교 1학년 · 여덟 살"*). 낭독으로 「초1 초2 초3 초4」를
  해마다 네 번 듣는 건 정보가 아니라 **소음**입니다.
- 🎨 **색이 아니라 굵기**로 갈랐습니다 — 흑백 렌더에서 5px/3px이 그대로 남는 걸 확인했어요.

### 6-2. 🌤️🌇🌙🌌 시간대 톤 4단 — designer §2-3의 두 번째 요청

| 해 | 톤 | 값 | 실측 띠 |
|---|---|---|---|
| 초1 · 여덟 살 | 🌤️ **낮** | `rgba(111, 201, 255, .07)` | `5px/3px/3px/3px` |
| 초2 · 아홉 살 | 🌇 **노을** | `rgba(255, 159, 69, .07)` | `3px/5px/3px/3px` |
| 초3 · 열 살 | 🌙 **저녁** | `rgba(150, 130, 255, .08)` | `3px/3px/5px/3px` |
| 초4 · 열한 살 | 🌌 **밤** | `rgba(20, 32, 92, .30)` | `3px/3px/3px/5px` |

- 화면 위 하늘(`radial-gradient`)과 **카드 표면**에 같은 톤을 한 겹. 바탕만 갈면 박스가 그 위에 떠 보여요.
- 🔴 **고른 줄은 톤보다 앰버가 이깁니다** — 톤이 「고른 것」을 흐리면 안 됩니다.
- ♿ **톤은 정보가 아니라 공기입니다.** 흑백에서 사라져도 되게 만들었어요(§4-1).
  🔴 여기에 「고른 것」이나 「좋고 나쁨」을 실으면 안 됩니다 — 색이 두 가지 뜻을 갖게 돼요.
- 🔒 절대색 0. 전부 `--sky`/`--accent`/`--bg2` 계열의 옅은 겹입니다.
- 🔑 초3의 이름이 designer 표에서 **🌙**인 것과 맞췄습니다.

### 6-3. 🧺 쌓인 칩 — 초2부터 **화면이 길어집니다**

지난 해에 고른 것이 아래에 남아, 네 번째 화면은 앞의 셋과 **눈에 띄게 다른 화면**이 됩니다(§5-3).

### 6-4. 그리고 — **반복되는 것은 「누르는 법」입니다**

이건 뒤집어 볼 수도 있어요. 네 화면이 같은 손동작이라 **두 번째부터는 생각 없이 누릅니다.**
바뀌어야 하는 건 **내용**이고, 그건 designer가 §2-2에서 이미 갈라 뒀습니다 —
「**먼저**」 / 「**빨리**」 / 「**언제**」 / 「**한 번 더**」. 네 질문이 서로 다른 낱말을 씁니다.
화면이 할 일은 **그 다름을 가리지 않는 것**이고, 진행 띠·톤·칩 셋이 그걸 합니다.

- 🔴 **탭 횟수 > 0** — 셀렉터마다. 도달만 재면 아무것도 안 눌러도 통과합니다
