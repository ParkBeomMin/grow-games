### 2-2. 📍 번호 집계 — 「같은 장면, 민재라면」

**지금**(`story.js:249-254` · `game.js:800`): 1장(6주) 뒤 공식 경기마다 내 평점 > 민재 평점이면 +1, 낮으면 −1 → 25주 경기 뒤 d ≥ 2 되찾음 · \|d\| ≤ 1 둘이 · 그 외 넘겨줌.
**왜 무너졌나**: 엔진은 나를 늘 주인공으로 비춥니다(`SPOT` · `ACT1_SPOT`) — 민재는 장면을 나눠 갖는 **같은 포지션 동료**라 판 2.5에서 내 크레딧이 거의 늘 큽니다. 평점 비교는 「누가 더 잘했나」가 아니라 **「카메라가 누구를 따라갔나」**를 잽니다. 판 수가 다시 바뀌면 또 깨집니다(27번이 약속에서 고친 것과 같은 함정).

**새 집계** — 내 판마다, **같은 장면을 민재가 맡았다면** 해냈을 확률과 견줍니다.

| | 규칙(제안) |
|---|---|
| 한 판 | **Δ = 해냄 − q** · 해냄 = 그 판이 `perfect`(⚽ 골 · 🅰️ 도움 · 🧱 막음 — 기록이 남은 판)면 1, 아니면 0 · **q = 그 경기의 같은 장면에서 민재 실력의 자동 확률**(엔진 `autoP(kind, 민재 실력)` — 내 판의 중심과 같은 함수) |
| 한 경기 | Δ를 더해 **소수 한 자리로** — 화면에 그 숫자 그대로(보이는 값 = 판정 값 · 집계는 화면 숫자의 합) |
| 기간 | 지금 그대로 — 1장(6주) 뒤 공식 경기부터 25주 경기까지(리그 · 대회 · 약 9~13경기) |
| 결말(25주 경기 뒤) | 집계 **D ≥ +1.5 「번호를 되찾은 날」 · D ≤ −1.5 「넘겨준 번호」 · 그 사이 「둘이 선 양 날개」**(`SLOT_LINE` 1.5 — `SLOT_WIN` · `SLOT_PAIR`를 대신) |
| 화면(경기 뒤 한 줄 · 예) | 「📍 같은 장면 3번 — 나 2번 해냄 · {rival}라면 1.2번 → +0.8(번호 집계 +2.1)」 |
| 도감 규칙 글(예) | 「📍 번호 집계 — 내 판마다, 같은 장면을 {rival}가 맡았다면 해냈을 확률을 더해 견줘요. 내가 해낸 수와의 차가 쌓이고, 번호 결정전 뒤 +1.5 이상이면 번호를 되찾아요」 |

**왜 이 모양인가**
- **노출에서 떨어짐**: 판마다 견주니 판이 2.5든 1.4든 기댓값이 같습니다 — 판 수가 바뀌어도 안 깨짐
- **🤖 중립이 정의상**: `s = 0.5`이고 내 능력치 = 민재 실력이면 E[Δ] = 0(엔진 §2-6 「`s = 0.5`에서 카드 = 자동」과 같은 뼈)
- **포지션이 구성으로 대등**: 세 종류의 자동 확률이 능력치에 같은 기울기로 탑니다(⚽🅰️ `FIN × atkW` ≈ 0.44 · 🧱 `1 − CON × defW` ≈ 0.44 — 58:58) → 「해냄」(perfect)만 세면 종류마다 감도가 같음. ⚽의 `ok`(골문 안 슛)를 넣으면 공격수만 감도가 반으로 줄어 **안 넣습니다**(약속의 「살림」과 다른 까닭 — 약속은 성공률 40~60을 맞추는 자리, 집계는 둘을 견주는 자리)
- **키운 만큼 + 솜씨 + 운**: 능력치가 오르면 내 확률이 민재 쪽으로(성장) · `s`가 0.5 위면 더(솜씨) · 판마다 해냄은 굴림(운)
- **숨은 굴림 0**: 민재 쪽은 굴리지 않고 **확률 그대로** 씀(그림자 굴림은 결말을 숨은 굴림으로 정함 — 이야기 결말 원칙 위반)

**어림**(스크래치 — 경기 10 · 상대 52~70 · 58 대 · 동료 58±8 · 민재 64 · 정책은 능력치 길과 `s`로만: 잘함 50 → 57 · `s` 0.70 / 보통 49 → 53 · 0.57 / 대충 48 → 50 · 0.50 · 포지션마다 3,000판)

### 4-2. 「미니게임 스킵」의 이름 — 왜 「건너뛰기」가 아닌가

- 지금 규칙은 **판정을 건너뛰지 않습니다** — 판은 열리지 않지만 엔진이 `s = 0.5`(중립)로 판정해 골 · 막음이 나고, 평가서 솜씨 칸에 🤖가 붙습니다(`sheet.js` 솜씨 칸 · `game.js:789`). 「스킵」이라 부르면 「그 장면이 없던 일」로 읽혀 결과가 날 때 놀랍니다
- 그래서 이름은 **「판 자동 진행」**, 설명 첫 문장이 **「미니게임을 열지 않고 보통의 한 수로 판정해요」** — 사용자가 찾는 낱말(미니게임 · 넘김)은 설명에 있고, 하는 일(판정)은 제목에 있습니다

### 4-3. 판마다 「이번만 자동」 — 안 둡니다

- **골라 넘기는 길이 생깁니다** — 판이 열린 뒤(키퍼 · 밝은 칸이 보인 뒤) 고를 수 있으면 약발 쪽 · 자신 없는 종류만 자동으로 넘겨 `s̄`가 올라갑니다(중립은 「평균의 한 수」라, 내가 평균보다 못할 판만 골라 넘기면 이득). 판이 열리기 전에만 고르게 해도 「🧱만 넘기기」가 남음
- 판은 경기당 2~3번이고, 경기 전체를 줄이는 손잡이(⏩ · 🤖 · 「결과만」 류)가 이미 있습니다
- 🤖를 경기 중에 바꿔도 **다음 경기부터** — 같은 까닭(판 사이에서 켰다 껐다 하며 고르는 길을 막음)
- 판단이 바뀔 조건: 실기기에서 「한 판만 넘기고 싶다」가 반복되면 — 그때는 **판이 열리기 전 · 종류를 모를 때**(경기 시작 화면)에 「이 경기만 자동」으로

| 📍 민재 그림자 굴림 | 이야기 결말이 숨은 굴림으로 정해짐 | 없음 |
| 📍에 ⚽ `ok`(골문 안 슛)를 넣기 | 공격수만 감도가 반 — 포지션이 구성으로 안 갈림 | 없음 |
| R15 · R9를 자로 풀기(선을 절대값으로) | 뜻이 실제로 깨졌음(몰빵 손해 0.63 SD · 테스트 운 11.7%) | 없음 |
| 모든 포지션의 기록 가중을 같게 | 포지션의 일(공격수의 골 · 미드의 도움)이 기록 칸에서 사라짐 — 갈리는 원인(수비수의 곁 종류 ×2)만 고침 | R5가 수비수 둘째 값으로도 안 설 때 |
| 판 구성(간격 10 · 포지션별 g · a · d) | 사용자 반응 대기(오케스트레이터) — 🧱 몫 39%는 그대로 | 「공격수인데 막기만」 반응 |
| 시작 능력치 4점 단위(더 넓게) | 판의 절반에 F(40) 칸 — 「망한 뽑기」가 흔함 | 실기기에서 「다 비슷하다」 |
| 다시 뽑기 무제한 | 「잘 뽑으면 끝」 · 뽑기가 육성을 대신(⑥의 사촌) | R19가 넉넉히 넘을 때 늘릴 수 있음 |
| 시작 모양을 포지션에 맞춰 굴리기 | 랜덤이 안 랜덤 — 「능력치를 보고 포지션을 고르는」 맛이 사라짐 | 없음 |
| 말투를 🧭 성향에서 | 2막이 처음부터 쓸 안정된 말투 id가 필요 · 성향은 필름 · 도감에 이미 있음 | 없음 |
| 문을 성장 모양(고르게 · 한 가지)으로 | 문의 높이가 고정이라 모양 + 높이가 겹치는 판이 드묾 · 2막 입구 칸의 높이 짝(`univ` ↔ `pro2`)이 흔들림 | 2막이 문의 높이를 풀 때 |
| 판마다 「이번만 자동」 | 골라 넘기는 길(§4-3) | 「한 판만 넘기고 싶다」 반복 → 경기 시작 화면의 「이 경기만 자동」 |
| 시계 속도 칸 | I가 정한 값 · ⏩가 같은 일 | 「⏩는 너무 빠르다」 |
| 🗑️에서 공유 키 · 클라우드 지우기 | 다른 게임의 기록 · 사람의 백업 | 없음 |
| 주발 「왼 · 오」 자체의 힘 차이 | 대칭 원칙 | 없음 |
| 이름을 성 + 이름으로 | 문장의 `{me}` 결(다른 사람은 문장에서 두 글자) · 카드 기본값과 어긋남 | 명전에서 「같은 이름이 많다」 |

## 13. 위험 — 무엇이 무너지면 이 설계가 실패인가

| 위험 | 무슨 일이 | 막는 것 |
|---|---|---|
| 🟠 📍 집계 숫자가 어렵게 읽힘 | 「민재라면 1.2번」이 기댓값이라 낯섦 | 줄을 「같은 장면 3번 — 나 2번 · 민재라면 1.2번」으로 풀어 씀 · 도감 규칙 글 · 실기기 |
| 🟠 몸 꼭대기가 곧아져 몰빵의 S가 끌림 | 잘함 짝의 🎯 > 🪜(R15 아래 끝 — 어림 약 0.2로 가장 가까움) | R15 둘째 값(S 5.6) · 40~60의 오목함은 그대로 |
| 🟠 수비수 골이 덜 쳐짐 | 「수비수 골인데 기록 칸이 막음과 같다」 | 평점(수비수 골 12)과 연출이 손맛을 짐 · 칸의 상세에 골 · 도움 · 막음 수 그대로 |
| 🟠 시작 운이 「키운 만큼」을 흔듦 | 맞는 모양 + 맞는 포지션이 구간을 끌어올림 | R19 · 둘째 값(폭 좁힘 · 다시 뽑기 1) |
| 🟠 가족 셋의 그림이 늦음 | 엄마 · 할머니가 이름 글자로 | P1 덧붙임(아버지만 먼저) · `Art`의 물러섬 |
| 🟠 「나머지 둘은 왜 닫히나」 | 가족 이야기를 하나만 고르는 까닭이 안 읽힘 | 🤝 얼굴 밑 한 줄(「올해 끝까지 함께할 이야기 — 하나만 고를 수 있어요」) · 25주 사실 한 줄 |
| 🟡 이름 표의 대조 누락 | 명전에 유명인 이름이 오름(결정 L) | §3-4 다섯 규칙 · 웹 대조 · 20개 이상만 남김 |
