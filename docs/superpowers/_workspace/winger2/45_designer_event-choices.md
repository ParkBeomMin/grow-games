## 0. 한 장 요약

| 물음 | 답(제안) |
|---|---|
| 선택지 수 | 이벤트마다 **셋 또는 넷**. 종류는 넷 중에서: **🎲 크게**(지금 도전) · **🎲 작게**(판돈 반 · 확률 +5) · **🌿 확정**(작은 확실한 몫) · **💬 이야기**(사람과의 장면 깃발 + 작은 몫) |

## 1. 무엇을 푸는가

- 지금 카드는 **[넘긴다(효과 0)] / [도전(판돈 ±1 · %)]** 둘입니다. 사용자 말 둘:
  - **선택지가 적다** — 이야기상 태도가 「안 한다 / 한다」 둘뿐입니다
  - **넘긴다에 혜택이 없다** — 고를 이유가 「잃기 싫다」뿐입니다
- 지금 원칙(볼트 `disclosed-odds-choice-events` §2)은 「안전 = 효과 0」입니다. 늘 안전한 판이 이벤트 없던 판과 **비트가 같아** 밸런스 · 검사가 구성으로 섰습니다. 확정에 몫을 주면 이 구성이 깨지므로 **무엇으로 대신 지킬지**가 이 문서의 핵심입니다.
- 함께 지킬 것: 보이는 % = 판정 % · 판돈 한 축 W = L · 확률 식(50 + 실력 ±10 + 상황 ±12) · 「선택은 수평(문 · 엔딩 · 관계), 높이는 육성」 · 새 추상 수치 금지(🤝 하나 — 12번 §7-1) · R8(선택만 바꿨을 때 구간 바뀜 ≤ 10%).

## 2. 구조 — 선택지 종류 넷

| 종류 | 무엇 | 확률 | 효과 | 높이에 닿나 |
|---|---|---|---|---|
| **🎲 크게** | 지금 도전 그대로 | `p` = clamp(50 + 실력 + 상황, 10, 90) | 판돈 축 **±1**(능력치) · **±2**(🤝) | 판돈(기댓값 0 근처 — W = L) |
| **🎲 작게** 🆕 | 같은 일을 덜 걸고 | `p + 5`(상한 90) — 조각 「작게 +5」 | 판돈 축 **±0.5** · **±1**(🤝) | 크게의 절반 |
| **🌿 확정** 🆕(넘긴다 자리) | 이야기에 맞는 작은 몫 하나 — 확실히 | 없음(「확정」) | 아래 메뉴 중 **하나** | 아주 작게(≤ +0.5점 — R8-b) |
| **💬 이야기** 🆕(넣을 수 있는 이벤트만) | 사람에게 다가가는 태도 | 없음(「확정」) | **🔖 깃발 하나** + 🤝 +1 또는 🫀 +5 | 깃발은 0 · 몫은 🌿과 같음 |

**🌿 확정 몫 메뉴** — 한 장에 하나 · 판돈 축이 아닌 칸

| 몫 | 크기 | 까닭 · 높이 어림 |
|---|---|---|
| 🫀 컨디션 | **+5** | 쉬면 돌아오는 값이라 시즌 가치가 작음(볼트 §3). J10 관리 칸에 닿아도 경기 날 평균 c̄를 경기 약 14번에 걸쳐 +0.36 → 칸 **+0.07** |
| 🤝 감독 신뢰 | **+1** | 평가서 점수 0(23번 §7) — 감독 의견 · 이야기 · 엔딩 한 줄로만 |
| 능력치(판돈과 다른 칸) | **+0.2** | 몸 칸 기울기 약 0.1/점 × 1.5 → **+0.03** · 기록에 아주 조금(J11) |
| 🦶 약발 경험 | **+0.4** | 약발 훈련 한 주(효율 약 0.7)의 반 — 「반대발 주간」 전용 |
| 🔖 깃발(덤) | — | 수치 0 — 아래 §3-2 |

- 🔒 **잘리는 몫은 내놓지 않음**(지금 원칙 그대로): 🤝이 +6이면 「🤝 +1」 확정은 그 판에서 🔖 깃발만 남기고 글을 바꿈(「감독은 이미 너를 믿어요」) · 컨디션 100이면 🫀 대신 같은 이벤트의 다른 몫 · 판돈이 안 맞으면(`fits`) 🎲 둘을 내놓지 않음(지금처럼 그 이벤트가 후보에서 빠짐 — 무작위면)
- 🔒 확정 둘(🌿 · 💬)은 서로 다른 몫 — 같은 카드에 🫀 +5가 두 번 나오지 않음

### 2-1. 지배 금지 — 구성으로

- 🎲 크게 ↔ 작게: 기댓값(판돈 단위) 크게 `2p − 1` · 작게 `0.5 × (2(p + 0.05) − 1) = p − 0.45` → **p = 55%에서 같음**. 55 위면 크게, 밑이면 작게
- 작게 ↔ 🌿 확정: 작게의 기댓값이 0이 되는 곳이 **p = 45%** — 그 밑에선 확정(작은 + 몫)이 나음
- 지금 확률 분포(R12 — 대부분 28~72%)에서 어림 크게 · 작게 · 확정이 **약 ⅓씩** 「읽으면 최선」 → 늘 같은 답이 없음. %를 읽는 것이 곧 고르는 법(🧮)
- 확정 몫이 작아서(≤ 0.07점) %가 높은 카드에서 확정만 고르는 것은 **조금 손해** — 그래도 이야기(깃발 · 사람)를 위해 고를 수 있게 둠: 「선택은 수평」
- 💬 이야기는 높이로는 🌿과 같은 몫 — 고르는 까닭이 **이야기**뿐이도록

### 2-2. 원칙 바꿈 — 볼트 `disclosed-odds-choice-events` §2를 이렇게(실측 뒤 반영 제안)

| 지금 | 바꿈 |
|---|---|
| 안전 = 효과 0 → 「늘 안전」 판이 이벤트 없던 판과 **비트 같음**(구성) | **확정 = 작은 몫 · 판돈 축 밖 · 회복되는 값이거나 수평 값** → 「늘 확정」 판과 옛 「늘 안전」 판의 차를 **잼**(R8-b: 평균 ≤ +0.5점 · 구간 바뀜 ≤ 5%) — 구성이 아니라 사전등록한 선으로 |
| 판돈 한 축 · W = L | **그대로** — 🎲 크게 · 작게 모두 한 축 · W = L(작게는 크기만 반) |
| 「넘긴다」 = 효과 0 | 없앰 — 고를 이유가 「잃기 싫다」뿐인 선택지는 두지 않음 |

- 왜 바꿔도 되나: 1막 높이는 이제 키우기 + 관리가 가르고(J10 · 43번), 선택의 높이 몫이 0.1점입니다. 확정 몫을 판돈 축 밖 · 아주 작게 두면 높이 원칙은 그대로이고, 사용자가 본 「혜택 없음」만 풉니다
- 볼트 문서는 실측(R8-b) 뒤에 고칩니다(이번엔 안 건드림)

## 3. 수평 — 선택이 가르는 것

### 3-1. 높이 ↔ 수평

| | 높이(평가서 구간) | 수평(문 · 엔딩 · 관계) |
|---|---|---|
| 🎲 크게 · 작게 | 판돈(기댓값 0 근처 · 읽으면 조금 +) | 이야기 장이면 결말 갈래(아래) |
| 🌿 확정 | ≤ +0.5점(1막 통째 · R8-b) | 🤝 · 🔖 |
| 💬 이야기 | 🌿과 같음 | **🔖 깃발 — 이것이 몫의 본체** |

### 3-2. 🔖 깃발 — 수치 0 · 쓰이는 곳

- 저장: `S.evFlags`(이름 목록 · 같은 이름 한 번) · `act1.evFlags`로 2막에 넘김
- 쓰이는 곳(셋): ① **엔딩 문장 한 줄**(깃발 하나를 골라 「그해, {me|는} …」 — 여럿이면 가장 늦게 세운 것) ② **졸업 필름 한 컷**(그 장면의 글) ③ **이야기 결말 문장**(📍 · 🕯️ · 🔥 · 가족 — 표의 「결말에」 칸)
- 새 추상 수치 0 — 깃발은 수가 아니라 「있었던 일」

### 3-3. 이야기 장의 결말과 새 선택지

| 이야기 | 지금 결말 규칙 | 새 선택지가 닿는 곳 |
|---|---|---|
| 🕯️ 마지막 공 | 1장 도전이면 성공 → 「새벽」 · 실패 → 「못 따라감」 · 안전이면 「악수」 · 2장 약속을 지키면 「선물」 | **🎲 작게도 「도전」으로 셈**(같은 갈래) · 🌿은 「악수」 · 💬 깃발은 「악수」 결말 문장에 한 줄 |
| 📍 번호의 주인 | 25주 집계(📍)로 셋 | 결말 규칙 그대로 — 💬 깃발 `slot_congrats`는 「둘이 선 양 날개」 · 「넘겨준 번호」 문장에 한 줄 |
| 🔥 이웃 학교 에이스 | 2장 약속 | 💬 깃발 `race_greet`는 결말 문장에 한 줄 |
| 🏠 가족(아버지 · 엄마 · 할머니) | 2장 깃발(문)을 세우면 그 문 · 아니면 다른 결말 | **문은 2장의 「깃발」 하나만 엶**(그대로) — 새 셋째 선택지는 문 없음 · 결말 문장만 다름 |

## 5. 카드 — 320px 한 화면

```
┌──────────────────────────── 320 ────┐
│ [반신 그림 96px]  🦶 불 꺼진 운동장   │  머리 — 그림 · 제목
│                   골대 하나에만 불이… │  본문 2줄(넘치면 「…」 · 눌러 펼침)
│ 🎲 실력 +4 · 그날의 상황 +6 → 60%     │  조각 줄 — 한 번만(🎲 둘이 같은 바탕)
├──────────────────────────────────────┤
│ 🎲 남아서 백 개                       │  버튼 1 — 2줄 · 높이 52px
│    60% · 슈팅 +1 / −1                 │
│ 🎲 오십 개만 — 65%(작게 +5)           │  버튼 2
│    슈팅 +0.5 / −0.5                   │
│ 🌿 들어가서 쉰다                      │  버튼 3
│    확정 · 🫀 컨디션 +5                 │
│ 💬 {rival}에게 같이 하자고 한다       │  버튼 4
│    확정 · 🤝 +1 · 🔖 이야기 한 줄      │
└──────────────────────────────────────┘
```

- 머리 약 150px + 조각 줄 28px + 버튼 넷(52 × 4 + 간격 6 × 3 = 226px) + 여백 ≈ **430px** — 320 × 568(가장 작은 폰)에서 스크롤 없이 들어옴
- 버튼 줄 1 = 태도(문구) · 줄 2 = **숫자**(% · 효과). 효과 칩은 지금 `chips` 모양 그대로(🎲은 「+1 / −1」 두 칩)
- 🎲 작게의 %는 그 버튼 안에 「작게 +5」를 같이 적음 — 보이는 조각의 합 = 판정 값(조각 줄 60 + 작게 5 = 65)
- 확정 버튼은 % 대신 「확정」 · 색은 🎲과 다르게(무늬 + 글 — 색만으로 안 가름)
- 탭 대상 44px 이상 · 키보드 1~4 · 버튼마다 `aria-label`에 두 줄을 이어서
- 결과 카드는 지금 모양 그대로(🌿 · 💬은 「확정 — 🫀 +5」처럼 몫을 칩으로)

| 🟠 「늘 확정」이 높이를 부풀림 | R8-b 선 0.5 · 둘째 값 둘 |
| 🟡 🤝이 위로 몰림 | R11 · 잘리는 몫 규칙 |
| 🟡 카드가 길어짐 | 본문 2줄 · 조각 줄 한 번 · 버튼 2줄 고정 |

## 9. ❓ 사용자 판단 지점

### J11 — 「확정」의 몫에 능력치 소폭을 넣을까

| 선택지 | 얻는 것 | 잃는 것 |
|---|---|---|
| **(가) 넣음 — 판돈과 다른 칸 +0.2 · 컨디션 · 🤝 · 깃발과 섞어서**(추천) | 「주발을 더 다듬는다」처럼 몸이 자라는 체감 · 사용자 예시 그대로 | 「늘 확정」이 높이를 아주 조금 올림(어림 1막 통째 +0.1~0.3점 — R8-b로 잼) |
| (나) 안 넣음 — 컨디션 · 🤝 · 깃발만 | 높이 원칙이 가장 깨끗 | 「주발을 다듬었는데 주발이 그대로」 — 혜택이 이야기 쪽으로만 |

### J12 — 「🎲 작게」(판돈 반 · 확률 +5)를 넣을까

| 선택지 | 얻는 것 | 잃는 것 |
|---|---|---|
| **(가) 넣음 — 이벤트마다 크게 · 작게 · 확정(+ 💬)**(추천) | 「조금만 걸기」라는 태도 · %를 읽는 맛(55 · 45에서 답이 바뀜) · 확정만 정답이 되는 것을 막음 | 카드에 숫자가 하나 더 |
| (나) 안 넣음 — 크게 · 확정 · 💬 | 카드가 단순 | 「크게 걸기 ↔ 확정」 둘 사이 — %가 낮은 카드에선 확정만 답이 되기 쉬움(R8-c 위험) |
