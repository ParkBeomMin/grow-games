### 4. 3D — 어디에 쓰고 어디에 안 쓰는가

**전용 파일 2개만 늘어납니다. 공유 파일은 안 건드립니다.**

| 파일 | 무엇 |
|---|---|
| `beta/winger2/vendor/three.module.min.js` | **벤더링합니다** (CDN 아님) |
| `beta/winger2/char3d.js` | `window.W2Char` — 캐릭터·장비 뷰어. **ES module** |

> 🔴 **CDN을 쓰지 않습니다.** `decisions.md` #2가 *"외부 CDN 의존 없음 — 오프라인 PWA가
> 유지됩니다"*로 정한 선입니다. 범민 님이 three.js를 쓰자고 하신 건 **캐릭터를 3D로**라는
> 뜻이지 **CDN을 켜자**는 뜻이 아니라고 읽었어요. 파일을 저장소에 넣고
> `sw.js`의 `ASSETS`에 손으로 추가하면 오프라인이 그대로 유지됩니다.
> (⚠️ `sw.js`는 자동 생성이 없어요 — 빠뜨리면 **온라인에선 멀쩡하고 오프라인에서만 깨집니다.**)

| 자리 | 3D? | 왜 |
|---|---|---|
| 🌱 유망주 카드 | ✅ | **첫 화면에서 "내 선수"가 생깁니다.** 소유감이 여기서 시작해요 |
| 🏠 홈 HUD (유스·프로) | ✅ 작게 | 공 저글링 유휴 동작. 성장하면 체격·장비가 바뀜 |
| 🛍️ 상점 | ✅ | **3D가 가장 값을 하는 자리.** 사기 전에 신어 봅니다 |
| 🏆 시즌 결산 · 수상 | ✅ | 트로피 드는 세리머니. 커리어의 마침표 |
| ⚽ 골 세리머니 컷 | 🟡 갈래 D2 | 3초. **경기 흐름을 끊지 않는 길이여야 합니다** |
| 🔥 순간 카드 진행 중 | 🔴 **아니요** | ↓ 아래 경고 |
| ⚔️ 평가전 · 경기 카드 피드 | ❌ | 읽는 화면입니다. `match-scene.js`가 이미 카드를 밀어 올려요 |
| 📊 순위표 · 👥 명단 · 📈 능력치 · 📜 기록 · 🏛️ 전당 · 💼 이적 | ❌ | **정보 밀도와 스크롤.** 3D가 자리만 먹습니다 |

> ### 🔴 순간 카드가 도는 동안 3D를 렌더하지 않습니다
> 이게 이 문서에서 가장 중요한 한 줄입니다.
>
> 미니게임은 **프레임 위에서 판정합니다.** 저사양 폰에서 3D가 같이 돌면
> 프레임이 떨어지고 → **판정이 실제로 나빠지고** → `s`의 분포가 내려가고 →
> `P(사건) = clamp(autoP + 2·half(a)·(s−0.5))`가 **기기마다 다른 곡선**이 됩니다.
>
> **balancer가 `_t.skill = 0.5`로 잰 곡선 전체가 기기 성능에 의존하게 돼요.**
> 이건 밸런스 사고가 아니라 **밸런스를 잴 수 없게 되는 사고**입니다.
>
> **규칙**: `W2Moment.play`가 시작하면 `W2Char.pause()`, 콜백에서 `resume()`.
> 3D 무대를 미니게임 뒤에 깔더라도 **정지 프레임 1장**만 렌더하고 루프를 멈춥니다.

**`W2Moment`는 한 줄도 고치지 않습니다.** 3D는 `W2Moment`가 만드는 컨테이너 **뒤에**
절대 위치 캔버스로 깔리고, 조작 요소(움직이는 표적 · 방향 버튼)는 현행 DOM 그대로 위에 겹칩니다.
→ `tests/winger2/moment-test.js`가 안 깨집니다.

### 5. 캐릭터를 코드로 만드는 방식 (외부 모델 파일 0)

| 위험 | 무엇이 무너지면 실패인가 | 어떻게 막는가 |
|---|---|---|
| 🔴 **3D가 판정을 오염시킨다** | 저사양 폰에서 프레임이 떨어져 `s` 분포가 내려가고, **곡선이 기기 성능에 의존**하게 됩니다. 밸런스 사고가 아니라 **밸런스를 잴 수 없게 되는 사고**예요 | **순간 카드가 도는 동안 3D 렌더 정지**를 규칙으로. inspector가 *"`W2Moment.play` 진입 시 `W2Char`가 멈추는지"*를 검사로 지킬 것 |
| 🔴 **WebGL 컨텍스트가 여러 개 생긴다** | 유망주 3장을 각각 캔버스로 만들면 화면을 오갈수록 컨텍스트가 쌓이고, 상한에 닿는 순간 **가장 오래된 것이 검게 죽습니다.** 재현이 어려워 원인을 못 찾아요 | **렌더러 1개, DOM만 이동.** 3장을 동시에 안 그립니다 (B3가 1장씩인 이유 중 하나) |
| 🔴 **`sw.js` 누락** | 온라인에선 멀쩡하고 **오프라인에서만** 3D가 깨집니다. 자동 생성이 없어요 | `char3d.js` · `vendor/three.module.min.js`를 손으로 추가. inspector 교차 검사 항목 |
| 🔴 **등급 판정을 죽여도 검사가 전부 초록불이다** | 모든 능력치가 영원히 `F−`여도, 승급 카드가 영영 안 떠도, 유망주 3장이 전부 `F−`로 깔려도 **검사 10종이 전부 통과합니다**(engineer 변이 검증 §7). **이 저장소가 여덟 번 데인 그 형태예요** | inspector가 §7의 검사 4종을 짤 것. ⚠️ **문턱(40/58/74/90/108/128)을 소스에서 읽지 말고 검사에 직접 적을 것** — 읽어오면 `GRADES`를 갈아도 안 잡힙니다. XP 바 검사는 **`W2Grade.of()`의 출력을 정답으로 삼지 말 것**(자기 자신과 비교) |
| 🟡 **승급이 사건이 아니라 배경음이 된다** | 19단계에서 6칸 전체 카드가 **2턴에 한 장**입니다. 2.6초짜리 카드가 훈련 두 번에 한 번 화면을 덮으면 §B-3의 *"문턱을 넘는 순간"*이 무너져요 | 7단계로 되돌려 **36턴에 4~8장**으로. 🔴 실측 E |
| 🔴 **견주는 화면의 바가 더 좋은 칸을 더 짧게 그린다** | 카드의 바가 구간 진행률이라 `패스 53(E)`이 `숏 31(F)`보다 짧습니다. **셋을 가르라고 만든 칸이 거꾸로 가르고 있어요.** 렌더에서 확인됨 | 견주는 화면은 **절대 크기**, 키우는 화면은 **구간 진행률**. 이름도 「잠재력 바」/「XP 바」로 가릅니다(원칙 ⑨) |
| 🟡 **다른 축의 손잡이로 카드의 `F`를 고치려 든다** | 등급표를 세분하면 값은 움직이는데 **원인은 그대로**고, 유스 훈련의 승급 카드 목표가 샙니다. 0회 비율은 **8.3%로 이미 정상**이에요 | 원인은 **캡션과 바의 자**입니다. 문서에 축을 갈라 적어 뒀으니 이후 세션은 그걸 먼저 읽을 것 |
| 🔴 **훈련 3택이 몰빵을 못 막고 오히려 운으로 만든다** | 주 스탯 카드가 안 나오는 커리어가 생기면 **성장이 운**이 됩니다. 원칙 ⑦(몰빵 반대 압력)을 노리다 원칙 ⑥(육성이 의미 있어야)을 깨요 | 3장 중 **최소 1장은 주 스탯 계열**을 보장하는 손잡이를 남길 것. 🔴 balancer가 커리어 분산으로 판정 |
| 🔴 **💼 첫 구단 제안에 정답이 생긴다** | 하나가 확실히 유리하면 그건 선택이 아니라 절차입니다. 그리고 평균 팀 전력이 올라가 **곡선이 통째로 움직입니다**(원칙 ④) | 20시즌 커리어 총 공격포인트 기댓값 **±5%** 실측. 못 맞추면 **제안을 안 넣는 게 낫습니다** |
| 🟡 **화면이 늘어 첫 3분이 오히려 길어진다** | 트라이아웃 35초 + 한 화면 한 결정 4개. **줄이려던 게 늘어나면 실패**예요 | 목표를 숫자로 박습니다 — **타이틀 탭 → 첫 훈련까지 3분.** 실기기로 재고 넘으면 트라이아웃을 2종으로 줄일 것 |
| 🟡 **`miniZone` 폐기가 유스 곡선을 흔든다** | 유스 미니게임에서 능력치가 창을 넓히는 걸 빼면 능력치 높은 선수의 평가전 등급이 내려가고, **명성 → 프로 도전 확률(`명성/1500`)**로 번집니다 | 1차에서는 **껍데기만 교체하고 `miniZone`은 유지**하는 선택지를 열어 둘 것 |
| 🟡 **three.js가 오프라인 캐시를 무겁게 한다** | 첫 방문에 ~150KB(gzip)가 더 붙습니다 | 단일 최대 JS가 되지만 `career.js` 244KB와 규모가 같은 급이라 수용 가능. **다만 `char3d.js`는 `type="module"`로 늦게 로드**해 첫 화면을 안 막습니다 |
| 🟡 **범민 님이 정한 "CSS 자체 제작"을 뒤집는 것** | `decisions.md` #2가 *"캐릭터는 CSS 자체 제작 · 외부 CDN 의존 없음"*입니다 | **뒤집는 게 아니라 절반만 바꿉니다** — 표현 수단은 three.js로, **CDN 금지는 그대로**(벤더링). 그리고 **CSS 실루엣은 폴백으로 살아 있어야 합니다** |
