# 3. 선택지 표 — **무엇을 얻고 무엇을 잃는가**

## 3-1. 🔒 세 선택지가 **여섯 칸을 정확히 2 + 2 + 2로 나눕니다**

| 선택 | 문구 | 🟢 얻는 칸 | 🔴 잃는 칸 (총합 고정의 반대급부) |
|---|---|---|---|
| ⚽ **공** | 하루 종일 공만 찼어요 | `dribble` · `shoot` | `defense` `stamina` `pass` `speed` |
| 🛡️ **몸** | 형들 틈에 껴서 안 밀렸어요 | `defense` · `stamina` | `dribble` `shoot` `pass` `speed` |
| 👀 **눈** | 빈 곳을 먼저 보고 먼저 뛰었어요 | `pass` · `speed` | `dribble` `shoot` `defense` `stamina` |

> ★ **합집합이 여섯 칸 전부이고 겹침이 0입니다.** 이게 §5의 중립을 **구조로** 만듭니다.
> 🔒 **선택지를 늘리거나 문구를 갈 때 이 성질을 깨지 마세요** — `CHILD_FOCUS`는 🔗 **종속값**이라
> 칸이 겹치는 순간 중립이 깨집니다.

## 3-2. 🔴 **「정답 찾기」가 아닌 이유 — 셋 다 어떤 자리엔 최선입니다**

| | |
|---|---|
