## 4. ⓶ 판정 — `bench-test` G-1이 🧒 어린 시절을 지나지 않고 초록불

### engineer 자인이 맞습니다. **그리고 제안한 감지기 중 하나는 안 통합니다.**

실측 (기준선, 지금 소스 그대로):

```
동기 타이머 없이 재현 → 닿은 곳 screen-main  ✅   childPicks []            schoolN 8
                        건너뛴 선택자 5개 (#screen-child2/3/4 · …)
```

🔴 **`S.schoolN === 8`은 이 사고의 감지기가 아닙니다** — 어린 시절을 **통째로 건너뛴** 위
상태에서도 **8이었어요**. 감지기는 **`S.childPicks`** 하나뿐입니다.

**왜 이렇게 되나**: 초1을 누르면 `setTimeout(…, 620)` 뒤에야 초2 화면이 **생깁니다.**
동기로 줄줄이 누르면 초2~초4가 **DOM에 아예 없어서** `querySelector`가 `null` → 조용히 건너뜀.
그런데 `#position-list`는 **정적 마크업**이라 그다음 줄이 흐름을 끝까지 밀어요.
👉 CLAUDE.md 열두째 유형 **「자가 복구가 실패를 삼킴」** 그대로입니다.

### 어떻게 보강했나 (구현 완료)

1. 🔒 **`fastEcho` 사용 여부를 소스에서 읽습니다** (`/fastEcho\(/`).
   손으로 적으면 `make-fixtures`가 방식을 바꾼 날 이 재현본만 옛 길에 남아요
   (「도달 경로가 조용히 죽음」).
2. 🔴 **`bootPage`의 `fastTimers`로는 안 됩니다** — 그건 `setTimeout(fn, 0)`이라 여전히
   **비동기**예요. 실측으로 확인했습니다: 그래도 `childPicks`가 `[]`.
   `fastEcho`처럼 **그 자리에서 부르는** 것만 통합니다.
3. **G-2** — `childPicks.length === 4` **AND** `schoolN > 3`.
4. **G-2-대조** — 같은 순서를 **동기 타이머 없이** 눌러 `childPicks`가 4가 **아님**을 확인.
   👉 G-2가 공짜 초록불이 아니라는 증거를 **실행할 때마다** 찍습니다.

### 🟡 `schoolN === 8` 대신 `schoolN > 3`을 쓴 이유

`town-test.js`가 *"이 파일은 8이라는 값을 T-5 한 줄에서만 쓰고, 카드 수(2/3/3)는 designer가
아직 만질 수 있다"*고 못박아 뒀습니다. **두 번째 파일에 8을 박으면 designer가 카드 수를
만지는 날 두 곳이 갈라져요.** 그래서 여기서는 **옛 세이브 중립값 3보다 크다**는
관계만 봅니다 — 「학교를 실제로 굴렸나」. **정확한 8은 `town-test` T-5가 정본입니다.**
