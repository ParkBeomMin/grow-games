## 3. 🔴 재 봤더니 — **훈련 배수를 지운 판정의 전제가 뒤집힙니다**

designer의 근거는 이랬습니다:

> *"조숙은 ×1.18을 받는 대신 계단을 4년 먼저 내려갑니다. 둘이 거의 정확히 **상쇄**돼요.*
> *→ 그러면 배수가 **아무 일도 안 하는 계수**입니다. 지웁니다."*

**앞 문장은 맞고 뒤 문장이 틀립니다.** A와 B가 상쇄한다면, A를 지운 결과는 *0*이 아니라
**상쇄되지 않은 B**예요. 배수는 아무 일도 안 한 게 아니라 **계단의 불균형을 지우고 있었습니다.**

같은 창(20~37세)·새 앵커에서 **훈련 계단 총량**(= 커리어 훈련 상승 총량에 비례):

| | 🌱 조숙 | 🌿 보통 | 🌳 만성 |
|---|---|---|---|
| **계단만 (= 지금, 배수 폐기 후)** | **81.5** | 100 | **119.2** |
| 옛 배수(×1.18/×0.86)를 얹으면 | 96.2 | 100 | 102.5 |
| 계단을 중립으로 만들 배수 | ×1.226 | ×1.000 | ×0.839 |

**옛 배수 1.18 / 0.86은 중립화 배수 1.226 / 0.839와 거의 같습니다.**
지운 결과, 훈련 총량이 **조숙 −18.5% · 만성 +19.2%**로 벌어졌어요.

> 참고 — 54번에서 잰 96.4 / 100 / 101.7은 **옛 정점(23/27/31)** 기준이었습니다.
> 정점이 22/26/30으로 옮겨가면서 계단 총량도 함께 바뀌었으니, 옛 배수를 그대로
> 되살리는 것도 정답은 아니에요.

**engineer는 지시대로 지웠습니다.** 되살릴지·다른 형태로 갈지는 designer 판단입니다.
선택지가 셋 보입니다 — 셋 다 *"검증할 것을 하나로 줄인다"*는 원래 뜻을 지킵니다:

| 안 | 내용 | 값 |
|---|---|---|
| **ⓐ 계단을 중립화** | 계단 자체를 정점 기준 **대칭**으로 만들어 타입 간 총량이 같아지게 | 계단 눈금 재설계 |
| **ⓑ 배수를 되살리되 중립화 값으로** | "아무 일도 안 하는 계수"가 아니라 **계단을 중립으로 만드는 계수**로 다시 이름 붙임 | ×1.226 / 1.000 / 0.839 |
| **ⓒ 그대로 두고 곡선으로 상쇄** | 훈련 총량 불균형을 **곡선 면적**에서 반대로 기울여 상쇄 | 앵커 재조정 |

**이건 진짜 버그였고 고쳤습니다.** 검사가 잡아 줘서 찾았어요 — 고맙습니다.

원인: `startPrep`이 `S.proYear += 1`을 **먼저** 하고 `birthday`를 불렀는데,

유스 해넘이(`S.year += 1` → `birthday`)에도 같은 형태가 있었어요.

고친 것 셋:
1. `career.js startPrep` — `birthday`를 **`proYear += 1` 앞**으로
2. `game.js` 해넘이 — `birthday`를 **`S.year += 1` 앞**으로
3. `game.js fillStats` — 나이 칸이 없는 세이브에 **한 번 심어요**
   (🦶 주발을 심는 바로 윗줄과 같은 이유. 읽을 때마다 되짚으면 부르는 순서에 휘둘립니다)

**실제 경로로 확인했습니다** — 픽스처 세이브에서 `S.age`를 지우고 **진짜 `startPrep`**을 호출:
```
옛 세이브(age 없음) 실제 startPrep: year=3 proYear=2 · 21 → 22  ✅ +1
이어서 한 시즌 더:                              22 → 23  ✅ +1
```

**그런데 D-2는 여전히 빨간불입니다** — 검사가 실제 `startPrep`을 부르지 않고
**옛 순서를 손으로 재현**하기 때문이에요:
```js
oldSave.proYear += 1; P0.birthday(oldSave);     // ← 코드가 더는 이렇게 안 합니다
```
고침이 *순서 바꾸기*였으니, 옛 순서의 손 재현은 **영원히 통과할 수 없습니다.**
이건 저장소가 여러 번 데인 *"픽스처가 실제와 다른 모양"*이에요.

- **inspector에게** — `CT.startPrep`을 `_t`로 노출해(이미 `EXPOSE` 패턴이 있어요)
