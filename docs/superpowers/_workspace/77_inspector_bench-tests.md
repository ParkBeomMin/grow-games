## 2. 🌍 세계가 뒤집힌 자리를 어떻게 다뤘나

engineer가 짚은 대로, prospect-test의 **C절은 값이 아니라 세계가 바뀐 자리**였습니다.

```
옛 계약: "두 번 쓰면 잠긴다" · "상한이 이 기능의 절반입니다"
새 판정: ♾️ 무제한. 브레이크는 횟수가 아니라 총합 고정
```

**`2`를 `Infinity`로 바꾸지 않았습니다.** 그러면 *문법적으로 멀쩡하고 변이도 걸리는데
지키는 문장이 틀린* 검사가 됩니다 — 이 저장소가 훈련 배수에서 이미 한 번 겪은 형태예요
(기준선 ❌ · 변이 ✅).

**A절·C절을 `bench-test.js`로 옮기면서 지키는 문장 자체를 바꿨습니다.**
prospect-test에는 **왜 옮겼는지만** 남겼어요 — 값을 갈아 끼운 흔적을 남기면
다음 사람이 "값만 고치면 되는 자리"로 읽습니다.

| 옛 문장 | 새 문장 | 어디로 |
|---|---|---|
| A-1 세 장의 총합이 **서로 같다** | 몇 번을 굴려도 **정확히 194** | bench B-1·C-1 |
| A-2 ⭐ 잠재력을 세 장이 **공유** | ⭐ 잠재력은 🎲 **대상이 아니다** | bench D-1 |
| A-3 세 장의 분포가 **서로 다르다** | 굴릴 때마다 **모양이 달라진다** | bench C-3 |

| H-1 `REROLL_MAX: 2` | `REROLL_MAX: Infinity` + **왜 안전한지** | prospect H-1 |

### 🏷️ 「어느 세계의 문장인가」를 검사 옆에 적었습니다

세 자리에 붙였어요. 전제가 바뀔 때 **누군가 이 검사를 먼저 찾아오도록.**

  그때 C-1(총합)부터 다시 보세요. 총합이 흔들리면 **예산 1회도** 곡선을 밉니다."*
