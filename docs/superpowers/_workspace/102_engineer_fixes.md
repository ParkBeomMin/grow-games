## 3. ③ — 📏 `PEER_REF.town`이 「거의」만 중립이었습니다

*(이 절은 ①②와 **다른 커밋**입니다 — 🔴 곡선을 만지니까요)*

### 무엇이 문제였나

`PEER_REF.town = 32.0`은 ⚔️ 평가전에서 가져온 값인데, 🏫 학교에서 엔진이 보는 몸은
**전원이 `evenStats()`**라 평균이 **32.333…**입니다. 비율 **1.0104** →
`autoP`가 ⅓·½가 아니라 **0.3368 · 0.5052** → **카드 평균이 1이 아니라 1.005~1.010**.
장마다 +0.0075점씩 위로 새서 `E[d]`가 **N에 비례해** 커졌어요.

### ★ 고친 법 — **숫자가 아니라 관계를 적었습니다**

```js
get town() {
  const P = window.WingerProspect;
  if (!P || typeof P.evenStats !== "function") return 0;
  const st = P.evenStats();
  const ks = Object.keys(st);
  return ks.length ? ks.reduce((a, k) => a + st[k], 0) / ks.length : 0;
},
```

| | |
|---|---|
| 🔗 **종속값** | `evenStats()`의 평균을 **그대로 따라갑니다.** `POOL`이 194에서 200이 돼도 자동으로 맞아요 |
| ⚠️ **왜 상수가 아니라 칸인가** | `prospect.js`는 `game.js` **뒤**에 실려서 로드 시점에 `WingerProspect`가 없습니다. 그래서 **읽을 때 계산**해요. 없으면 0을 돌려주고 `youthAutoP`가 `PEER_REF.eval`로 떨어집니다(그 경우 `x`도 0이라 결과는 `base`) |
| 🔒 **되살린 게 아닙니다** | 87번이 폐기한 건 **「동네만 따로 난이도를 정하는 값」이라는 형태**예요. 이 칸은 **아무것도 안 정합니다** — 따라갈 뿐입니다. 🔴 그래서 **여기에 숫자를 적으면 안 됩니다** |
| 🔒 `eval`·`survival` | **한 톨도 안 건드렸습니다** (32.0 / 36.5). ⚔️ 평가전 곡선은 그대로예요 |

### 🔬 실측 — 편향이 사라졌습니다

**고친 뒤 값이 정확히 계약값입니다:**

```
PEER_REF.town = 32.333333333333336  ≡  evenStats() 평균  ≡  POOL / 6   (비트 단위로 같음)
학교가 보는 몸의 overall() / ref = 1.000000000000
autoP(goal) = 0.3333333333333333  ✅   autoP(assist) = 0.3333333333333333  ✅   autoP(defend) = 0.5  ✅
```

**`E[spotMul]` (시드 5개 × 20,000판):**

| N | 전 (검사 파일이 적어 둔 값) | ★ 후 (시드 5개) | 가장 벗어난 시드 |
|---|---|---|---|
| 2 | +0.02% | 0.99994 · 1.00022 · 0.99997 · 0.99991 · 1.00006 | **+0.022%** |
| 5 | +0.06% | 0.99981 · 0.99989 · 1.00002 · 0.99998 · 1.00008 | **−0.019%** |
| 8 | 🔴 **+0.13%** | 1.00006 · 1.00013 · 1.00023 · 0.99980 · 0.99988 | **+0.023%** |

> 🔑 **부호가 갈립니다.** 전에는 시드마다 **전부 위로** 쏠렸어요(누적 편향) —
> 이제는 위아래로 흩어집니다. **편향이 아니라 잡음**이라는 뜻이에요.
> 카드당 드리프트도 **+0.00098 → +0.00056점/장**(1σ ≈ 0.0007 — 0과 구분이 안 됩니다).
