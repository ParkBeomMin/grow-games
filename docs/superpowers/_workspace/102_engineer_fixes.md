## 1. ① — 🔢 「3 / 3」이 거짓말이었습니다

### 무엇을 고쳤나

```js
const STEPS = ["screen-name", "screen-foot", "screen-origin", "screen-position", "screen-prospect"];
```

`intro.js`의 목록은 원래 **「첫 순간 카드 앞에 놓인 결정 수」**를 세는 자리였습니다.
그래서 🎯 자리·🧬 조립대가 빠져 있었고, 🗺️ 동네에 **「3 / 3」**이 떴어요.

🔴 **그런데 화면에는 그 규칙이 안 적혀 있습니다.** 사람은 「3 / 3」을 *"만들기가 끝났다"*로 읽어요.
범민 님의 *"능력치 고르는 게 없어졌네…?"*의 가장 유력한 원인입니다 (101번 §1-4).

★ 이제 세는 것은 **「선수가 완성되기까지 남은 결정」**입니다 — 카드 뒤에 오는 결정도 셉니다.

### 화면에 실제로 찍히는지 — 게임 입구를 통해 확인

| 화면 | 전 | ★ 지금 |
|---|---|---|
| ✏️ 이름 | 1 / 3 | **1 / 5** |
| 🦶 주발 | 2 / 3 | **2 / 5** |
| 🗺️ 동네 | 🔴 **3 / 3** | ✅ **3 / 5** |
| 🎯 자리 | (칸 없음) | **4 / 5** |
| 🧬 조립대 | (칸 없음) | ✅ **5 / 5** |

🔧 🎯 자리·🧬 조립대에는 **`.step-no` 칸 자체가 없었습니다.** `index.html`의 두 `<h2>`를
`step-head`로 감싸 `#step-position`·`#step-prospect`를 만들고, `openBench()`에
`stampStep("screen-prospect")` 한 줄을 더했어요 (🎯 자리는 `goPosition()`이 이미 부르고 있었습니다 —
칸이 없어서 아무 데도 안 찍히고 있었을 뿐이에요).

🔒 **`STEPS`는 세는 것이지 만드는 게 아닙니다.** 첫 카드 앞의 탭 5(여유 0)는 그대로예요 —
화면을 늘린 게 아니라 **이미 있던 두 화면을 세기 시작한 것**입니다.

### 🚨 원칙 ⑩ — 되돌렸더니 **아무도 안 봅니다**

`STEPS`를 3칸으로 되돌리고 검사 20종을 전부 돌렸습니다 → **전부 초록불.**

**놀랍지 않습니다 — `foot-map-test.js`가 그렇게 적어 뒀어요:**
> *"⏳ **곧 죽을 것에는 일부러 검사를 안 걸었습니다** … `WingerIntro.STEPS`의 "2 / 4".
> 🏫 학교 3단계가 들어오면 저것들은 사라집니다"*

🔑 **그때는 맞는 판단이었지만, 지금은 그 자리가 「비어 있는 채로 살아남았습니다.」**
학교 3단계가 들어왔는데 `STEPS`는 안 죽었고, **아무도 안 보는 사이에 거짓말을 하고 있었어요.**

→ 📮 **inspector에게**: 이 자리에 검사가 없습니다. 아래 §5.

## 2. ② — 🧬 조립대에 **고르는 손잡이**

### 무엇을 고쳤나

```
draw.picks = [벌A, 벌B]     // 🎲 한 번 = rollShape 2회. 조건과 무관하게 항상 2회
draw.pick  = 0 | 1          // 고른 쪽. build.stats·shapeKey는 그 사본
```

| 함수 | 하는 일 |
|---|---|
| `rollPair()` | 🎲 두 벌. **두 줄을 나란히** 둡니다 — 조건부 분기 금지(§18-5) |
| `usePick(i)` | 고른 쪽을 `build`에 옮겨 담습니다. **난수 0** |
| `choosePick(i)` | 🅰️🅱️ 버튼이 부릅니다. **난수 0** |
| `pickHTML()` | 두 벌을 **나란히** 그립니다 (`.pb-opt` × 2 · `aria-pressed`) |

`open()`은 `rollBuild`가 이미 한 벌을 굴리니 **짝이 될 한 벌만 더** 굴립니다 —
합쳐서 `rollShape` **2회**라 🎲와 소비량이 같아요.

### ⚠️ 난수 소비량이 굴림당 1 → 2로 늘었습니다

🔒 **조립대는 학교 아크 「뒤」**라 아크·제안·`spotMul`에는 한 톨도 안 닿습니다.
🔒 **조건부가 아닙니다** — 언제나 2회라 소비량이 조건을 안 탑니다(§18-5).
✅ `youth-moment` B-0(시드 재현성) 초록불 그대로.

### 🔒 코드 주석에 남긴 문장 (101번 §1-2·§1-3 · designer가 문을 닫았습니다)

`prospect.js`·`town.js` 양쪽에 적었습니다:

> **조립대가 학교 아크 「뒤」인 이유는 이제 하나입니다 — 편차 밴드의 중립이 「전원 같은 몸」을
> 요구하기 때문이에요.** §5-3의 대칭은 **모든 카드가 평균 1**이라야 성립하고, 그건 몸이
> 기준선에 정확히 설 때뿐입니다. 앞으로 옮기면 잘 굴린 몸이 `d`를 양수로 밀어
> `E[spotMul] > 1.000`이 되고 — **그건 굴림이 `spotMul`을 산다는 뜻이라 원칙 ⑥ 정면**입니다.
> 🔒 **§5-1의 「바뀔 조건」은 닫혔습니다.** 그 문장을 쓸 때는 편차 밴드가 아직 없었어요.
> 🔑 그리고 순-B의 옛 근거(*"자리가 30초 안에 닫힌다"*)는 **아크가 8장이 되며 이미 죽었습니다** —
> 서사는 덤이지 근거가 아닙니다.

### 🧪 bench-test의 변이 셋이 **한 번 죽었다가 되살아났습니다**

그 줄을 겨누던 변이 **M2·M3·DEAD_ROLL이 전부 「안 도는」 상태**가 됐어요 (0번이 잡았습니다 ✅).
