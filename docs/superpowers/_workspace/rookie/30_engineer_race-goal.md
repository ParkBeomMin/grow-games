## 2. 설계에서 벗어난 것 (전부 의도)

| 설계 | 실제 | 왜 |
|---|---|---|
| 새 `race.css` 파일 | `beta/rookie/style.css`에 추가 | `style.css`는 이미 야구 전용이에요. 새 파일은 `index.html`·`sw.js ASSETS` **두 곳에 등록**해야 하고, 빠뜨릴 자리를 늘리는 게 이 저장소가 실제로 데인 곳입니다. 자산 목록이 안 바뀌어 `sw.js` 캐시 버전도 그대로 |
| 테마 변수명을 못 봐서 `currentColor` 기반 | `var(--accent)`·`--muted`·`--line` | 사본에 `style.css`가 없어 아스트라가 몰랐어요. **실제로 있습니다** |
| `raceViewContext` + `syncRaceView()` | 안 넣음 | 기존 `metrics.includes(raceKey)` 가드가 실제 실패(보직 변경으로 부문 목록이 바뀜)를 이미 처리하고, 격차는 **매 렌더 다시 계산**해서 남지 않아요. 요청 없는 상태를 늘리지 않았습니다 |
| `_t`에 순수 함수 넷만 | `renderStandings`도 열음 | 「카드가 진짜 그려지고 탭이 진짜 먹는가」를 재려면 화면 입구가 필요해요 |
| `.race-tab` 최소 높이 44px | 안 함 | 기존 탭이라 제 기능 밖입니다. **별도 판단이 필요해요** (지금 `padding: 5px 6px`) |
| 자격 회귀를 `records-test`에 | `race-view-test` ①에 | 한 파일에서 무변이→변이→복원이 한 묶음으로 돌아가는 게 낫습니다 |
