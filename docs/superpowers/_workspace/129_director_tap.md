## 2. ✂️ 무엇을 줄였는지 — **아무것도 안 줄였습니다**

🔑 먹고 있던 건 상자가 아니라 **여백의 사슬**이었어요. 320px에서 한쪽만 세면:

```
#app 16 + .tour-card 테두리 2 + 여백 16 + .tm-box 테두리 2 + 여백 14 + 골문 테두리 2 = 52px
320 − 104 = 216 ÷ 6 = 36.00
```

**52px 중 34px이 상자 바깥**(`#app` + `.tour-card`)입니다. 그건 8종이 같이 쓰는 자리예요.

### 그래서 상자를 `#app`의 콘텐츠 폭에 맞춰 다시 폈습니다

```css
.w2m-oneone {
  --w2m-span: min(100vw - 32px, 448px);
  width: var(--w2m-span);
  margin-inline: calc((100% - var(--w2m-span)) / 2);
  padding-inline: 10px;              /* .tm-box의 14 → 10, 가로만 */
}
.w2m-oneone .w2m-goal { margin-inline: -6px; }
```

- `100vw - 32px` = `#app`의 좌우 여백(16 × 2)을 뺀 폭
- `448px` = `#app`의 최대 폭(480) − 그 여백. 넓은 화면에서 더는 안 벌어져요
- `margin-inline`의 `%`는 `width`의 `%`와 **같은 기준(부모 폭)**이라 정확히 가운데에 섭니다

**얻은 것 320px 기준**: 카드 여백·테두리 36 + 상자 여백 8 + 골문 내밈 12 = **56px** → 216 → 272.

### 🔴 부모 이름으로 가르지 **않았습니다**

`#stage-card .w2m-oneone { margin-inline: -18px }`이 제일 짧은 길이고, 실제로 먼저 그걸 재 봤어요.
**버렸습니다** — 판이 서는 자리가 **셋**이라서요:

| 자리 | 부모의 좌우 여백 | `-18px`이면 |
|---|---|---|
| 🏟️ `#stage-card` | 16 + 테두리 2 | 딱 맞음 |
| 🏫 `#town-card` | **0** | 🔴 `#app` 밖으로 **36px 넘침** |
| 🧪 확인 페이지 iframe | 그때그때 | 🔴 모름 |

셋을 선택자로 가르면 **화면 구조가 바뀌는 날 한 갈래가 조용히 죽습니다**
(CLAUDE.md 「도달 경로가 조용히 죽음」). 폭을 화면에서 직접 재면 **부모가 무엇이든 같은 폭**이고,
죽을 갈래가 없어요. 위 표의 «스테이지와 학교가 폭마다 같은 값»이 그 증거입니다.

### 🔴 세로는 안 건드렸습니다

재 봤는데 **세로는 이미 여유가 있습니다** — 320px에서 골문 안쪽 높이가 **100px**,
430px에서 **125px**이에요. 칸은 `top:0; bottom:0`이라 **세로는 처음부터 100~125px**이었고,
44px에 모자란 건 **가로뿐**이었습니다. 그리고 세로를 줄이면 탭이 나빠지니 손댈 이유가 없어요.

## 4. 🔴 못 맞춘 자리 — **300px 이하**

| 폭 | 칸 | |
|---|---|---|
| 300px | **42.00px** | 🔴 44px 미달 |
| 320px | 45.33px | 🟢 |

**왜 못 맞추나** — 산수가 남지 않습니다. 300px에서 `#app` 여백 32를 빼면 268이고,
상자 테두리 4 + 골문 테두리 4가 **구조상 못 지우는 8px**이에요. 남는 256을 여섯으로
나누면 42.67이고, 여기서 44 × 6 = 264를 만들려면 **여백을 통째로 0**으로 놔도 모자랍니다.

```
44 × 6 + 테두리 8 = 272 > 300 − 32 = 268     (여백을 전부 0으로 놔도 4px 부족)
44 × 6 + 테두리 8 = 272 ≤ 300                (여백 32까지 다 버리면 되긴 함)
```

**여백을 전부 버리는 건 안 했습니다** — 판이 화면 끝에 딱 붙고 상자 테두리가 사라져요.

🔑 **300px은 실기기 폭이 아닙니다.** 현행 최소가 iPhone SE(1세대) **320px**이고,
Galaxy Fold 접힘이 280px인데 그건 **`ONE.cells: 6`을 줄여야 푸는 문제**예요 — 그건
`winger-moment.js`(engineer)이고 **판정 산식이 걸린 자리**라 연출이 건드릴 곳이 아닙니다.

👉 **280~300px을 지원 대상으로 삼을지**는 designer 판단으로 넘깁니다.
   삼는다면 손잡이는 **칸 수**지 여백이 아니에요.

🟢 **화면이 하는 말은 전부 성취**입니다:

🟡 **남는 위험은 낱말입니다.** 「약발」은 그 자체로 결핍어이고, 같은 화면에
**「약발 －25%」라는 벌점 표가 떠 있어요.** 그래서 *"약발**로도** 해냈다"*가 아니라
*"약발**로밖에** 못 했다"*로 읽힐 여지가 남습니다.
