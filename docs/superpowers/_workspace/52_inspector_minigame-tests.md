### A. 🎯 `s` 산식의 **모양 계약** — 넷이 같은 자를 씁니다

설계 §4-4 ①이 *"난이도를 한자리에서 견줄 수 있어야 한다"*고 한 근거예요. 모양이 다르면
폭(±5%p)을 재는 것 자체가 성립 안 합니다.

| # | 무엇 |
|---|---|
| A-1 | `s = 1 − 오차 ÷ 판정창` — 0에서 1 · 창에서 0 · **단조감소** · [0,1] 안 (41칸 훑음) |
| A-2·3 | 🥅 키퍼 몸 안이면 0 · 🎯 라인을 넘었으면 0 (**실패는 0**이 넷의 공통 규칙) |

| A-5 | 🧱 정타 1 · 인접 0.24 · **정반대 0** (좌↔우는 몸을 못 걸쳐요) |
| A-변이 | 창을 ×2로 흔들면 s 0.500 → **0.750** ✅ · 🧱 인접을 정타와 같게 하면 빨간불 ✅ |

### B. 🎚️ 판정 창은 **무엇에 반응하나** — 🚨 능력치는 안 실립니다

| # | 무엇 | 실측 |
|---|---|---|

| B-4·5 | ♿ 확대 +30% · **성적 페널티 없음** · 🦶 비가 안 흔들림 | 1.00 → 1.30 ✅ |
| **B-6** | 🚨 **능력치가 안 실린다** — 셋째 인자를 무엇으로 줘도 값이 그대로 | 1.250 고정 ✅ |

**변이 넷 전부 잡힙니다:**

```

✅ B-변이. 그 변이가 s까지 번진다 — 같은 오차 6에서 0.600 → 0.684
✅ B-변이. 🦶 주발을 창에서 빼면 빨간불 (주발·약발이 1로 같아져요)
✅ B-변이. 🫀 컨디션을 창에서 빼면 빨간불 (60·100이 1로 같아져요)

> 능력치 변이는 **4곳 한 벌**입니다 — `winMul` 정의 + 호출부 셋. 상용 `miniZone(stat)`이
> 실제로 그렇게 생겼어요. 창만 바뀌고 `s`가 그대로면 반쪽이라, **s까지 번지는지**도 봅니다.

### C. 🔒 **판정을 이 파일이 만들지 않는다**

`opts.judge`가 오면 **그걸 먼저** 쓰는 것, 그리고 **판정과 표시가 같은 값을 본다**는 것.

## 3. 🚧 E[s]를 **안 잰 이유** — 조작자 모델이 저장소에 없습니다

engineer가 잰 **0.522 / 0.522 / 0.521 / 0.537**(폭 0.017 → perfect 폭 0.6%p)은
가상 조작자(시간 오차 σ 70ms · 조준 σ 3.5% · 놓침 3%)로 나온 값입니다.
그런데 그 조작자의 **겨냥 전략**(어디를 노리고 언제 누르나)은 문서에만 있고 코드에 없어요.

**같은 σ로 제가 다시 짜서 재 봤습니다:**

| | 🏃 컷인 | 🥅 마무리 | 🎯 킬패스 | 🧱 차단 | 폭 |
|---|---|---|---|---|---|
| engineer | 0.522 | 0.522 | 0.521 | 0.537 | **0.017** |
| inspector (같은 σ) | 0.558 | **0.655** | 0.559 | 0.510 | **0.145** |

🥅에서 *"빈 곳의 한가운데를 겨냥한다"*로 뒀더니 0.52가 **0.66**이 됐습니다.
**σ는 같은데 겨냥 전략 하나로 0.13이 움직여요.** 설계 §4-4 ①의 ±5%p가 ΔE[s] 0.132니까,
**모델 선택만으로 밴드를 통째로 넘나듭니다.**

> 🚨 이 상태로 밴드를 박으면 검사가 **코드가 아니라 제 조작자 모델**을 재게 됩니다.
> 이 저장소가 여러 번 데인 *"픽스처가 다른 모양"* 그 자리예요 —
> 없는 병이 보이거나(제 모델이 0.66을 내서 "폭 초과" 빨간불), 있는 병이 안 보입니다.
> **⚪ 검증 불가로 넘깁니다** — 측정 주체는 engineer/balancer입니다.

### 대신 — 🔗 **유효 조건을 지킵니다** (`league-test` 33-B와 같은 방식)

E[s]를 만든 **판정 창·속도 상수 17개 + 배열 둘**을 검사에 **직접 박았습니다.**
하나라도 움직이면 engineer의 측정값은 무효예요:

```
✅ D-1. 🔗 E[s] ≈ 0.5를 만든 판정 창·속도 상수 17개가 그대로다
   (움직이면) 🔴 움직인 것: CUT.win 20≠12
     👉 engineer에게 **E[s] 4종 재측정**을 요청하세요 (지금 0.522/0.522/0.521/0.537은 무효입니다).
        설계 §4-4 ①의 ±5%p ⇔ ΔE[s] 0.132 (half(70) = 0.19)
✅ D-2. 🔗 KP.speed [22,34] · CUT.lane [26,74]도 그대로다
```

### 🧱 차단은 **값이 아니라 부등호**로 지킵니다

engineer가 여기서 한 번 갈아엎었어요 — *"신호가 둘인 척하는 신호 하나짜리 판"*이었습니다.
계수를 옮겨도 **이 부등호가 살아 있으면** 판이 성립하므로, 값 대신 관계를 봅니다:

```

        「살짝」은 주발 쪽(0.240 < 0.608)이 정답
     👉 두 경우의 정답이 **서로 갈려야** 읽기가 판이 됩니다
✅ D-변이. favor를 키워 한쪽으로 몰면 → 빨간불 (0.580 vs 1.260)
