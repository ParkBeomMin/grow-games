## 4. 화면 문구 — **필요합니다. 다만 유스 선택 화면이 아니라 소집 카드에**

```js
const abroad = (S.market && S.market !== "k")
  ? `<div class="wc-inv-sub">🇰🇷 해외 유스에서 자랐어도 대표팀은 <b>대한민국</b>이에요.</div>` : "";
```

판단 근거 셋:

| | |
|---|---|
| ① | **유스 선택 화면에 적으면 소음입니다.** 그 시점엔 월드컵이 있는 줄도 몰라요 — 3시즌 도달률이 5~20%라 **대부분은 그 기능을 평생 안 봅니다.** 안 볼 기능의 예외 규칙을 미리 읽히는 셈이에요 |
| ② | **질문이 처음 생기는 자리가 소집 카드입니다.** `📨 대표팀 소집 통지`에 🇰🇷 국기가 뜨는 그 순간이 *"브라질 유스인데 왜?"*가 나오는 지점이라, 답을 그 자리에 뒀습니다 |
| ③ | **국내 유스에겐 안 적습니다.** 당연한 말이라 소집의 순간만 흐려요. director의 화면 파일을 안 건드리는 부수 효과도 있습니다 |

designer의 *"「전남 출신인데 브라질 유스로 갔다」는 어긋남이 아니라 **서사**"*를 따라,
문구를 **규칙 고지가 아니라 사실 한 줄**로 적었습니다 — 사과하거나 설명하지 않아요.
