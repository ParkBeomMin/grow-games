# 플레이어 피드백 4건 — 은퇴 확인 · 초반 경제 · 게임 내 설명

작성일: 2026-07-26
대상: 7개 육성 게임 (`rookie` `idol` `soccer` `stock` `dev` `chef` `stream`) — 🦄 유니콘은 구조가 달라 제외

## 1. 배경

플레이어가 보낸 피드백 4건을 코드에 대조한 결과다.

| # | 피드백 | 확인 결과 |
|---|---|---|
| 1 | 환생은 확인을 눌러야 하는데 은퇴는 확인 절차가 없다 | **사실.** `rebirth()`에만 `confirm`이 있고 `enshrine()`에는 없다. 나란히 있는 두 버튼 중 하나만 되돌릴 기회가 있다 |
| 2 | 환생했는데 소지금이 0원이었다 | **사실이었고 v2.8.0에서 수정 완료.** `legacyMoneyBonus`가 확인창 문구에서만 쓰이고 `newState()`는 `money: 0`으로 시작했다 |
| 3 | 돈 벌기가 너무 힘들다 | **사실.** 아래 2절 참고 |
| 4 | 설명이 부족하다 | **사실.** 게임 안에 도움말·튜토리얼이 하나도 없다 |

2번은 이미 배포됐으므로 이 문서의 범위가 아니다. 남은 1·3·4번을 다룬다.

### 3번이 실제로 어디서 발생하는가

고교 3년(36턴)에 대회는 6번(연 2회 × 3년)이고, 대회당 1~4경기다.

| 성적 | 고교 3년 총수입 | 살 수 있는 장비 |
|---|---|---|
| 대회마다 1회전 탈락 | **150만** | **없음** (최하 등급이 500만) |
| 대회마다 4강 탈락 | 1,020만 | 등급 I |
| 대회마다 우승 | 4,140만 | 등급 II |

**3년을 플레이하고 아무것도 못 사는 구간이 존재한다.** 반면 프로는 한 시즌에 약 11,820만
(경기 수당 4,320 + 연봉 3,000 + WAR×1,500)이라 반 시즌 만에 등급 III을 산다.
초반이 메마르고 프로에서 갑자기 풀리는 구조다.

통계상 새 캐릭터 590명 중 프로 시즌을 완주한 사람은 130명이다. **대부분의 플레이어가
그 메마른 구간에 머문다.**

## 2. 은퇴 확인창

`enshrine()`을 부르기 전에 `confirm`을 띄운다. 환생과 대칭을 이루고, 되돌릴 수 없는
선택이므로 무엇이 남는지 요약해서 보여준다.

```
🎓 여기서 커리어를 마칠까요?

· 명예의 전당에 기록이 남아요
    박도윤 · 5시즌 · WAR 40.9
    🏆우승 1 · 🎖️MVP 4 · 🧤GG 1
· 등급: 👑 명예의 전당 헌액

⚠️ 되돌릴 수 없어요. 유산을 남기려면 '환생'을 선택하세요.

진행할까요?
```

요약 문구는 `enshrine()`이 이미 계산하는 값(`careerScore()`, `gradeOfScore()`, `S.career`)을
그대로 쓴다. 새 계산은 없다.

### 호출 지점 — 시즌 결산의 은퇴 버튼에만 건다

`enshrine()`을 부르는 곳은 게임당 두 곳이지만, **확인창은 한 곳에만 붙인다.**

- ✅ 시즌 결산의 `🎓 은퇴하기` (rookie 기준 `career.js:866`) — **확인창을 붙인다.**
  플레이어에게 실제로 다른 선택지가 있다: 다음 시즌을 더 뛰거나, 환생하거나.
  잘못 누르면 그 선택지들이 사라진다. 환생과 대칭이 되어야 하는 자리다.

- ❌ 드래프트 미지명 시의 `🏛️ 기록 남기고 은퇴` (rookie 기준 `career.js:48`) — **붙이지 않는다.**
  이 버튼이 만들어지는 시점에 이미 `clearSave()`가 호출된 뒤라 되돌아갈 커리어가 없다.
  선택지는 "기록을 남긴다" 하나뿐이고, 취소하면 기록조차 못 남긴 채 끝난다.
  여기에 확인창을 붙이면 오조작을 막는 게 아니라 **오조작으로 기록을 잃을 길을 새로 만드는 셈**이다.

취소하면 아무 일도 일어나지 않고 결산 화면에 그대로 머문다.

각 게임의 최고상 명칭이 다르므로(루키는 MVP·골든글러브, 나머지는 대상·본상) 요약 문구는
게임별로 필드명을 맞춘다.

## 3. 초반 경제 (⚾ 더 루키)

수입을 올리고 초반 장비를 싸게 만든다. 둘 중 하나만으로는 1회전 탈락형이 여전히
아무것도 못 산다.

| 항목 | 현재 | 변경 |
|---|---|---|
| 대회 승리 수당 | `60 + 라운드×25` | `120 + 라운드×50` |
| 대회 패배 수당 | 25만 | 50만 |
| 대회 우승 보너스 | 300만 | 600만 |
| 장비 I | 500만 | **300만** |
| 장비 II | 1,500만 | **900만** |
| 장비 III | 4,000만 | **2,500만** |
| 장비 IV | 10,000만 | **9,000만** |
| 장비 V | 25,000만 | 25,000만 (그대로) |

결과:

| 성적 | 변경 전 | 변경 후 |
|---|---|---|
| 1회전 탈락 | 150만 → 없음 | **300만 → 등급 I** |
| 4강 탈락 | 1,020만 → 등급 I | **2,040만 → 등급 II** |
| 우승 | 4,140만 → 등급 II | **8,280만 → 등급 III** |

실력에 따라 계단이 생긴다. 등급 V를 그대로 두어 후반 목표는 유지하고, 고교 총수입
최대치(8,280만)가 프로 한 시즌(11,820만)보다 여전히 적어 프로 진입의 도약감도 남는다.

**⚾ 더 루키에만 적용한다.** 다른 게임은 대회·상점 구조가 달라 같은 숫자를 쓸 수 없고,
피드백도 더 루키 기준이다. 다른 게임의 초반 경제는 별건으로 다룬다.

## 4. 도움말 모달

### 구조

루트에 공용 `help.js`를 만든다. `match.js`·`fx.js`와 같은 전역 노출 패턴을 따른다.

```js
window.Help = { open(title, sections) }
// sections: { emoji, title, body }[]
```

기존 `.av-overlay` / `.av-modal` 스타일(`base.css:308`, `:507`)을 재사용하므로 새 CSS는
닫기 버튼과 절 간격 정도만 필요하다.

각 게임은:
1. `index.html`에 `<script src="../help.js"></script>`를 `game.js` 앞에 추가
2. HUD마다 `<button class="mini-btn hud-battle" id="btn-help-*">❓ 도움말</button>` 추가
3. `game.js`에서 게임별 내용을 정의하고 버튼에 연결

`sw.js`의 `ASSETS`에 `../help.js`를 추가한다. 빠뜨리면 오프라인에서 `Help is not defined`가 난다.

### 내용 (⚾ 더 루키)

다섯 절. 다른 게임은 같은 뼈대에 용어만 바꾼다.

| 절 | 다루는 것 |
|---|---|
| 🏋️ 훈련과 컨디션 | 매달 훈련 또는 휴식. 컨디션이 낮으면 부상 위험 |
| ⭐ 재능과 각성 | 별은 훈련 효율. 스탯 상한에 닿으면 각성·초월로 상한을 올림 |
| 🏆 대회와 드래프트 | 3년간 6번. 성적이 스카우트 주목도와 지명 순위를 정함 |
| 🎓 은퇴 vs 🧬 환생 | 기록을 남길지, 유산을 남길지. 환생 조건도 함께 |
| 💰 돈 벌기와 쓰기 | 대회 수당·연봉·상점 장비. 30분마다 무료 특훈 |

### HUD 배치

`.hud-right`가 `flex-direction: column`이라 버튼이 세로로 쌓인다(`base.css:426`).
❓를 더하면 **HUD가 버튼 한 개 높이만큼(약 30px) 길어진다.**

모바일에서 답답할 수 있으므로 배치는 사용자가 브라우저에서 확인한다. 답답하면
버튼을 가로로 묶는 후속 작업이 필요하고, 그건 `base.css`를 건드려 7개 게임 전체에
영향을 주므로 이번 범위에 넣지 않는다.

## 5. 범위 밖

- 🦄 유니콘 — 방치형이라 은퇴·대회·상점 구조가 전부 다르다.
- 다른 6개 게임의 초반 경제 — 대회 구조가 달라 같은 숫자를 못 쓴다.
- 정규시즌 경기 수·클릭 수·훈련 횟수 — 이전에 결정된 범위 밖 사항이 그대로 유효하다.
- 튜토리얼(첫 1회 자동 안내) — 도움말 모달로 대체한다.
- HUD 버튼의 가로 배치 — `base.css` 전역 변경이라 별건.

## 6. 검증

테스트 러너가 없으므로 node VM으로 배포되는 코드를 직접 실행해 검증한다.

| 대상 | 확인 |
|---|---|
| 은퇴 확인창 | 7개 게임 모두 **시즌 결산의 은퇴 버튼에만** 확인이 걸렸는지. 드래프트 미지명 경로는 그대로인지. 취소하면 기록이 남지 않는지. 요약 문구가 게임별 필드명(MVP/대상)을 맞게 쓰는지 |
| 고교 수당 | 1회전 탈락 300만 · 4강 탈락 2,040만 · 우승 8,280만 |
| 장비 가격 | 누적 300 / 1,200 / 3,700 / 12,700 / 37,700만. 등급 V 단가가 25,000만 그대로인지 |
| 도움말 | `Help.open`이 절 배열을 받아 모달을 만들고, 닫기가 동작하는지. 7개 게임이 각자 내용을 넘기는지 |
| 회귀 | 가을야구 스위트 6종(219건)과 환생 스위트가 그대로 통과하는지 |

모달의 실제 모양과 HUD 높이는 브라우저 확인 항목이다.
