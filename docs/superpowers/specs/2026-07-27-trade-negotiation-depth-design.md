# 트레이드 협상 개편 (⚾ 더 루키)

작성일: 2026-07-27
대상: `rookie/career.js` 한 파일
선행: `2026-07-27-in-season-trade-design.md`

## 1. 배경

플레이어가 시즌 중 트레이드를 처음 돌려보고 두 가지를 물었어요.

> "어디로 갈지는 나중에 정하는 건가?"
> "요청 거절당했는데 승낙 확률이 5%래. 왜 그런 거야?"

첫 질문은 설계대로예요 — 원소속 구단의 승낙을 먼저 받고, 그다음 행선지를 골라요.
두 번째를 따라가다 설계 결함 세 개가 드러났어요.

### 결함 1 — 안내 문구가 틀렸다

협상 화면이 "구단 태도가 60을 넘겨야 보내줘요"라고 하는데, 실제 공식은
`확률 = (태도 − 40) ÷ 50`, 하한 5% 상한 95%예요. **태도 60은 40%**예요.
문턱이 아니라 확률인데 문턱처럼 읽혀요. 진짜 문턱은 42고, 그 아래는 전부 5%로 뭉개져요.

### 결함 2 — 팬 여론이 사실상 아무 일도 안 한다

여론이 쓰이는 곳은 두 군데뿐이에요.

```js
.filter((t) => teamStrOf(t) < 0.52 || T.fans >= 45 || mv >= 55)
const sour = T.fans < 35;
```

**`mv >= 55`가 여론을 통째로 우회해요.** 잘하는 선수에게 여론은 "35 밑으로만 안
떨어지면 되는 값"이에요. 그래서 여론을 올리는 카드(📰 언론, 🙇 팬 호소)는
구단 태도를 깎기만 하는 순손해가 돼요. 저울의 한쪽이 비어 있어요.

### 결함 3 — 카드가 6장뿐이고 중복해서 나온다

라운드마다 6장 중 3장을 뽑으니 같은 카드가 계속 보여요. 3라운드면 사실상
"단장 면담을 몇 번 누를까"가 돼요.

## 2. 정보를 드러낸다

| 위치 | 내용 |
|---|---|
| 게이지 아래 | `승낙 확률 26%` — 매 라운드 갱신 |
| 여론 게이지 설명 | 45↑ 우승 후보 합류 · 65↑ 후보 +1팀 · 60↑ 환영 계약금 · 35↓ 적응 난항 |
| 협상 시작 | 구단 분위기 한 줄 (시작 태도를 읽게 해줘요) |

틀린 "60을 넘겨야" 문구는 지워요.

확률 계산은 `renderTrade`와 `finishTrade`가 함께 쓰도록 함수로 뽑아요.
두 곳에 같은 식을 두면 한쪽만 고쳐져 어긋나요.

```js
const tradeOdds = (front) => clamp((front - 40) / 50, 0.05, 0.95);
```

구단 분위기 문구는 시작 태도로 갈라요.

| 시작 태도 | 문구 |
|---|---|
| 55 이상 | 구단도 재편을 고민하는 눈치예요 |
| 35~54 | 구단은 아직 마음을 정하지 못한 것 같아요 |
| 20~34 | 구단은 널 놓칠 생각이 없어 보여요 |
| 20 미만 | 구단은 절대 못 놓겠다는 분위기예요 |

## 3. 팬 여론에 값어치를 준다

`mv >= 55` 우회를 없애요. 이게 이번 개편의 핵심이에요 — 우회가 살아 있으면
여론에 무엇을 붙여도 스타 플레이어에게는 여전히 무의미해요.

| 여론 | 효과 |
|---|---|
| 45 이상 | 전력 0.52 이상인 **우승 후보가 행선지 후보에 들어와요** |
| 65 이상 | 행선지 후보가 **한 팀 늘어요** (최대 4팀) |
| 60 이상 | **환영 계약금** — `(여론 − 60) ÷ 40 × 3,000만`, 100원 단위 반올림 |
| 35 미만 | 이적 후 다음 캠프 컨디션 80 → 60 (기존) |

후보 팀 수는 `clamp(1 + ⌊시장가치/30⌋ + (여론 65 이상이면 1), 2, 4)`.

환영 계약금은 여론 60에서 0, 100에서 3,000만이에요. 트레이드는 원래 이적료가
0이라(FA와 달리) 여론을 챙길 이유가 하나 더 생겨요.

## 4. 카드 6 → 12장

같은 협상에서 **한 번 쓴 카드는 다시 나오지 않아요**. 12장 중 3장씩 3라운드면
고르는 재미가 생기고, 마지막 라운드에 뭘 남겨둘지 계산하게 돼요.

| 카드 | 구단 | 여론 | 대가 |
|---|---|---|---|
| 🤝 단장과 진솔한 면담 | +10~18 | — | |
| 🗣️ 동료들의 지지 | +8~16 | +4~10 | |
| 🏆 우승 도전 명분 | +12~20 | +8~16 | 우리 팀 전력 0.53↑이면 역효과 |
| 🙏 가족 사정 호소 | +10~16 | +6~12 | |
| 🧊 조용히 기다리기 | +6~12 | −14~−6 | |
| 🎤 팀에 감사 인터뷰 | +2~8 | +12~20 | |
| 🙇 팬들께 직접 호소 | −8~−2 | +16~26 | |
| 📰 언론에 흘리기 | −14~−6 | +12~22 | |
| 💰 연봉 삭감 감수 | +16~26 | −12~−4 | 💰 3,000만 |
| 🎁 구단 발전기금 | +24~34 | — | 💰 8,000만 |
| 🧨 훈련 거부 | +22~34 | −20~−12 | 시즌 중이면 컨디션 −15 |
| 💼 타 구단 관심설 | 도박 | | 55% `+18~28` / 45% `−12~−4` · 여론 `−8~0` |

돈이 모자란 카드는 후보에서 빠져요 (기존 💰 카드가 하던 방식을 값에 따라 일반화).

🧨 훈련 거부의 컨디션 대가를 시즌 중에만 매기는 이유: 오프시즌에는 캠프가
컨디션을 80으로 다시 세워서 깎아도 사라져요. 오프시즌에서의 대가는 여론 −20~−12예요.

## 5. 프런트 반응

지금은 `구단 +14 · 여론 +8` 숫자만 남아요. 카드를 낼 때마다 구단 반응을 한 줄
덧붙여요. 카드마다 전용 문구를 두지 않고 **구단 태도 변화량으로 고릅니다** —
카드가 늘어도 문구를 따로 관리하지 않아도 되고, 도박 카드처럼 결과가 갈리는
경우에도 알아서 맞아요.

| 태도 변화 | 반응 |
|---|---|
| +22 이상 | 단장이 처음으로 고개를 끄덕였어요 |
| +12 ~ +21 | 단장이 잠시 말을 멈췄어요… |
| +1 ~ +11 | 구단은 별말 없이 들어줬어요 |
| −8 ~ 0 | 구단은 떨떠름한 표정이에요 |
| −9 이하 | 구단은 불쾌한 기색을 감추지 않았어요 |

도박 카드만 성패를 알리는 문구를 따로 앞에 붙여요.

## 6. 범위 밖

- **라운드 수** — 3 그대로예요. 시즌 중엔 라운드마다 컨디션 −8이라 늘리면 부담이 커져요.
- **구단이 먼저 트레이드를 제안하는 것** — 이전 결정("내가 신청하는 것만")이 유효해요.
- **다른 6개 게임** — 트레이드가 없어요.
- **FA 협상** — 제안 중 고르는 방식이라 협상 카드가 없어요.

## 7. 검증

| 대상 | 확인 |
|---|---|
| 확률 | `tradeOdds`가 화면과 판정에서 같은 값을 내는지. 42 이하가 전부 5%, 90이 95%인지 |
| 카드 | 12장인지 · 쓴 카드가 다시 안 나오는지 · 돈이 모자라면 빠지는지 · 3라운드에 3장이 겹치지 않는지 |
| 도박 | 성공/실패 두 갈래가 다 나오는지, 각각 수치가 맞는지 (난수 고정) |
| 대가 | 💰 카드가 값만큼 깎는지 · 🧨가 시즌 중에만 컨디션을 깎는지 |
| 여론 | 45 미만이면 우승 후보가 빠지는지(시장가치와 무관하게) · 65↑에서 후보가 늘어나는지 · 60↑ 환영 계약금이 맞는지 · 35↓ sour |
| 화면 | 확률·분위기·여론 설명이 실제로 그려지는지. 틀린 "60을 넘겨야" 문구가 사라졌는지 |
| 회귀 | 시즌 중 트레이드·가을야구·환생·경제 스위트가 그대로 통과하는지 |
