# ⚾ 더 드래프트 — 해외 진출

작성 2026-07-30 · 대상 `beta/rookie/`

## 왜 필요한가

**시리즈에서 가장 깊은 게임인데 후반 목표가 없다.** 8년차 FA로 강팀에 가는 게 최종이다.

⚽ 축구는 방금 5단 사다리를 얻어서 밑바닥에서 챔피언스리그까지 오르는 서사가 생겼다.
야구에는 그게 없다. 팀은 `REGIONS`에서 온 국내 구단뿐이고 이적은 그 안에서만 오간다.

그리고 **KBO 선수의 커리어에서 해외 진출은 가장 큰 사건**이다. 그게 게임에 없다.

## 3단 사다리

| 리그 | 성격 |
|---|---|
| **KBO** | 지금의 그것. 기본값 |
| **일본 리그** | 첫 해외. 상대가 세지만 아직 감당 가능 |
| **메이저리그** | 최종 목표 |

축구와 달리 **아래로 가는 층은 없다.** KBO가 바닥이다. 사용자가 요청한 건 위로 가는 길이다.

## 난이도는 상대 수준으로 건다 — 자리가 이미 있다

`proBatterGame`이 이미 `oppStr: teamStrOf(opp)`를 넘기고, 주석에
"상대가 강할수록 치기 어렵고 막기 어려워요"라고 적혀 있다.

```js
// 타격 (game.js:1469)
const hitP = clamp(0.16 + S.stats.contact / 800 - (oppStr() - 0.49) * 0.55, 0.10, 0.46)

// 투구 (game.js:283)
const hold = clamp(0.02 + S.stats.control / 300 - (oppStr - 0.49) * 0.6, …)
```

**리그 난이도는 `oppStr`에 얹는다.** 상위 리그에서는 모든 상대가 그만큼 세다.

이게 축구와 결정적으로 다른 점이다. 축구는 평가가 순위 기반이라 **경기 평점을 깎았지만**,
야구는 평가가 타율·홈런·방어율에서 나오므로 **상대를 세게 하면 그 숫자가 자연히 내려간다.**
실제로 벌어지는 일과도 같다 — 메이저에서 타율이 떨어지는 건 투수가 좋기 때문이다.

### 문턱을 따로 손대지 않는다

WAR이 내려가면 수상이 자동으로 어려워진다.

```js
if (war >= 5.5 && war >= leagueBest) { awards.push("MVP"); … }
if (war >= 4.5) { const posBar = …; if (war >= posBar) awards.push("골든글러브"); }
```

축구에서는 하부 리그를 쉽게 만들려고 `bar`를 도입해야 했다. 야구는 하부 리그가 없어서
그 문제가 없다. **`oppUp`과 `prestige` 두 축으로 시작한다.**
곡선이 안 나오면 그때 `bar`를 더한다 — 처음부터 넣지 않는다.

## 두 상수

```js
const LEAGUES = [
  { id: 1, tier: 1, name: "KBO",      short: "국내", flag: "🇰🇷", oppUp: 0,    prestige: 1.00 },
  { id: 2, tier: 2, name: "일본 리그", short: "일본", flag: "🇯🇵", oppUp: 0.06, prestige: 1.45 },
  { id: 3, tier: 3, name: "메이저리그", short: "메이저", flag: "🇺🇸", oppUp: 0.13, prestige: 2.10 },
];
```

**`oppUp`·`prestige` 값은 시험값이다.** 구현 때 실측해서 목표 곡선에 맞춘다.
`id`는 옛 세이브가 가리킬 값이니 나중에 바꾸지 않는다. 순서는 `tier`다.
(축구에서 `id`로 순서를 판단해 사고가 났다 — 같은 실수를 반복하지 않는다.)

## 목표 곡선

**핵심은 "실력이 되면 올라가는 게 이득, 안 되면 손해"다.**

판단 기준은 수상 확률이 아니라 **명예의 전당 가치**(`수상 확률 × prestige`)다.
상위 리그에서는 상을 덜 받지만 그 상이 크게 남는다.

| 능력치 수준 | 최적 리그 |
|---|---|
| 평범 | KBO |
| 준정상급 | 일본 리그 |
| 정상급 | 메이저리그 |

**분기점이 뚜렷해야 한다.** 각 구간에서 최적 리그의 가치가 차선보다 10% 이상 높아야 한다.
붙어 있으면 고민할 근거가 없다.

## 자격 — 포스팅

실제 제도를 따른다. 오프시즌에만, 한 해에 한 번.

| 경로 | 자격 |
|---|---|
| KBO → 일본 리그 | 4년차 이상 + 직전 시즌 WAR 4.0 이상 |
| 일본 리그 → 메이저리그 | 직전 시즌 WAR 4.5 이상 |
| KBO → 메이저리그 (직행) | 7년차 이상 + 직전 시즌 WAR 5.5 이상 |

**KBO 직행이 가장 어렵다.** 일본을 거치면 문턱이 낮아진다 — 실제 커리어 경로와 같다.

**돌아오는 이적은 문턱이 없다.** 언제든 국내로 복귀할 수 있다.

**강등·방출은 넣지 않는다.** 마이너 강등은 벌이 무거워서 도전을 막는다.
못 버티면 성적이 안 나올 뿐이고, 그러면 스스로 돌아오면 된다.

## 구단

일본·메이저 구단 목록을 새로 만든다. 리그당 6곳 이상, 전력(`teamStrOf`와 같은 눈금)은 KBO보다 높게.

**실제 구단명을 쓰지 않는다.** 이 저장소는 상표를 전부 가상 명칭으로 바꿨다
(KBO 구단명도 그래서 바꿨다). 지역·색·동물 같은 결로 짓는다.

## 명예의 전당

`prestige`만큼 가중한다. **안 그러면 안전하게 KBO에 머문 커리어가 순위에서 앞선다.**

축구가 쓴 방식을 그대로 따른다 — 새 카운터를 더하고 옛 카운터는 남긴다.

```js
// 옛 세이브에 가중 카운터가 없으면 옛 값을 1배로 세어 이어붙인다.
// 로드 시점에 마이그레이션하지 않고 수상 시점에만 처리한다.
const mvp = c.mvpW != null ? c.mvpW : c.mvp;
```

> 축구에서 `(mvpW || 0) + prestige`로 쓰면 **옛 세이브가 새 상을 받는 순간 지난 상이
> 사라지는** 버그가 있었다. 반드시 옛 카운터를 이어받아야 한다.

## 기존 저장 데이터

**마이그레이션하지 않는다.** `S.league`가 없으면 KBO다.
`oppUp`이 0이라 진행 중인 캐릭터의 성적이 안 튄다.

## 화면

시즌 결산에 해외 진출 제안이 뜬다. 리그별로 묶고 **`oppUp`이 성적에 어떻게 작용하는지
숫자로 보여준다.** 도박의 크기를 감추면 안 된다.

기존 FA·트레이드 화면과 나란히 서야 한다. 야구는 이미 그 두 창구가 있으니
**세 번째 버튼이 아니라 같은 흐름 안에 들어가는 게 자연스러운지 검토한다.**

## 위험

- **`oppStr`은 팀 전력과 같은 통로다.** 리그 난이도를 얹으면 `teamWinP`·`gameWinP`·
  `crisisRuns`·가을야구 대진까지 흘러간다. **팀 승률이 무너지지 않는지 반드시 측정한다.**
  축구에서 같은 자리를 놓쳐 수비수 팀 승률이 7%가 된 적이 있다.
- **`hitP`의 하한이 0.10이다.** `oppUp`이 크면 거기 붙어서 난이도가 더 안 오른다.
  상한에 붙는지 확인해야 한다 — 축구의 평점 천장이 정확히 그 실패였다.
- **가을야구가 KBO 전용 구조다.** 해외 리그에도 포스트시즌이 있는지, 없으면 어떻게
  다룰지 정해야 한다. **이번 범위에서 가장 불확실한 지점이다.**
- WAR은 이 게임의 고유 축이고 잘 돌아간다. **리그 계수가 그걸 흔들지 않게 재는 것이
  일의 대부분이다.**
