# ⚽ 축구 이적 설계

작성 2026-07-29 · 대상 `beta/soccer/`

## 왜 야구의 이적을 그대로 못 옮기나

⚾ 더 드래프트의 이적은 **같은 리그 안에서 팀을 옮기는 것**이다. 팀마다 전력(`teamStr`)이
있고 그게 승률에 반영된다. 축구에도 그 축은 필요하다.

하지만 축구 커리어의 핵심 서사는 **리그를 옮기는 것**이다. 국내에서 뛰다 유럽으로 가고,
거기서 빅클럽으로 간다. 지금 게임에는 그 축이 아예 없다 — `S.group`은 이름 문자열이고
라이벌은 `rand(52, 88)`로 리그 개념이 없다.

**둘 다 넣는다.** 서로 다른 질문에 답하기 때문에 겹치지 않는다.

| | 무엇이 바뀌나 | 왜 가나 |
|---|---|---|
| 같은 리그 이적 | 팀 전력 → 동료 득점·실점 | 우승, 팀 성적 |
| 상위 리그 이적 | 평점 페널티 + 수상 가치 | 개인 커리어, 명예의 전당 |

## 리그 티어

```js
const LEAGUES = [
  { id: 1, name: "K리그",     short: "국내",   penalty: 0,   prestige: 1.00 },
  { id: 2, name: "유로파리그", short: "유럽",   penalty: 1.6, prestige: 1.35 },
  { id: 3, name: "챔피언스리그", short: "빅클럽", penalty: 2.8, prestige: 1.80 },
];
```

- **`penalty`** — 경기 평점에서 뺀다. `rating = clamp(myScore / RATING_DIV - penalty, 1, 10)`
- **`prestige`** — 축에 곱한다. `hype = log(posAxis(act, pos) * prestige) * AXIS_K - AXIS_OFF`

### 왜 난이도를 평점에서 빼는가

**곱셈으로는 도박이 안 된다.** 처음에 `perf`에 난이도를 곱하고 축에 리그 격을 곱해봤는데,
둘 다 균일하게 작용해서 순효과도 균일했다 — 능력치와 무관하게 올라갈수록 유리해졌다.

평점에서 빼면 다르다. `perf = clamp((rating - 5) / 4 + 0.6, 0.15, 1.6)`가 평점의
비선형 함수라, **평점을 깎으면 약한 선수가 훨씬 크게 무너진다.** 강한 선수는 상한 근처에
있어서 덜 다친다. 이게 "실력이 되면 통하고 아니면 못 버틴다"는 구조를 만든다.

### 측정값 (공격수, 5년차 리그MVP 확률)

| 능력치 | 1부 | 2부 | 3부 | 최선 |
|---|---|---|---|---|
| 70 | 1% | 1% | 0% | **1부** |
| 90 | 14% | 14% | 11% | **1부** |
| 110 | 56% | 63% | 67% | **3부** |
| 130 | 86% | 98% | 99% | **3부** |
| 150 | 96% | 100% | 100% | 2부 |

**능력치 100 언저리가 분기점이다.** 그 아래에서 올라가면 손해, 위면 이득.
"지금 갈까, 더 키우고 갈까"가 진짜 고민이 된다.

150에서 2부가 3부보다 나은 건 둘 다 100%에 붙어서 생기는 잡음이다. 의미 없다.

## 클럽

각 리그에 클럽 6개, 클럽마다 전력(`str`, 40~90)을 둔다.
기존 `OPP_CLUBS` 8개를 리그별로 재배치하고 이름을 늘린다.

```js
const CLUBS = {
  1: [{ name: "FC 노바", str: 78 }, { name: "레인저스", str: 71 }, …],
  2: [{ name: "레알 몬테", str: 82 }, { name: "아틀레티코 델", str: 76 }, …],
  3: [{ name: "…", str: 92 }, …],
};
```

**`str`은 팀 성적에만 작용한다.** 개인 수상에는 안 닿는다.

- `teammateGoals`의 기본값에 곱한다 — 좋은 팀은 동료가 더 넣는다
- `deriveOppGoals`에서 빼준다 — 좋은 팀은 덜 먹는다

같은 리그 안에서 전력 좋은 팀으로 가면 **팀은 더 이기지만 내 수상 확률은 그대로**다.
이게 야구의 이적과 같은 성격이고, 리그 이적과 명확히 구분된다.

## 이적 자격

오프시즌(시즌 결산 화면)에서만 가능하다. 야구와 같다.

| 종류 | 자격 |
|---|---|
| 같은 리그 이적 | 2년차 이상 |
| 상위 리그 이적 | 직전 시즌 hype가 리그 문턱 이상 |

리그 문턱은 **제안이 오는 조건**이지 성공 보장이 아니다.

- 1부 → 2부: 직전 시즌 hype ≥ 5.5 (대략 능력치 90 수준)
- 2부 → 3부: 직전 시즌 hype ≥ 6.5

**강등은 없다.** 못 버티면 성적이 안 나올 뿐이고, 아래 리그로 돌아가는 이적은
언제든 할 수 있다. 커리어가 끝나는 벌은 주지 않는다.

## 화면

시즌 결산 화면에 이적 버튼을 둔다. 누르면 제안 목록이 뜬다.

```
💼 이적 제안 — 6년차 오프시즌

현재  FC 노바 (K리그 · 전력 78)

┌────────────────────────────────────┐
│ 🇰🇷 K리그                           │
│  레인저스   전력 85   계약금 1,200만  │
│  선더볼트   전력 71   계약금   700만  │
├────────────────────────────────────┤
│ 🇪🇺 유로파리그        평점 -1.6      │
│  레알 몬테  전력 82   계약금 4,500만  │
│  아틀레티코 전력 76   계약금 3,800만  │
└────────────────────────────────────┘
        [ 남는다 ]
```

**평점 페널티를 숫자로 보여준다.** 이게 도박의 크기라 감추면 안 된다.
리그 격(수상 가치)도 같이 표시한다 — "수상 가치 ×1.35".

## 하지 않는 것

- **협상·트레이드 요청은 안 넣는다.** 야구의 트레이드 협상은 그 게임 고유의 재미고,
  축구는 제안을 받고 고르는 쪽이 실제와 가깝다. 화면이 하나로 끝난다.
- **시즌 중 이적은 안 넣는다.** 축구에도 겨울 이적시장이 있지만,
  이번 범위를 좁게 잡는다. 통하면 나중에 본다.
- **강등·방출은 안 넣는다.** 벌이 무거우면 도전을 안 한다.

## 기존 저장 데이터

새 필드가 생긴다. **마이그레이션하지 않는다.**

- `S.league` — 없으면 `1`(국내)
- `S.clubStr` — 없으면 `70`(중간)
- `S.moves` — 없으면 `[]`

진행 중인 캐릭터는 국내 리그 중간 전력 팀 소속으로 이어진다.
평점 페널티가 0이라 성적이 안 튄다.

## 위험

- **평점 페널티가 `deriveOppGoals`와 `matchScoreline`에도 흘러간다.**
  상위 리그에서 팀 승률이 무너질 수 있다. 반드시 측정해야 한다.
- **리그 문턱이 새 hype 눈금 기준이다.** 축 기반으로 바꾼 뒤의 값(5.5 / 6.5)이라,
  옛 눈금으로 계산하면 안 된다.
- **`prestige`가 명예의 전당 점수에도 닿아야 하는지** 정해야 한다.
  안 닿으면 빅클럽에서 뛴 커리어가 기록에 안 남는다.
