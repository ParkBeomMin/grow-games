# 🎤 아이돌 — 컴백 컨셉 설계

작성 2026-07-28 · 대상 `beta/idol/`

## 무엇을 푸는가

[성장 곡선 작업](2026-07-27-growth-curve-design.md)으로 판매량 축을 세워 천장은 없앴다.
하지만 **플레이어가 하는 선택은 여전히 "어느 능력치를 올릴까" 하나뿐**이다.
그 선택도 한 번 정하면 커리어 내내 반복이라, 후반에는 클릭만 남는다.

컴백 컨셉은 **연 2회 돌아오는 결정**을 만든다. 육성 방향과 달리 되돌릴 수 있고,
매번 상황이 달라서 같은 답이 안 나온다.

## 구조

컴백 직전에 컨셉 4종 중 하나를 고른다. 컨셉마다 **어느 능력치를 보는지**가 다르다.

| 컨셉 | 주로 보는 것 | 편차 | 성격 |
|---|---|---|---|
| 💧 청량 | 댄스 1.0 · 매력 0.5 · 보컬 0.2 · 랩 0.1 | ±10% | 안정적. 못해도 중간은 간다 |
| 🔥 강렬 | 랩 0.8 · 댄스 0.7 · 매력 0.4 · 보컬 0.1 | ±28% | 터지거나 망하거나 |
| 🌙 감성 | 보컬 1.1 · 매력 0.5 · 댄스 0.2 | ±12% | 보컬형의 유일한 길 |
| ✨ 하이틴 | 매력 1.1 · 댄스 0.5 · 보컬 0.3 · 랩 0.1 | ±18% | 매력 몰빵이 사는 길 |

### 랜덤은 컨셉이 아니라 유행에 건다

컨셉 자체를 랜덤으로 주면 선택이 사라진다. 대신 **컴백 시즌마다 유행과 식상을 하나씩
굴린다.**

- 🔥 **유행** 컨셉: 판매량 ×1.18
- ❄️ **식상** 컨셉: 판매량 ×0.85
- 나머지 둘: 배수 없음

같은 컨셉이 유행이자 식상으로 뽑힐 수 있다. 그때는 배수를 곱하지 않는다.

### 유행은 고른 뒤에 확정된다 — 고르기 전엔 소문만

**고르기 전:** 후보 2종을 소문으로 흘린다. 둘 중 하나가 진짜 유행이다.
**고른 뒤 시즌 시작:** 확정 유행·식상을 공개하고 버프/너프를 화면에 띄운다.

전부 공개하면 확실한 정답이 생겨 고민이 사라지고, 전부 감추면 누구나
자기 최고 컨셉을 고를 뿐이라 유행이 순수 운이 된다. 소문 2종이 그 사이다.

이러면 매 컴백이 **"내 강점을 밀까, 소문 쪽에 걸까"** 가 된다.
보컬 몰빵인데 소문이 하이틴·청량이면, 확실한 감성으로 갈지
반반 확률에 걸고 매력이 부족한 하이틴에 올라탈지 고른다.

### 판매량 산식

```js
// 지금
const cbSales = Math.max(1, Math.round(
  S.stats.charm * 0.55 + stage * 0.75 + S.fandom * 0.05 + act.cbWins * 4 + rand(-4, 4)
));

// 바꿈
const base = Object.entries(concept.w)
  .reduce((sum, [k, w]) => sum + S.stats[k] * w, 0);
const cbSales = Math.max(1, Math.round(
  (base * 0.72 + S.fandom * 0.05 + act.cbWins * 4) * trend * (1 + rand(-concept.v, concept.v))
));
```

`0.72`는 시뮬레이션으로 잡았다. 아래 곡선 참고.
소문 방식은 전부 공개보다 결과가 낮게 나와서, 공개 기준으로 잡았던 `0.55`에서 올렸다.

## 이 설계가 노리는 것

**몰빵 메타를 깬다.** 지금은 주 스탯 하나만 올리는 게 정답이다.
컨셉이 들어오면 고르게 키운 쪽이 유리해진다 — 유행이 어디로 오든 받을 수 있으니까.

측정값 (정보 공개 수준별 대상 확률):

| 유형 | 깜깜이 | **소문 2종** | 전부 공개 |
|---|---|---|---|
| 댄스 몰빵 (150/60/60/70) | 42% | 45% (+3) | 55% |
| 고르게 (110 전부) | 49% | **54% (+5)** | 69% |
| 평범 (95 전부) | 20% | 23% (+3) | 30% |
| 덜 키움 (75 전부) | 6% | 6% (+0) | 9% |

소문에서 고르게 키운 쪽 이득(+5)이 몰빵(+3)보다 크다. 의도한 방향이 살아 있다.
전부 공개하면 그 차이가 +20 대 +13으로 벌어지지만, 정답이 확정돼서 고민이 사라진다.
덜 키운 쪽은 +0이다 — **선택이 육성을 대체하지 않는다.**

## 곡선 검증

계수 `0.72`, 유행 1.18 / 식상 0.85, 소문 2종 기준. 능력치를 전부 같은 값으로 두고:

| 능력치 | 대상 확률 | 목표 |
|---|---|---|
| 70 | 11% | 5% |
| 90 | 30% | 25% |
| 110 | 58% | 60% |
| 130 | 84% | 85% |
| 150 | 94% | 계속 오름 |

110·130은 목표와 맞는다. **저연차(70·90)가 목표보다 후하다** — 계수를 더 내리면
110·130이 같이 무너져서 여기서 멈췄다. 실기기 확인 후 저연차만 조일 방법을 다시 본다.

150에서 94%로 포화한다. 확률은 100%를 못 넘으므로 그 위 구간은
[월드투어](2026-07-27-growth-curve-design.md)가 받는다. 설계대로다.

## 기존 저장 데이터

`S.concept`은 새 필드다. 진행 중인 캐릭터에는 없다.

**마이그레이션하지 않는다.** 읽는 쪽에서 기본값을 준다.

```js
const concept = CONCEPTS.find(c => c.id === act.concept) || CONCEPTS[0];  // 청량
```

청량이 기본인 이유: 편차가 가장 작아서(±10%) 옛 캐릭터의 성적이
갑자기 흔들리지 않는다. 다음 컴백부터 정상적으로 고르게 된다.

`trend`도 없으면 `1`이다. 저장된 컴백 도중에 업데이트가 걸려도 성적이 안 튄다.

## 화면

컴백 시작 버튼을 누르면 컨셉 선택 화면이 먼저 뜬다.

### 1단계 — 컨셉 고르기 (소문만)

```
🎬 3년차 1차 컴백 — 컨셉 정하기

🗣 업계 소문: 이번 시즌은 🔥 강렬 아니면 ✨ 하이틴 이 온대요

┌──────────────────────────────┐
│ 💧 청량                       │
│ 댄스 중심 · 안정적             │
│ 예상 판매량 ~ 28만장           │
├──────────────────────────────┤
│ 🔥 강렬            🗣 소문     │
│ 랩·댄스 중심 · 편차가 커요      │
│ 예상 판매량 ~ 35만장           │
├──────────────────────────────┤
│ 🌙 감성                       │
│ 보컬 중심                     │
│ 예상 판매량 ~ 22만장           │
├──────────────────────────────┤
│ ✨ 하이틴          🗣 소문     │
│ 매력 중심                     │
│ 예상 판매량 ~ 31만장           │
└──────────────────────────────┘
```

**예상 판매량을 보여준다.** 가중치 표를 읽고 암산하게 만들면 안 된다.
편차와 유행 배수를 **뺀** 기댓값을 보여준다 — 소문 카드에도 배수를 얹지 않는다.
아직 확정이 아니니까. 그래야 "소문에 거는 게 도박"이라는 판단이 화면에서 성립한다.

### 2단계 — 시즌 시작, 유행 공개

컨셉을 고르면 무대로 넘어가기 전에 공개 화면이 뜬다.

```
      🔥 강렬 컨셉으로 컴백!

  이번 시즌 유행   🔥 강렬     ← 적중
  이번 시즌 식상   🌙 감성

  ┌────────────────────────┐
  │  🔥 트렌드 적중!         │
  │  초동 판매량 +18%        │
  └────────────────────────┘
```

세 가지 결과가 나온다.

| 결과 | 화면 | 배수 |
|---|---|---|
| 유행에 걸림 | 🔥 **트렌드 적중!** 초동 +18% | ×1.18 |
| 식상에 걸림 | ❄️ **한물간 컨셉…** 초동 -15% | ×0.85 |
| 둘 다 아님 | 무난한 시즌이에요 | ×1 |

이 배수는 컴백 진행 내내 무대 화면 상단에 배지로 남는다.
연말 결산에도 고른 컨셉과 적중 여부를 남긴다.

## 하지 않는 것

- **컨셉별 미니게임 분기** — 게임이 4배로 늘어난다. 판매량 산식만 갈린다.
- **컨셉 숙련도 누적** — 같은 컨셉을 반복하면 유리해지는 구조는
  몰빵 메타를 다시 불러온다. 이 설계가 깨려는 바로 그것이다.
- **컨셉 잠금 해제** — 처음부터 4종 전부 고를 수 있다.

## 솔로 전향은 보류

같은 대화에서 나온 제안이다. "팬덤을 잃고 다시 시작하는 도박"으로 잡으려 했는데
**수치가 성립하지 않는다.**

- 팬덤을 비율로 깎으면 팬덤이 많은(=잘 키운) 쪽이 절대 손실이 커서 방향이 반대로 붙는다
- 경쟁 난이도를 올려 상쇄하려 하면 전 구간이 손해로 내려간다

두 번 다르게 잡아봤고 둘 다 실패했다. 도박이 되려면 "잘 키운 사람은 이득"이 나와야 하는데
현재 산식 구조에서는 그 부호가 안 나온다. 컴백 컨셉을 먼저 넣고,
필요하면 그 위에서 다시 본다.
